---
title: "上线检查清单"
description: "Builder 正式上线前的关键接入、交易与安全检查项。"
---

在正式上线前，建议按照以下清单完成检查。

## Builder

- [ ] Builder 已创建
- [ ] Builder ID 已分配
- [ ] Builder 管理权限已配置

## 账户与资产

- [ ] 钱包连接正常
- [ ] 用户注册或账户创建流程正常
- [ ] 充值流程正常
- [ ] 提现流程正常

## 交易

- [ ] 行情展示正常
- [ ] Orderbook 正常
- [ ] 下单正常
- [ ] 撤单正常
- [ ] 改单正常
- [ ] 仓位展示正常
- [ ] 保证金与风险提示正常
- [ ] WebSocket 断线重连正常

## 产品配置

- [ ] 品牌名称与 Logo 已确认
- [ ] 域名配置完成
- [ ] 支持的交易市场已确认
- [ ] 手续费规则已确认
- [ ] 风险提示、Terms 与 Privacy 已配置

## 上线前验证

- [ ] 测试环境验证完成
- [ ] Production 配置已确认
- [ ] API Key / 签名密钥安全检查完成
- [ ] 异常监控与告警已配置
- [ ] 技术支持与问题反馈渠道已确认

<Note>
不同 Builder 的接入范围可能不同，请根据实际使用的模块补充专项测试。
</Note>
