---
title: "上线检查清单"
description: "Builder 正式上线前，对账户、交易、资产、运营后台和安全配置进行统一检查。"
---

在 Builder 正式上线前，建议按照以下清单逐项确认。

## 接入准备

- [ ] Builder 已创建并完成项目基础配置
- [ ] 接入环境和域名已确认
- [ ] 项目方联系人和技术对接人已确认
- [ ] 运营后台管理员已开通
- [ ] 后台角色与权限已分配

## 账户与认证

- [ ] 用户登录 / 钱包连接流程正常
- [ ] 私有 API 鉴权和签名正常
- [ ] 用户账户、资产、订单和仓位数据可正常读取
- [ ] 异常鉴权和过期请求有正确处理

## 交易

- [ ] 合约与行情数据正常
- [ ] Orderbook 和最新成交正常
- [ ] 下单、撤单、改单正常
- [ ] 订单状态和成交记录正常
- [ ] 仓位、杠杆和保证金展示正常
- [ ] 风险限制及异常提示已验证
- [ ] 实时数据断线重连正常

## 资产与资金

- [ ] 账户资产和资金记录展示正常
- [ ] 充值流程已验证（如项目支持）
- [ ] 提现流程已验证（如项目支持）
- [ ] 运营后台充值 / 提现记录可正常查询
- [ ] 资金转账权限和流程已确认
- [ ] 财务对账口径已确认

## Builder 运营

- [ ] 运营数据看板可正常查看
- [ ] 用户与交易量数据正常
- [ ] 手续费及收益规则已确认
- [ ] 邀请返佣规则和活动配置已确认
- [ ] 公告分类和发布流程已配置
- [ ] 充提及资金相关权限已确认
- [ ] 操作日志可用于关键操作追溯

## 上线与安全

- [ ] 正式环境配置已确认
- [ ] API 密钥 / 签名材料按安全要求保管
- [ ] 高权限后台账号未共享使用
- [ ] 风险、异常和系统维护提示已准备
- [ ] 监控、告警和问题反馈渠道已准备
- [ ] 上线后的技术与运营值班人已确认

<Note>
不同 Builder 的产品范围不同。未接入的模块可以跳过，但所有实际开放给用户或运营人员的能力都应在上线前完成验证。
</Note>
