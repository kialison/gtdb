---
title: "上线检查"
description: "Builder 在正式上线 DEX 前需要完成的产品、技术和运营检查。"
---

正式上线前，项目方应完成一次端到端验收，确保账户、资产、交易、实时数据和运营配置均符合预期。

## 产品与品牌

- [ ] 品牌名称、Logo、域名和页面配置已确认
- [ ] 支持的市场与交易对范围已确认
- [ ] 风险提示、Terms 与 Privacy 已配置
- [ ] 用户侧异常提示和空状态已检查

## 账户与资产

- [ ] 账户创建与认证正常
- [ ] 充值流程正常
- [ ] 提现流程正常
- [ ] 资产余额和状态展示正确
- [ ] 网络、资产、费用等配置与正式环境一致

## 交易

- [ ] 行情、盘口和成交数据正常
- [ ] 下单、撤单和改单正常
- [ ] 订单状态同步正确
- [ ] 仓位、保证金和盈亏展示正确
- [ ] 异常订单和风险提示已覆盖

## 实时数据

- [ ] WebSocket 连接正常
- [ ] 断线重连正常
- [ ] 重连后能够恢复完整状态
- [ ] 订单、成交和仓位不会因重复消息出现异常

## Builder 配置

- [ ] Builder 身份和正式环境配置已确认
- [ ] 手续费与收益规则已确认
- [ ] Builder 管理后台账号和权限已配置
- [ ] 运营、客服和技术联系人已明确

## 上线验收

- [ ] 测试环境验收完成
- [ ] 正式环境配置核对完成
- [ ] API / 签名相关安全检查完成
- [ ] 监控和告警已配置
- [ ] 回滚与异常处理方案已确认

<Note>
不同 Builder 的产品范围可能不同。仅需验收实际接入的模块，但所有资金和交易相关流程都应覆盖正常与异常场景。
</Note>
