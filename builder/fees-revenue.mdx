---
title: "手续费与收益"
description: "项目方在上线前需要确认的 Builder 手续费、收益与结算规则。"
---

手续费与收益属于 **Builder 项目级配置**，不应与普通用户查询交易手续费的接口混在一起。

## Builder 需要确认什么

在正式上线前，项目方需要与 DexBuilder 对齐：

- 用户侧交易手续费
- DexBuilder 基础费用
- Builder 可获得的收益或分成
- 特殊费率或活动费率的适用范围
- 收益统计口径
- 结算周期与结算方式

## 手续费关系

```text
用户交易
   ↓
用户实际支付手续费
   ↓
平台基础费用 + Builder 收益
```

具体费率、分成比例和结算规则以项目最终商务及系统配置为准。

## Builder 侧能力

Builder 后续可通过项目级能力查看或管理与自身业务相关的手续费信息，例如：

- Builder 当前费率配置
- 用户或用户组费率
- 手续费收入
- 交易量与费率统计
- 收益结算记录

<Warning>
只有已经在 Builder 后台或 Builder API 正式开放的能力才可使用。未在 API Reference 中出现的 Builder 专属接口，不应视为已经对外提供。
</Warning>

## 与普通交易 API 的区别

普通用户 API 中的手续费查询用于交易和账户展示；Builder 手续费与收益则属于项目级管理能力，两者权限和使用场景不同。
