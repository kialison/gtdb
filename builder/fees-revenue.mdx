手续费与收益是 Builder 运营交易产品的重要组成部分。DexBuilder 将逐步开放 Builder 维度的手续费配置、查询及收益相关能力。

## 手续费模型

```text
用户交易
   ↓
用户交易手续费
   ↓
DexBuilder 基础费用
   +
Builder 收益
```

具体费率范围、分成方式及结算规则以最终商业政策和实际开放能力为准。

## Builder 手续费能力

| 能力 | 当前状态 |
| --- | --- |
| 查询基础手续费 | 以现有公开能力为准 |
| Builder 默认手续费 | 规划中 |
| 查询用户手续费 | 规划中 |
| 设置用户手续费 | 规划中 |
| VIP 分级手续费 | 规划中 |
| 查询手续费收入 | 规划中 |
| 收益结算 | 规划中 |

<Note>
当前 OpenAPI 主要覆盖交易用户侧能力。Builder 专属手续费和收益接口后续将单独开放，并纳入 API Reference。
</Note>
