手续费与收益属于 **Builder 项目级运营能力**，不应与普通用户交易接口混在一起。

## 运营后台

当前运营数据看板可查看手续费相关业务数据，例如：

- 手续费收入
- 手续费趋势
- 手续费与交易量的变化关系
- 不同时间范围下的手续费统计

项目方可以结合交易量、活跃用户和返佣数据判断实际运营效果。

<Card title="运营数据看板" href="/builder/operations-dashboard" icon="chart-column">
  查看交易量、用户、手续费、充提及访问数据的整体趋势。
</Card>

## 费率、分成与结算

具体手续费率、Builder 收益、返佣扣除、结算方式等规则，与项目商业配置和产品方案相关。文档不会预设固定比例或收益公式。

<Info>
项目接入时应由双方确认最终费率和结算规则，再以正式配置为准。
</Info>

## 后续 Builder API

后续计划根据业务需要补充项目方专属接口，例如：

- 查询 Builder 当前费率
- 查询手续费收入
- 查询用户手续费
- 查询结算或收益数据
- 配置允许由 API 管理的费率能力

这些接口上线后会在 **API Reference → Builder API** 中独立提供，并使用项目级权限控制。

## 与邀请返佣的关系

返佣会影响项目最终运营收益，因此需要结合手续费收入、返佣奖励和交易量一起分析。
