通过 Builder 接入并进行交易的用户，将与对应 Builder 形成业务关联，用于后续用户统计、交易数据分析和运营管理。

## Builder 用户

Builder 维度后续可逐步支持：

- 用户统计
- 交易量统计
- 手续费统计
- 活跃用户分析
- 用户分层
- 运营活动

## 运营能力

后续规划中的 Builder 运营能力包括：

- 用户数据看板
- 交易量与手续费数据
- 邀请与返佣
- 活动管理
- 排行榜与交易赛
- VIP 用户运营

<Info>
Builder 运营能力将根据产品进度，通过 Builder Console 和 Builder API 逐步开放。
</Info>
