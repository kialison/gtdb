DexBuilder 为 Builder 提供独立的**运营管理后台**。它面向项目方运营、财务和管理员使用，与普通交易用户使用的 OpenAPI 分离。

Builder 上线后，不需要把所有运营能力都自行开发在前台；常用的项目级管理能力可以直接在运营后台完成。

## 后台与 OpenAPI 的区别

| | OpenAPI | Builder 运营后台 |
| --- | --- | --- |
| 使用对象 | Builder 的交易用户 / 前端 | 项目方运营、财务、管理员 |
| 核心目标 | 完成行情、账户和交易流程 | 完成业务运营和项目级管理 |
| 权限范围 | 用户级 | Builder 项目级 |
| 当前形态 | API Reference 已提供 | 独立管理后台 |
| 后续扩展 | 持续增加交易接口 | 部分能力逐步开放 Builder API |

<Info>
后台实际显示的菜单和权限会根据项目开通范围及管理员角色有所不同。
</Info>
