---
title: "Builder 管理后台"
description: "DEX 上线后，项目方可通过 Builder 管理后台查看业务数据并进行日常运营管理。"
---

Builder 管理后台面向 **项目方运营和管理人员**。它不是终端用户功能，而是 DEX 上线后的项目级管理工具。

## 后台能力概览

根据当前运营后台能力，项目方可以集中查看和管理以下内容。

<CardGroup cols={2}>
  <Card title="运营数据" icon="chart-column">
    查看交易量、交易笔数、交易地址、手续费、活跃用户、充提金额、访问数据等核心指标和趋势。
  </Card>
  <Card title="用户与增长" icon="users">
    查看用户、交易量及邀请返佣相关数据，用于日常运营和增长分析。
  </Card>
  <Card title="公告与内容" icon="bullhorn">
    管理项目公告及公告分类，用于向用户同步产品和运营信息。
  </Card>
  <Card title="资金与充提" icon="wallet">
    查看资金转账、充值记录、提现记录及相关业务状态。
  </Card>
  <Card title="系统权限" icon="user-shield">
    管理后台管理员、角色权限和访问范围。
  </Card>
  <Card title="操作审计" icon="clipboard-list">
    查看关键后台操作日志，便于问题定位和权限审计。
  </Card>
</CardGroup>

## 运营数据看板

项目方可通过数据看板观察自己的业务运行情况，例如：

- 总交易量与交易笔数
- 交易地址数与活跃用户
- 手续费收入
- 充值与提现金额
- 新增用户
- 邀请返佣数据
- PV / UV 与独立 IP
- 交易量、用户和手续费趋势

## 后台与 Builder API 的关系

当前后台适合项目方进行日常运营和人工管理。对于需要程序化获取或配置的 Builder 能力，后续会根据实际开放范围逐步提供 Builder API。

<Note>
后台具体菜单和权限会根据项目配置有所不同。此处用于说明 Builder 可获得的项目级运营能力，不作为后台操作手册。
</Note>
