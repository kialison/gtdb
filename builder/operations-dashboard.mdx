运营数据看板用于帮助 Builder 快速判断业务规模、用户活跃度、资金流和收入变化。

## 基础数据

当前后台可围绕以下指标进行统计与展示：

- 总交易量
- 交易笔数
- 交易地址数
- 手续费收入
- 充值金额
- 提现金额
- 活跃用户
- 新增用户
- KOL / 邀请返佣拉新
- 返佣奖励
- 访问 PV / UV
- 独立 IP

## 时间范围

后台支持根据业务分析需要切换不同时间范围，例如当天、近 7 天、近 30 天或自定义区间。具体统计粒度以后台实际提供能力为准。

## Builder API

当前运营数据优先通过后台查看。后续如开放 Builder 数据 API，可用于项目方将交易量、手续费、用户等数据同步到自己的 BI、运营系统或自动化任务中。

<Note>
看板字段会随业务迭代持续补充，最终以运营后台实际展示口径为准。
</Note>
