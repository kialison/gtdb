---
title: "充提与资金管理"
description: "通过 Builder 运营后台查看充值、提现、资金转账及相关记录。"
---

资金管理用于项目方查看 Builder 业务中的充值、提现和资金转账情况，并配合日常运营、财务核对和异常排查。

## 充值与提现

后台提供对应的业务记录查询入口，包括：

- 充值记录
- 提现记录
- 充值 / 提现金额统计
- 相关状态与时间信息

项目方可以结合用户反馈、链上状态和后台记录定位资金问题。

## 资金转账

后台包含资金转账及转账记录能力，用于项目方在授权范围内处理相关资金操作和记录查询。

<Warning>
涉及实际资金变动的操作应严格使用项目方授权账户和对应角色权限，并保留操作日志用于后续核查。
</Warning>

## 常见排查流程

<Steps>
  <Step title="确认用户与业务记录">
    先根据用户、时间和业务类型定位对应的充值、提现或转账记录。
  </Step>
  <Step title="确认处理状态">
    核对当前状态、金额和时间，判断是否仍在正常处理窗口内。
  </Step>
  <Step title="进一步核对链上或系统状态">
    如记录异常，再结合实际链上交易、风控审核或系统状态进行排查。
  </Step>
</Steps>

## Builder API

项目级充提和资金数据目前以运营后台为主要管理入口。后续如开放相关 Builder API，会在 API Reference 中单独标明权限、字段和操作范围。
