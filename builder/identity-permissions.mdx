---
title: "Builder 身份与权限"
description: "了解 Builder 身份、项目级权限及其与普通交易用户权限的区别。"
---

Builder 身份用于识别项目方及其业务来源，并为后续项目级配置、数据查询和运营能力提供权限基础。

## Builder ID

每个 Builder 将拥有唯一的 Builder 标识，用于关联和识别：

- 用户来源
- 订单来源
- 交易量
- 手续费
- 收益
- 运营数据

## Builder 管理权限

Builder 管理权限用于执行项目级操作。相关能力将根据产品进度逐步开放，例如：

- 查询 Builder 配置
- 查询或配置 Builder 手续费
- 查询 Builder 用户
- 查询交易量与收益
- 管理运营配置

## Builder 与普通用户权限

```text
Builder
  ├─ Builder 管理权限
  │   ├─ 项目配置
  │   ├─ 手续费配置
  │   └─ 运营与数据管理
  │
  └─ Builder 用户
      ├─ 行情查询
      ├─ 账户与资产
      ├─ 下单 / 撤单
      └─ 仓位管理
```

<Warning>
项目级管理接口与普通用户交易接口将采用不同的权限边界。Builder 专属接口尚未全部开放，请以实际 API Reference 为准。
</Warning>
