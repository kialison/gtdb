## API 用户需要注册 Builder 吗？

不需要。仅调用公开 API 获取数据或进行交易的用户，不需要 Builder 身份。需要构建并运营独立交易产品的项目方，则需要 Builder 身份。

## Builder 必须使用 DexBuilder 提供的前端吗？

不必须。Builder 可以根据接入方式使用标准化方案，也可以基于 OpenAPI 自定义开发自己的前端和业务流程。

## Builder 可以设置自己的手续费吗？

Builder 手续费配置能力正在建设中。具体费率范围、配置方式及收益规则以后续正式开放能力和商业政策为准。

## Builder 可以获取自己用户的数据吗？

DexBuilder 将逐步开放 Builder 维度的用户、交易量、手续费及运营数据能力。具体字段和权限以后续 Builder API 为准。

## Builder 权限和普通 API 权限有什么区别？

普通 API 权限主要面向用户交易行为，例如查询行情、账户、仓位和进行下单等操作；Builder 权限则面向项目级配置、数据查询和运营管理。

## Builder API 在哪里？

当前 API Reference 主要覆盖交易用户侧能力。后续 Builder 专属接口上线后，将在 API Reference 中增加独立的 Builder API 分类。
