DexBuilder 提供从 **DEX 创建、品牌配置、用户账户、资产、行情、交易、结算到运营管理** 的完整能力。项目可以直接基于 DexBuilder 创建并运营自己的 DEX，无需分别建设交易前端和底层交易系统。

## DexBuilder 能力

  <Card title="DEX 创建与品牌配置" icon="wand-magic-sparkles">

  </Card>
  <Card title="账户与认证" icon="user-shield">
    提供用户登录、账户创建、身份识别、认证及账户状态管理能力。
  </Card>
  <Card title="资产与充提" icon="wallet">
    提供资产展示、充值、提现、资金流水及结算相关能力。
  </Card>
  <Card title="市场与行情" icon="chart-candlestick">
    提供市场信息、Ticker、订单簿、成交、K 线及实时行情。
  </Card>
  <Card title="交易与仓位" icon="arrow-right-arrow-left">
    提供下单、撤单、改单、订单、成交、仓位、保证金与杠杆等完整交易能力。
  </Card>
  <Card title="保证金与结算" icon="shield-halved">
    提供保证金、强平、ADL、保险基金及结算相关能力。
  </Card>
  <Card title="实时数据" icon="bolt">

  </Card>
  <Card title="运营管理" icon="sliders">

## Broker 能力

创建 Builder 后，DexBuilder 会为项目建立项目级标识，用于关联该项目的用户、交易和运营数据。

<CardGroup cols={2}>
  <Card title="项目与用户归属" icon="users">
    识别不同项目来源，并关联项目下用户、订单与交易数据。
  </Card>
  <Card title="手续费与收益" icon="coins">
    支持项目级手续费配置、交易费率、收入统计及相关结算能力。
  </Card>
  <Card title="数据与运营" icon="chart-column">
    通过 Builder 管理后台查看项目级用户、交易量、手续费及运营数据。
  </Card>
  <Card title="API 与 WebSocket" icon="code">
    对需要系统集成的场景，提供 REST API 与 WebSocket 能力。
  </Card>
</CardGroup>

## 支持的产品

| 产品 | 说明 |
| --- | --- |
| PerpDEX | 永续合约交易、行情、订单、持仓与账户能力 |
| 预测市场 | 事件结果市场、订单簿、交易、持仓与结算 |
| 事件合约 | 事件类合约市场、交易、实时数据与结算 |
| 多产品 DEX | 可根据业务需要组合启用多个产品 |

## 使用方式

DexBuilder 默认提供完整的 DEX 产品与管理能力。完成 Builder 创建后，可继续配置产品、品牌、市场、账户、手续费及运营能力并上线 DEX。

对于需要与其他系统连接的场景，可使用对应产品的 REST API 与 WebSocket。具体接口、参数与认证方式统一在 **API Reference** 中维护。

<Note>
具体可用产品、配置项及 Builder / Broker 管理能力，以当前 DexBuilder 实际开放范围为准。
</Note>
