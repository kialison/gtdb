DexBuilder 是面向项目方的交易基础设施平台。项目可以基于统一的账户、资产、行情、交易、风控与结算能力，快速构建自己的 DEX，并通过 Builder / Broker 能力完成项目级用户归属、手续费和运营管理。

## 整体架构

```text
项目方 DEX / 自定义前端
        │
        ├─ 用户注册与账户
        ├─ 充值 / 提现 / 资产
        ├─ 行情与实时数据
        ├─ 下单 / 撤单 / 持仓
        └─ 项目级运营配置
        │
        ▼
     DexBuilder
        │
        ├─ 账户与认证
        ├─ 资产与结算
        ├─ 行情与订单簿
        ├─ 订单与撮合
        ├─ 仓位与保证金
        ├─ 风控与强平
        └─ Builder / Broker 服务
```

项目方可以根据开发资源选择现有构建能力或 API / WebSocket 接入。具体交易接口、请求参数与返回字段统一在 **API Reference** 中维护。

## Broker 能力

Builder 创建后，可获得项目级标识，用于在 DexBuilder 基础设施中识别项目及其用户、交易和运营数据。

<CardGroup cols={2}>
  <Card title="项目与用户归属" icon="users">
    通过 Builder / Broker 标识区分项目来源，并关联项目下注册用户与交易数据。
  </Card>
  <Card title="手续费与收益" icon="coins">
    支持项目级手续费配置、交易费率及 Builder 收益相关能力。
  </Card>
  <Card title="数据与运营" icon="chart-column">
    查看项目级用户、交易及运营数据，并通过管理后台完成相关配置。
  </Card>
  <Card title="API 与 WebSocket" icon="code">
    使用 REST API 与 WebSocket 接入账户、行情、交易及实时数据能力。
  </Card>
</CardGroup>

## 支持的产品

| 产品 | 说明 |
| --- | --- |
| PerpDEX | 永续合约交易、行情、订单、持仓与账户能力 |
| 预测市场 | 事件结果市场、订单簿、交易与结算能力 |
| 事件合约 | 事件类合约市场、交易与实时数据能力 |

<Note>
具体可用产品、接口与 Builder / Broker 管理能力，以当前 DexBuilder 开放范围及 API Reference 为准。
</Note>
