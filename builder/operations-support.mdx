title: "运维与技术支持"
description: "了解 DEX 上线后的运行监控、问题定位与技术支持能力。"
---

DEX 上线后，DexBuilder 持续提供交易服务、API、WebSocket、账户、资产及核心基础设施的运行支持，并通过 Builder 管理后台提供项目级运营与问题排查能力。

## 运行监控

可重点关注：

- DEX 页面与核心功能可用性
- API 与 WebSocket 状态
- 行情、订单、仓位和资产状态
- 充值与提现状态
- 交易失败与异常情况
- 项目运营数据
- 后台管理员及权限变化

## 问题定位

出现交易或资产问题时，可结合以下信息进行查询和定位：

1. 用户及账户标识
2. 发生时间
3. 交易市场或资产
4. Order ID / Transaction Hash 等业务标识
5. 请求结果与错误码
6. Trace ID 或相关日志
7. 当前业务状态

Builder 管理后台和 API 返回信息可用于辅助定位具体问题。

## 平台支持

DexBuilder 提供：

- DEX 产品与交易服务运行支持
- API 与 WebSocket 问题定位
- 账户、资产、交易及结算问题排查
- 平台异常与服务状态同步
- 项目配置与上线阶段技术支持

## 重大异常

涉及交易中断、资产异常或大面积用户影响的问题，应优先确认影响范围并及时升级处理。

<Info>
具体支持渠道、响应流程和联系人以项目正式配置为准。
</Info>
