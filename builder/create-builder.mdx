---
title: "创建 Builder"
description: "项目方接入 DexBuilder 的第一步：创建 Builder 身份并确认项目配置。"
---

Builder 是项目方在 DexBuilder 中的项目级身份。它用于区分不同接入方，并作为后续项目配置、运营数据和权限管理的基础。

## 创建前准备

项目方通常需要先确认以下信息：

- 项目名称与品牌信息
- 业务类型与目标市场
- 前端及技术接入方式
- 预计上线范围
- 项目联系人与技术联系人
- 测试环境与正式环境需求

## Builder 身份的作用

Builder 身份用于关联：

- 项目级配置
- 用户来源
- 订单与交易来源
- 交易量与手续费数据
- Builder 管理后台权限
- 后续 Builder 专属能力

## 创建流程

<Steps>
  <Step title="提交项目信息">
    提供项目基础资料，并明确计划接入的产品范围。
  </Step>
  <Step title="确认接入方案">
    与 DexBuilder 对齐前端、账户、资产、交易及运营后台的接入边界。
  </Step>
  <Step title="分配 Builder 身份">
    获取用于识别项目的 Builder 身份及对应环境配置。
  </Step>
  <Step title="进入技术接入">
    按接入方案开始账户、资产、交易和实时数据联调。
  </Step>
</Steps>

<Note>
Builder 身份属于项目级能力，不等同于普通交易用户账号或用户 API Key。
</Note>
