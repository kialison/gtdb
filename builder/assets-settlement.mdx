资产相关能力通常同时涉及**用户侧产品流程**和**项目方运营管理**。接入时需要明确哪些能力由用户前端完成，哪些能力由运营后台查询和管理。

## 用户侧

用户前端需要根据实际产品范围处理：

- 账户资产与可用余额展示
- 资金流水或账户账本查询
- 交易盈亏及结算结果展示
- 充值与提现入口（如当前方案支持）
- 资产状态异常和处理中状态提示

具体开放接口以 API Reference 为准。

## 项目方运营侧

运营后台可用于查看和管理与资金相关的业务数据，包括：

- 充值记录
- 提现记录
- 资金转账
- 转账记录
- 运营数据中的充值 / 提现统计

## 接入原则

<Steps>
  <Step title="先确认资产模型">
    明确用户可交易资产、账户余额口径、充值提现网络以及结算方式。
  </Step>
  <Step title="再接用户侧接口">
    根据 API Reference 接入账户、账本及已开放的资产相关接口。
  </Step>
  <Step title="最后配置运营后台">
    为项目方开通相应的资金查询和管理权限，并完成上线前对账检查。
  </Step>
</Steps>

<Note>
当前未在 OpenAPI 中公开的项目级资金管理能力，以运营后台实际开放功能为准；后续如开放 Builder API，会单独补充接口文档。
</Note>
