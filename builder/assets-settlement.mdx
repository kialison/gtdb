---

DexBuilder 提供完整的资产与充提能力，并在 DEX 中统一提供资产展示、充值、提现和资金状态查询。

## 资产能力

<CardGroup cols={2}>
  <Card title="资产展示" icon="wallet">
    展示账户总资产、可用资产、冻结资产及相关资金状态。
  </Card>
  <Card title="充值" icon="arrow-down">
    提供充值网络、地址、资产选择及到账状态展示。
  </Card>
  <Card title="提现" icon="arrow-up">
    提供提现网络、地址、数量、手续费及提现状态展示。
  </Card>
  <Card title="资金流水" icon="list">
    查询充值、提现、交易及其他资金变化记录。
  </Card>
</CardGroup>

## 资金状态

充值与提现流程会根据实际处理进度持续更新状态。DexBuilder 会在对应页面展示当前状态，并提供相关记录用于查询和排查。

## 配置项

不同 DEX 可根据实际业务配置：

- 支持的资产与网络
- 最小充值 / 提现数量
- 提现费用
- 充值与提现状态
- 正式环境相关资金配置

<Note>
具体支持的资产、网络、费用及状态定义，以当前项目配置和对应 API 文档为准。
</Note>
