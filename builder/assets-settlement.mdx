Builder 需要把 DexBuilder 提供的资产能力，组织成用户可理解、可操作的完整资金流程。

## 典型资产流程

```text
用户
 ↓
Builder 前端
 ↓
交易账户
 ↓
充值 / 提现 / 资产查询
 ↓
DexBuilder 资金与结算能力
```

## Builder 需要实现

### 资产展示

前端应清晰展示用户当前可用资产、冻结资产及与交易相关的账户状态，并处理加载中、无数据和异常状态。

### 充值

Builder 需要完成充值入口、网络与资产选择、充值信息展示以及到账状态反馈。

### 提现

Builder 需要完成提现网络、地址、数量、费用和状态确认，并对风险或不可用状态进行明确提示。

### 状态同步

充值和提现并非只包含一次请求。项目方还需要根据返回状态或实时数据持续更新用户侧展示，直到资金流程结束。

## 接入时重点确认

- 支持的资产与网络
- 最小充值 / 提现要求
- 提现费用与到账规则
- 资金状态与异常状态
- 用户前端需要展示的风险提示
- 测试环境和正式环境配置

<Note>
具体资产、网络、费用和资金状态定义，以项目实际配置和对应 API 文档为准。
</Note>
