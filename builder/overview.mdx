---
title: "Builder 概览"
description: "了解 Builder 在 DexBuilder 中的角色、可构建的产品及可使用的基础能力。"
---

DexBuilder 面向希望构建独立交易产品的项目方（Builder），提供账户、行情、交易、资产、风控及结算等基础能力。

Builder 可以在 DexBuilder 的基础设施之上，构建具有独立品牌、用户入口和运营体系的交易产品。

## Builder 与 API 用户

| | Builder | API 用户 |
| --- | --- | --- |
| 主要场景 | 构建并运营独立交易产品 | 调用 API 获取数据或进行交易 |
| 独立前端 | 支持 | 非必须 |
| Builder 身份 | 需要 | 不需要 |
| 用户运营 | 支持，能力持续建设 | 不涉及 |
| 手续费与收益 | Builder 维度能力持续建设 | 按用户交易规则执行 |
| OpenAPI | 可使用 | 可使用 |
