title: "邀请返佣"
description: "通过 Builder 运营后台管理邀请关系、返佣活动及相关运营数据。"
---

邀请返佣用于 Builder 的拉新和用户激励。项目方可以通过运营后台查看和管理与邀请、返佣相关的业务数据。

## 主要能力

根据项目开通范围，后台可围绕以下能力进行管理：

- 邀请关系与返佣数据
- KOL / 渠道拉新数据
- 返佣奖励统计
- 活动效果分析
- 相关用户与交易数据查询

## 运营建议

<Steps>
  <Step title="先确定返佣规则">
    明确邀请人、被邀请人、渠道或 KOL 的奖励规则以及适用用户范围。
  </Step>
  <Step title="配置活动并上线">
    根据实际后台能力完成返佣活动配置，并确认前端展示和用户参与流程。
  </Step>
  <Step title="跟踪拉新与交易效果">
    结合新增用户、交易量、手续费和返佣奖励等数据评估活动效果。
  </Step>
</Steps>

## 与手续费的关系

返佣通常会与交易手续费和 Builder 收益相关联。具体返佣来源、比例、结算周期及分成规则，以当前项目的正式运营规则为准。

<Card title="手续费与收益" href="/builder/fees-revenue" icon="coins">
  查看手续费收入、收益及后续 Builder API 规划。

## Builder API

后续如开放邀请返佣类 Builder API，可用于项目方自动查询返佣数据、同步渠道数据或与自身运营系统联动。

<Note>
文档不预设固定返佣比例或结算公式，具体规则以项目实际配置为准。
</Note>
