---
title: "用户与交易量"
description: "在 Builder 运营后台查看项目用户、交易活跃度和交易量数据。"
---

用户与交易量是 Builder 日常运营的核心数据。运营后台将用户管理和交易量查询独立出来，方便项目方进行用户分析、活动运营和问题排查。

## 用户管理

项目方可根据实际后台权限查看与 Builder 相关的用户信息，用于：

- 用户查询与定位
- 用户状态确认
- 交易活跃度分析
- 运营活动目标用户筛选
- 用户问题排查

## 交易量

交易量模块用于查看 Builder 维度的交易数据，例如：

- 总交易量
- 按时间区间查询交易量
- 用户交易量
- 交易活跃用户数量
- 交易地址数量
- 相关手续费数据

## 与运营数据看板的关系

运营数据看板用于快速查看整体趋势；用户与交易量模块更适合进一步定位具体用户或业务数据。

<Card title="查看运营数据看板" href="/builder/operations-dashboard" icon="chart-column">
  先查看整体趋势，再进入用户或交易量模块做进一步分析。
</Card>

## Builder API

后续计划逐步提供 Builder 维度的数据查询接口，便于项目方将用户、交易量和手续费等数据接入自身运营系统。

<Note>
Builder 只能访问自身业务范围内的数据，具体可查询字段和权限以后台及后续 Builder API 定义为准。
</Note>
