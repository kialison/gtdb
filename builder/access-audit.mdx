Builder 运营后台属于项目级管理系统，权限控制应与普通交易用户完全隔离。

## 后台系统管理

当前后台包含：

- 管理员用户管理
- 角色管理
- 操作日志

通过角色控制不同团队成员可访问的菜单和可执行操作，降低误操作和越权风险。

## 推荐的角色划分

| 角色示例 | 建议权限范围 |
| --- | --- |
| 运营 | 数据看板、用户、交易量、公告、返佣 |
| 财务 | 手续费、充提记录、资金转账及相关数据 |
| 客服 | 用户查询、充提记录查询、问题排查所需只读权限 |
| 管理员 | 角色、用户、系统配置及必要的高级操作 |

具体角色名称和权限项由项目方根据组织结构配置。

## 操作日志

对关键后台操作保留日志，方便：

- 问题追溯
- 权限审计
- 资金操作核对
- 运营变更记录
- 安全事件排查

## 安全建议

- 按最小权限原则分配角色
- 资金相关权限与普通运营权限分离
- 离职或职责变更后及时调整后台权限
- 定期检查高权限账号和操作日志
- 不共享管理员账号

<Note>
后续 Builder API 如涉及项目级写操作，也应采用与运营后台一致的项目级权限和审计原则。
</Note>
