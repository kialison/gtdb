Builder 接入 DexBuilder 后，主要会使用两类能力：**用户侧交易能力**和**项目方运营能力**。

```text
Builder 产品
   │
   ├─ 用户侧前端
   │    └─ DexBuilder OpenAPI
   │         ├─ 行情与合约信息
   │         ├─ 账户与资产
   │         ├─ 下单 / 撤单 / 改单
   │         ├─ 仓位与保证金
   │         └─ 风险与交易数据
   │
   └─ 项目方运营
        └─ Builder 运营后台
             ├─ 运营数据
             ├─ 用户与交易量
             ├─ 手续费与收益
             ├─ 邀请返佣
             ├─ 公告管理
             ├─ 充提与资金管理
             └─ 权限与操作日志
```

## 用户侧：通过 OpenAPI 完成交易接入

当前公开 OpenAPI 主要面向交易用户侧，Builder 可以使用现有 PerpDEX API 完成行情、账户、订单、仓位及风险等交易能力接入。

## 项目方：通过运营后台完成日常运营

Builder 上线后，项目方可以通过独立运营后台查看业务数据并进行运营管理。后台能力与用户侧交易 API 分离，避免把项目级管理权限暴露给普通用户。

<Card title="查看 Builder 运营后台" href="/builder/operations-console" icon="gauge-high">
  查看数据看板、用户、交易量、返佣、公告、资金及系统权限等后台能力。
</Card>

## Builder API

当前 API Reference 主要是用户交易侧 OpenAPI。面向项目方的 Builder API 将根据业务需要逐步补充，例如手续费查询、运营数据、用户统计、返佣及其他项目级能力。

<Note>
Builder API 尚未完整开放的能力，不会在文档中写成已支持接口；现阶段优先通过运营后台提供项目方管理能力。
</Note>
