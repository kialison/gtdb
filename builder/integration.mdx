DexBuilder 支持不同深度的产品接入方式。项目方可根据上线速度、开发资源和定制需求选择适合自己的方案。

## 接入方式对比

| | 标准化接入 | OpenAPI 自定义接入 |
| --- | --- | --- |
| 开发成本 | 较低 | 较高 |
| 上线速度 | 较快 | 取决于开发周期 |
| UI 自定义 | 中 | 高 |
| 交易流程定制 | 有限 | 高 |
| API 开发量 | 少量或无需 | 需要 |
| 适合项目 | 希望快速上线的项目 | 钱包、交易平台及专业开发团队 |

## 标准化接入

标准化接入适合希望快速构建交易产品的 Builder。相关配置能力将逐步开放，包括：

- 品牌名称与 Logo
- 主题样式
- 域名
- 交易市场配置
- 默认交易对
- 手续费配置
- 运营入口

<Info>
具体可配置项以 Builder 平台实际开放能力为准。
</Info>

## OpenAPI 自定义接入

Builder 可以基于 DexBuilder OpenAPI 自定义实现自己的交易前端和业务逻辑。当前已开放的 PerpDEX API 主要包括：

- 行情与合约信息
- Orderbook 与成交数据
- 账户与资产查询
- 下单、撤单与改单
- 仓位及保证金管理
- 风险相关查询
