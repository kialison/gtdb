DexBuilder 提供完整的 DEX 产品能力。大多数项目可以直接通过 Builder 完成 DEX 创建、品牌配置、产品配置和上线，无需单独建设交易前端或交易基础设施。

## DEX 构建

通过 DexBuilder 可直接完成：

- DEX 名称、Logo、主题和域名配置
- PerpDEX、预测市场、事件合约等产品启用
- 账户、资产、充提和交易能力配置
- 市场与交易参数配置
- 手续费与收益配置
- 运营后台与管理权限配置
- DEX 创建、更新与部署

## API / WebSocket

对于需要将 DexBuilder 数据或交易能力连接到其他系统的场景，可以使用对应产品的 REST API 与 WebSocket。

常见用途包括：

- 获取市场与行情数据
- 查询账户、资产、订单和持仓
- 执行交易操作
- 订阅订单、成交、仓位和余额等实时数据
- 将业务数据连接到其他系统

具体 Endpoint、参数、认证方式和返回字段统一以 **API Reference** 为准。

## 推荐流程

1. 创建 Builder
2. 配置 DEX 基本信息
3. 选择并配置产品
4. 配置账户、资产与交易能力
5. 配置手续费与运营后台
6. 完成测试与验收
7. 发布上线
