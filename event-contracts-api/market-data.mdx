---
title: "Event Contracts Market Data"
sidebarTitle: "Prices and Order Books"
description: "Read Event Contracts token prices, tickers, order books, price history, and trades."
---

Market-data endpoints are public.

```http
GET /api/v4/event_contract/tokens/{token_id}/market
GET /api/v4/event_contract/tokens/{token_id}/price
GET /api/v4/event_contract/tokens/{token_id}/ticker
GET /api/v4/event_contract/tokens/{token_id}/order_book
GET /api/v4/event_contract/tokens/{token_id}/price_history
GET /api/v4/event_contract/tokens/prices
GET /api/v4/event_contract/tokens/{currency}/candlesticks
GET /api/v4/event_contract/markets/{market_id}/trades
```

Example:

```bash
curl "https://broker.dexbuilder.com/api/v4/event_contract/tokens/<token_id>/order_book?depth=20"
```
