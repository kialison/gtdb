---
title: "鉴权说明"
description: "DexBuilder PerpDEX REST API 的公开接口与私有接口认证要求"
---

公开行情接口无需认证。账户、持仓、订单等私有接口需要使用 API Key 进行认证。

## 私有请求 Header

私有接口请求需要携带：

| Header | 说明 |
| --- | --- |
| `KEY` | API Key |
| `Timestamp` | Unix 时间戳，单位为秒 |
| `SIGN` | 根据当前请求内容生成的签名 |

`SIGN` 的具体生成方法请查看「签名机制」。

<Warning>
API Secret 仅用于本地生成签名，不应作为 Header 发送，也不要暴露在前端代码或公开环境中。
</Warning>
