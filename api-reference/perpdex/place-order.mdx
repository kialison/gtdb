title: "创建永续合约订单"

openapi: "/openapi/perpdex.yaml POST /dex_futures/{settle}/orders"
---

该接口用于创建一笔永续合约订单。

<Warning>
该接口需要 API Key、时间戳和请求签名认证。
</Warning>

`size` 表示合约张数，不是币的数量。每张合约对应的标的资产数量可通过合约信息中的 `quanto_multiplier` 获取。

当 `price` 为 `0` 且 `tif` 为 `ioc` 时，可用于提交市价单。
