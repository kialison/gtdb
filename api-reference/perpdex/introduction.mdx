description: "DexBuilder PerpDEX REST API 的整体说明与接口分类"
---

DexBuilder PerpDEX REST API 提供永续合约的行情查询、风险数据、账户查询、持仓管理和订单交易能力。

## 接口分类

- **行情**：合约、深度、成交、K 线、资金费率等公开市场数据
- **风控**：市场强平、风险限额等风险相关数据
- **账户**：账户信息、账户流水与费率
- **持仓**：持仓查询、保证金、杠杆、仓位模式与风险限额管理
- **订单**：下单、撤单、改单、批量操作与成交记录

## 公开与私有接口

公开行情接口无需认证；账户、持仓和订单等私有接口需要按照「鉴权说明」和「签名机制」发送认证请求。

<Note>
具体请求参数、返回字段和认证要求以各接口页面为准。
</Note>
