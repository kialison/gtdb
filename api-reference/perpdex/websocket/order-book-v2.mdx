订阅高效的订单簿增量更新。

**频道：** `futures.obu`

**认证：** 不需要

## 订阅

```json
{
  "time": 1700000000,
  "channel": "futures.obu",
  "event": "subscribe",
  "payload": ["BTC_USDT", "100ms", "20"]
}
```

服务端确认订阅后，会通过同一 `channel` 持续推送 `event: "update"` 消息。

## 取消订阅

将 `event` 改为 `unsubscribe`，并保持 `payload` 与订阅时一致。

深度 V2 适合需要更低延迟维护本地订单簿的场景。
