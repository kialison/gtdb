订阅市场公开强平订单数据。

**频道：** `futures.public_liquidates`

**认证：** 不需要

## 订阅

```json
{
  "time": 1700000000,
  "channel": "futures.public_liquidates",
  "event": "subscribe",
  "payload": ["BTC_USDT"]
}
```

服务端确认订阅后，会通过同一 `channel` 持续推送 `event: "update"` 消息。

## 取消订阅

将 `event` 改为 `unsubscribe`，并保持 `payload` 与订阅时一致。
