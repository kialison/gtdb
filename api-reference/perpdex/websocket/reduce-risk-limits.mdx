接收账户降低风险率相关更新。

**频道：** `futures.reduce_risk_limits`

**认证：** 需要 API Key

## 订阅

```json
{
  "time": 1700000000,
  "channel": "futures.reduce_risk_limits",
  "event": "subscribe",
  "payload": ["<user_id>", "BTC_USDT"],
  "auth": {
    "method": "api_key",
    "KEY": "<API_KEY>",
    "SIGN": "<SIGN>"
  }
}
```

如需订阅全部合约，可在支持的频道中使用 `!all`。签名方式请参见「认证与签名」。

## 取消订阅

将 `event` 改为 `unsubscribe`，并保持认证信息与订阅参数一致。
