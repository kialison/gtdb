订阅指定合约与周期的实时 K 线。

**频道：** `futures.candlesticks`

**认证：** 不需要

## 订阅

```json
{
  "time": 1700000000,
  "channel": "futures.candlesticks",
  "event": "subscribe",
  "payload": ["1m", "BTC_USDT"]
}
```

服务端确认订阅后，会通过同一 `channel` 持续推送 `event: "update"` 消息。

## 取消订阅

将 `event` 改为 `unsubscribe`，并保持 `payload` 与订阅时一致。
