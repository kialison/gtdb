# BatchAmendOrderReq

批量修改订单请求模型，对应 OpenAPI Schema：`BatchAmendOrderReq`。

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `order_id` | integer(int64) | 是 | 订单 ID |
| `amend_text` | string | 否 | 改单自定义信息 |
| `size` | string | 否 | 新的订单数量 |
| `price` | string | 否 | 新的订单价格 |
