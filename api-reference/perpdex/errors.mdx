---
title: "错误处理"
description: "DexBuilder PerpDEX REST API 的 HTTP 错误处理说明"
---

接口调用成功时返回 `2xx` HTTP 状态码；调用失败时根据 HTTP 状态码和接口返回内容判断原因。

## 常见状态

| HTTP 状态 | 说明 |
| --- | --- |
| `2xx` | 请求成功 |
| `400` | 请求参数或请求格式错误 |
| `401` | API Key、时间戳或签名认证失败 |
| `403` | 当前凭证没有对应接口权限 |
| `429` | 请求频率超过接口限制 |
| `5xx` | 服务端处理异常 |

<Note>
具体业务错误信息以接口实际返回内容为准。排查问题时建议保留请求 Method、Path、Query、时间戳以及返回内容；不要对外提供 API Secret。
</Note>
