DexBuilder 为多种去中心化市场产品提供统一基础。项目团队可以根据用户需求选择产品模式，同时在账户、资产、数据和运营方面保持一致的接入方式。

## 永续合约 DEX

永续合约 DEX 面向无固定到期日的连续订单簿交易，覆盖活跃交易者与专业交易者所需的主要流程：

- 合约信息、订单簿、市场成交、K 线、行情统计与历史资金费率；
- 限价、市价、只减仓、只挂单、全部成交或取消、批量与档位 BBO 下单流程；
- 单向持仓与双向持仓模式；
- 全仓与逐仓保证金模式；
- 杠杆、仓位保证金、仓位档位、标记价格、资金费率、强平与 ADL 记录；
- 账户状态、账户流水、交易费率、个人成交与平仓历史。

## 预测市场

预测市场围绕定义清晰的问题和一组可能结果组织交易。完整的市场体验会向用户展示市场规则、交易状态、结果标的、关键时间与最终判定结果，使用户能够在交易前核对合约含义。

项目团队可以通过 DexBuilder 将预测市场产品纳入自有品牌与用户体验，并沿用平台统一的账户、资产与运营流程。

## 事件合约

事件合约是与特定事件结果关联的结果型合约。每个合约均以明确条款、生命周期状态、交易可用性与结算条件呈现，使用户可以理解最终结果的判定依据。

事件合约扩展了 Builder 可提供的市场范围，并遵循相同的产品原则：规则清晰、用户状态一致、账户记录可核对、结算结果明确。

## 共同的产品原则

| 原则 | 用户应获得的体验 |
| --- | --- |
| 清晰的市场定义 | 提交操作前可以查看产品条款、市场状态、支持的操作与结算条件 |
| 一致的账户状态 | 订单、仓位或结果敞口、余额、手续费与历史记录形成连贯的账户体验 |
| 明确的授权 | 已认证操作与资产操作遵循公开的凭证和钱包授权规则 |
| 可追踪的生命周期 | 应用可以从提交、执行、账本更新一直跟踪至最终结算 |
| Builder 自主控制 | 项目团队拥有前端、品牌、用户路径与允许配置的产品参数 |
