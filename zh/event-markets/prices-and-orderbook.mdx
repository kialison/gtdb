了解价格如何形成，以及订单簿如何支持点对点交易。

预测市场使用中央限价订单簿（CLOB）进行交易。价格并非由平台设定，而是由用户之间交易形成的供需关系决定。

![图片](/images/image-2.png "图片")

## 价格代表概率

预测市场中的每份份额价格都介于 0.00 美元至 1.00 美元之间。价格直接反映市场对该结果发生概率的判断。

页面显示价格通常是买卖价差的中间价。如果价差大于 0.10 美元，则改为显示最近成交价。

| 价格 | 隐含概率 |
| --- | --- |
| 0.25 美元 | 25% |
| 0.50 美元 | 50% |
| 0.75 美元 | 75% |

### 示例

如果 Yes 的最佳买价为 0.34 美元，最佳卖价为 0.40 美元：

```text
显示价格 = (0.34 美元 + 0.40 美元) / 2 = 0.37 美元（37% 概率）
```

## 订单簿

订单簿是市场中所有未成交买单和卖单的列表，分为两侧：

| 方向 | 说明 |
| --- | --- |
| 买盘（Bids） | 买单，即交易者愿意支付的最高价格 |
| 卖盘（Asks） | 卖单，即交易者愿意接受的最低价格 |

价差是最高买价与最低卖价之间的差额。价差越小，通常表示市场流动性越高。

## 订单类型

### 市价单

按当前最优可成交价格立即执行。适合希望立即成交、并愿意承担价差的场景。

- **买入：**支付最低卖价
- **卖出：**获得最高买价

### 限价单

只在指定价格或更优价格成交。适合希望控制成交价格并愿意等待的场景。

- 订单会留在订单簿中，直到有其他交易者与之成交
- 订单可以由不同交易者分批成交
- 未成交部分可随时取消

## 交易如何执行

预测市场的 CLOB 采用混合去中心化架构：

1. **链下撮合**——运营方撮合相互兼容的订单
2. **链上结算**——已撮合交易通过智能合约结算

这种设计兼具中心化撮合的速度与链上结算的安全性，资金始终由你自行托管。
