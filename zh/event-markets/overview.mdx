## 开发者快速开始

数分钟内发起你的第一个 API 请求。了解预测市场平台的基础能力，获取市场数据、提交订单并赎回获胜仓位。

<CodeGroup>

```bash API
curl -G "https://api.dexbuilder.com/api/v4/event_markets/markets" \
  --data-urlencode "active=true" \
  --data-urlencode "closed=false" \
  --data-urlencode "limit=5"
```

</CodeGroup>
