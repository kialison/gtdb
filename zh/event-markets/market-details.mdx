从[发现预测市场](/zh/event-markets/discover-markets)选择市场后，可调用市场详情接口。市场数据为公开数据，无需认证。

生产环境 API 基础 URL 为 `https://api.dexbuilder.com`。

## 获取市场

通过复合市场 ID：

```bash cURL
curl "https://api.dexbuilder.com/api/v4/event_markets/markets/<market_id>"
```

通过 slug：

```bash cURL
curl "https://api.dexbuilder.com/api/v4/event_markets/markets/slug/<market_slug>"
```

## 响应

响应为单个市场详情对象：

```json 示例
{
  "market_id": "market-123",
  "event_id": "event-123",
  "slug": "example-market",
  "question": { "en": "Will the outcome occur?" },
  "condition_id": "0xabc...",
  "status": "active",
  "closed": false,
  "accepting_orders": true,
  "enable_order_book": true,
  "outcomes": [
    { "token_id": "token-yes", "outcome": { "en": "Yes", "cn": "是", "tw": "是" } },
    { "token_id": "token-no", "outcome": { "en": "No", "cn": "否", "tw": "否" } }
  ],
  "best_bid": "0.48",
  "best_ask": "0.52",
  "last_trade_price": "0.50",
  "min_order_size": "5",
  "tick_size": "0.01",
  "neg_risk": false,
  "volume": "12500.50",
  "volume_24hr": "850.25",
  "resolution_source": "https://example.com/source"
}
```

## 字段说明

| 字段 | 说明 |
| --- | --- |
| `market_id` | 市场专用接口使用的复合 ID |
| `event_id` | 所属事件 ID |
| `slug` | 稳定、适用于 URL 的市场标识符 |
| `question` | 稀疏本地化对象，可用语言键取决于源数据 |
| `condition_id` | 结算条件标识符 |
| `outcomes` | 结果对象数组，每项包含 `token_id` 与本地化 `outcome` |
| `status` | 当前市场状态 |
| `closed` | 交易或市场活动是否已关闭 |
| `accepting_orders` | 当前是否接受订单 |
| `enable_order_book` | 是否提供订单簿数据 |
| `best_bid`、`best_ask` | 当前最佳买价与卖价 |
| `last_trade_price` | 最近成交价 |
| `min_order_size` | 十进制字符串格式的最小订单数量 |
| `tick_size` | 十进制字符串格式的价格最小变动单位 |
| `neg_risk` | 是否采用负风险结算 |
| `start_date`、`end_date` | Unix 秒格式的市场时间 |
| `resolved_at` | 已结算时的 Unix 秒格式结算时间 |
| `winning_outcome`、`winning_token_id` | 可用时的结算结果 |
| `tags` | 与市场关联的标签摘要 |

## 使用结果代币

将 `outcomes[].token_id` 用于公开价格接口：

```bash cURL
TOKEN_ID="<token_id>"

curl "https://api.dexbuilder.com/api/v4/event_markets/tokens/$TOKEN_ID/order_book?depth=20"
curl "https://api.dexbuilder.com/api/v4/event_markets/tokens/$TOKEN_ID/price"
curl "https://api.dexbuilder.com/api/v4/event_markets/tokens/$TOKEN_ID/ticker"
```

API 直接在 `outcomes` 数组中返回 Token ID。请勿读取或解析 JSON 编码的 `clobTokenIds` 字符串，该字段不属于 Prediction API 响应。

## 关联事件

使用市场响应中的 `event_id` 获取所属事件：

```bash cURL
curl "https://api.dexbuilder.com/api/v4/event_markets/events/<event_id>"
```

市场数据为公开数据。下单、仓位、账户数据等私有接口需要认证；认证机制另有文档说明，并可能发生变化。
