使用私有 `pred.orders` 和 `pred.usertrades` 跟踪订单生命周期和成交，使用 `pred.positions` 和 `pred.settlements` 跟踪账户状态。

## 连接地址

```text
wss://broker.dexbuilder.com/ws/dex-builder/prediction
```

## 订阅

使用 API Key 签名认证：

```json
{"t":1720000000123,"id":"orders-1","op":"subscribe","ch":"pred.orders","payload":{"all":true},"auth":{"method":"api_key","key":"YOUR_API_KEY","sign":"HEX_SIGNATURE"}}
```

## 推送内容

订单包含标识、方向、价格、数量、状态和时间戳；用户成交包含成交、订单、角色、费率、成交价格、数量和确认状态；仓位包含数量、平均价格、结算状态、可用数量、锁定数量和可领取金额。文档不描述标记价格字段。

## 状态恢复

WebSocket 是事件推送，不能替代 REST 查询。连接或重连后：

1. 订阅需要的私有频道。
2. 通过对应 REST 接口查询订单、成交、仓位和账户当前状态。
3. 使用标识和时间戳应用后续 WebSocket 更新。

客户端请求中不要暴露内部用户 Header 或 broker 账户标识。
