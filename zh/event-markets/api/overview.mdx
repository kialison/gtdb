## Base URL

```text
https://api.dexbuilder.com
```

预测市场 REST API 前缀为：

```text
/api/v4/event_markets
```

## 接口访问模型

| 接口类型 | 是否需要认证 | 典型能力 |
| --- | --- | --- |
| 市场发现 | 否 | 事件、市场、标签 |
| 市场数据 | 否 | 价格、Ticker、订单簿、历史数据、K 线 |
| 交易 | 是 | 下单、查询订单、撤单 |
| 账户 | 是 | 持仓、资产、余额、费率、个人成交 |
| 结算 | 是 | 平仓、领取、资金处理 |

## 分页

列表接口使用游标分页：

```json
{"items":[],"next_cursor":"opaque-cursor"}
```

将上一页返回的 `next_cursor` 原样作为下一页的 `cursor`。不要自行解析或修改游标。

## 时间约定

- 事件与市场日期字段通常使用 Unix 秒；
- `from`、`to` 等范围参数通常使用 Unix 毫秒；
- K 线、价格历史、订单和账户生命周期时间通常使用 Unix 毫秒。

## 多语言字段

部分文本字段使用语言对象返回：

```json
{"en":"Yes","cn":"是","tw":"是"}
```

## 数值字段

价格、数量、成交额、余额、手续费等金额类字段通常以字符串返回。建议使用 Decimal 精度处理，避免二进制浮点误差。

## 标准错误

```json
{"label":"INVALID_ARGUMENT","message":"invalid request"}
```

| HTTP 状态 | 说明 |
| --- | --- |
| `400` | 请求参数或 Body 无效 |
| `401` | 私有接口认证失败 |
| `404` | 资源不存在或当前不可见 |
| `503` | 上游或服务暂时不可用 |
