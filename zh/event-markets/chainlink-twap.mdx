TWAP（Time-Weighted Average Price）表示资产在指定回看窗口中的时间加权平均价格。本页介绍 Chainlink 计算的 30 秒与 60 秒 TWAP。

## 使用 RTDS

生产环境优先推荐通过 RTDS 获取 Chainlink TWAP。RTDS 会转发 Chainlink 主网计算后的 TWAP 更新，不需要 Chainlink 凭证。

Symbol 使用小写、斜杠分隔格式，例如 `btc/usd`。不传 symbol 过滤条件时，可接收该 Topic 下全部可用交易对。

```text API
wss://ws-live-data.polymarket.com
```

<Note>
RTDS 使用应用层心跳。每 5 秒发送文本帧 `PING` 以保持连接。
</Note>

订阅 30 秒与 60 秒窗口：

```json
{
  "action": "subscribe",
  "subscriptions": [
    {
      "topic": "crypto_prices_twap_thirty",
      "type": "update",
      "filters": "{\"symbol\":\"btc/usd\"}"
    },
    {
      "topic": "crypto_prices_twap_sixty",
      "type": "update",
      "filters": "{\"symbol\":\"btc/usd\"}"
    }
  ]
}
```

| 回看窗口 | RTDS Topic |
| --- | --- |
| 30 秒 | `crypto_prices_twap_thirty` |
| 60 秒 | `crypto_prices_twap_sixty` |

`filters` 使用紧凑 JSON 字符串，例如 `{"symbol":"btc/usd"}`。如果同一窗口需要多个 symbol，也可以省略 `filters`，然后由客户端根据 `payload.symbol` 自行过滤。

```json
{
  "topic": "crypto_prices_twap_thirty",
  "type": "update",
  "timestamp": 1785178800123,
  "payload": {
    "symbol": "btc/usd",
    "value": 65000.5,
    "full_accuracy_value": "65000500000000000000000",
    "timestamp": 1785178800009,
    "window_s": 30
  }
}
```

`full_accuracy_value` 为精确的 E18 定点数，应使用整数或 Decimal 除以 `10^18`。`value` 更适合展示，不建议在高精度业务计算中直接使用。

使用 `payload.timestamp` 作为 Chainlink 观测时间；外层 `timestamp` 表示数据提交到 RTDS 的时间。连接断开后需要重新连接并重新订阅。

### 选择窗口

每个订阅选择 30 秒或 60 秒；如需两个窗口，需要分别订阅。

### 数据流行为

订阅后从下一条更新开始接收，不提供 Snapshot、History 或断线后的 Replay。

## 直接使用 Chainlink Data Streams

如果需要直接访问 Chainlink 主网数据、获取最新 Report 或保留原始签名 Report，可以使用 Chainlink Data Streams。

在 [Chainlink Data Streams catalog](https://docs.chain.link/data-streams/crypto-streams) 中查找所需资产对应的 `TWAP: 30s` 或 `TWAP: 60s` Feed，并复制 Feed ID。

<Warning>
Chainlink Client ID、Secret 等凭证必须保存在可信后端，不要暴露在浏览器、H5 或移动客户端代码中。
</Warning>

### 安装 SDK

Node.js 20+、TypeScript 5.3+：

```bash
npm install --save-exact @chainlink/data-streams-sdk@1.2.1
```

创建客户端：

```typescript
import {
  createClient,
  decodeReport,
  type Report,
} from "@chainlink/data-streams-sdk";

const client = createClient({
  apiKey: process.env.CHAINLINK_CLIENT_ID!,
  userSecret: process.env.CHAINLINK_CLIENT_SECRET!,
  endpoint: "https://api.dataengine.chain.link",
  wsEndpoint: "wss://ws.dataengine.chain.link",
  haMode: false,
});
```

SDK 会为请求完成认证签名。服务器时间应与 Chainlink 服务保持同步。

### Feed ID 与窗口映射

Report 不直接包含业务 Symbol 或窗口名称，接入方应维护 Feed ID → Symbol / Window 的映射，不能通过更新频率推断窗口。

```typescript
const feeds = new Map([
  [process.env.CHAINLINK_TWAP_30S_FEED_ID!.toLowerCase(), { symbol: "btc/usd", windowSeconds: 30 }],
  [process.env.CHAINLINK_TWAP_60S_FEED_ID!.toLowerCase(), { symbol: "btc/usd", windowSeconds: 60 }],
]);
```

### 获取最新 Report

```typescript
const latestReports = await Promise.all(
  [...feeds.keys()].map((feedID) => client.getLatestReport(feedID)),
);
```

### 订阅实时更新

```typescript
const stream = client.createStream([...feeds.keys()]);

stream.on("report", (report) => {
  console.log(report);
});

stream.on("disconnected", () => {
  console.warn("Chainlink stream disconnected");
});

stream.on("reconnecting", ({ attempt, delayMs }) => {
  console.warn(`Reconnecting: attempt ${attempt} in ${delayMs}ms`);
});

stream.on("error", (error) => {
  console.error("Chainlink stream error:", error);
});

await stream.connect();
```

SDK 会自动处理认证与重连。业务侧仍应监控 `error`、`disconnected` 与 `reconnecting` 状态。

## 读取 Chainlink Report

TWAP Feed 使用 Chainlink Report Schema V2。`decodeReport()` 可解析报告中的价格字段。

| 字段 | 用途 |
| --- | --- |
| `report.feedID` | 映射到资产和 30s / 60s 窗口 |
| `decoded.price` | 精确 E18 价格，建议以 `bigint` 或 Decimal String 保存 |
| `report.validFromTimestamp` | Report 最早有效时间 |
| `report.observationsTimestamp` | Chainlink 观测时间 |
| `decoded.expiresAt` | Report 过期时间 |
| `report.fullReport` | 原始签名 Report |

`decodeReport()` 负责解析字段，但并不等同于完成 DON 签名验证。如果数据被用于结算或其他高信任场景，应按照 Chainlink 官方要求完成完整验证。

| REST URL | WebSocket URL |
| --- | --- |
| `https://api.dataengine.chain.link` | `wss://ws.dataengine.chain.link` |

30 秒与 60 秒代表 TWAP 回看窗口，而不是推送频率。接入方应自行定义数据 Freshness 阈值及数据中断时的回退策略。
