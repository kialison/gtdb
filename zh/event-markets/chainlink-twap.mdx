直接或通过预测市场 RTDS 获取 Chainlink 计算的 TWAP 价格。

时间加权平均价格（TWAP）表示资产在回看窗口内的平均价格。本页介绍 Chainlink 计算的 30 秒和 60 秒 TWAP。

## 使用预测市场 RTDS

RTDS 是推荐的生产环境集成方式。它无需凭证即可转发 Chainlink 计算的主网 TWAP 更新。symbol 应使用小写、斜杠分隔格式，例如 `btc/usd`。省略 symbol 筛选器可接收全部可用交易对。

```text API
wss://ws-live-data.polymarket.com
```

<Note>
  RTDS 使用应用层心跳。每 5 秒发送文本帧 `PING` 以保持连接。
</Note>

需要底层控制时，可直接连接 RTDS，并为所需回看窗口发送订阅帧：

```json
{
  "action": "subscribe",
  "subscriptions": [
    {
      "topic": "crypto_prices_twap_thirty",
      "type": "update",
      "filters": "{\"symbol\":\"btc/usd\"}"
    },
    {
      "topic": "crypto_prices_twap_sixty",
      "type": "update",
      "filters": "{\"symbol\":\"btc/usd\"}"
    }
  ]
}
```

| 回看窗口 | RTDS 主题 |
| --- | --- |
| 30 秒 | `crypto_prices_twap_thirty` |
| 60 秒 | `crypto_prices_twap_sixty` |

`filters` 必须使用上例所示的紧凑 JSON 格式，只包含一个小写 symbol 且不能有空格，例如 `{"symbol":"btc/usd"}`。省略该字段可接收全部 symbol。如需同时获取一个窗口下的多个 symbol，可省略 `filters`，再由应用根据 `payload.symbol` 筛选。

```json 示例输出
{
  "topic": "crypto_prices_twap_thirty",
  "type": "update",
  "timestamp": 1785178800123,
  "payload": {
    "symbol": "btc/usd",
    "value": 65000.5,
    "full_accuracy_value": "65000500000000000000000",
    "timestamp": 1785178800009,
    "window_s": 30
  }
}
```

`full_accuracy_value` 是精确的有符号 E18 定点值，应使用整数或十进制运算除以 10^18；数值型 `value` 仅用于便捷展示。

使用 `payload.timestamp` 作为 Chainlink 观测时间；外层 `timestamp` 表示发布方将更新提交至 RTDS 的时间。连接中断后，客户端必须重新连接并重新订阅。

### 选择窗口

每次订阅选择 30 秒或 60 秒窗口；如两者都需要，请分别订阅。

### 数据流行为

订阅从下一次更新开始，不提供初始快照、历史记录，也不会在断线后重放。

## 使用 Chainlink Data Streams

如需直接访问主网、在开始订阅前获取最新报告，或取得原始签名报告，请使用 Chainlink Data Streams。在 [Chainlink Data Streams 目录](https://docs.chain.link/data-streams/crypto-streams)中找到资产对应的 TWAP: 30s 或 TWAP: 60s 条目并复制 Feed ID。该功能只能在受信任的后端运行，切勿向浏览器或移动应用暴露 Chainlink 凭证。

<Steps>
  <Step title="安装并连接">
    使用 Node.js 20+ 与 TypeScript 5.3+，安装 Chainlink SDK：
    
    ```bash
    npm install --save-exact @chainlink/data-streams-sdk@1.2.1
    ```
    
    创建主网客户端：
    
    ```typescript
    import { createClient, decodeReport, type Report } from "@chainlink/data-streams-sdk";

    function requireEnv(name: string): string {
      const value = process.env[name];
      if (!value) throw new Error(`Missing required environment variable: ${name}`);
      return value;
    }

    const client = createClient({
      apiKey: requireEnv("CHAINLINK_CLIENT_ID"),
      userSecret: requireEnv("CHAINLINK_CLIENT_SECRET"),
      endpoint: "https://api.dataengine.chain.link",
      wsEndpoint: "wss://ws.dataengine.chain.link",
      haMode: false,
    });
    ```
    
    SDK 会为每次请求签名。请确保服务器时间与 Chainlink 服务器时间的误差不超过 5 秒。
  </Step>
  <Step title="映射并解码报告">
    将目录中的 Feed ID 存入服务端环境变量，并把每个 ID 映射至资产和窗口。请保留有符号 E18 值，不要转换为 JavaScript `number`。
    
    使用 `decodeReport(report.fullReport, report.feedID)` 解码报告；验证版本为 `v2`，再读取 `decoded.price`。使用 `bigint` 或十进制字符串除以 10^18，避免精度损失。
  </Step>
  <Step title="获取最新 TWAP">
    开始订阅前，获取每个 Feed 的最新报告：
    
    ```typescript
    const latestReports = await Promise.all(
      [...feeds.keys()].map((feedID) => client.getLatestReport(feedID)),
    );

    for (const report of latestReports) {
      console.log(readTwap(report));
    }
    ```
    
    输出应包含 `feedID`、`symbol`、`windowSeconds`、精确 `value` 和 `observedAt`。
  </Step>
  <Step title="订阅更新">
    订阅选定 Feed ID：
    
    ```typescript
    const stream = client.createStream([...feeds.keys()]);

    stream.on("report", (report) => {
      try { console.log(readTwap(report)); }
      catch (error) { console.error("Failed to decode Chainlink report:", error); }
    });

    stream.on("disconnected", () => console.warn("Chainlink stream disconnected"));
    stream.on("reconnecting", ({ attempt, delayMs }) =>
      console.warn(`Reconnecting: attempt ${attempt} in ${delayMs}ms`)
    );
    stream.on("error", (error) => console.error("Chainlink stream error:", error));

    await stream.connect();
    ```
    
    SDK 会自动认证并重连。请监控 `error`、`disconnected` 和 `reconnecting`；如果重试耗尽，应重新启动数据流。
  </Step>
</Steps>

### 读取 Chainlink 报告

TWAP Feed 使用 Chainlink V2 报告结构。`decodeReport()` 将编码后的 `benchmarkPrice` 暴露为 `decoded.price`。

| 值 | 用法 |
| --- | --- |
| `report.feedID` | 将报告映射到资产及 30 秒或 60 秒窗口 |
| `decoded.price` | 以 `bigint` 或十进制字符串保留精确有符号 E18 值 |
| `report.validFromTimestamp` | Unix 秒格式的最早有效时间 |
| `report.observationsTimestamp` | Unix 秒格式的 Chainlink 观测时间 |
| `decoded.expiresAt` | Unix 秒格式的报告过期时间 |
| `report.fullReport` | 原始 Chainlink 签名报告 |

报告不包含 symbol 或窗口标签。请自行维护映射，不要根据更新频率推断窗口，并使用 `observationsTimestamp` 检查新鲜度。

`decodeReport()` 只解析报告字段，并不验证 DON 签名。将报告用于结算或其他高信任操作前，请遵循 Chainlink 的验证要求。

### 查找 Feed ID

打开 [Chainlink Data Streams 目录](https://docs.chain.link/data-streams/crypto-streams)，搜索所需资产及窗口，例如 BTC / USD - TWAP: 30s 或 BTC / USD - TWAP: 60s。从产品页面复制 Feed ID，并配合现有标准或赞助型 Data Streams 凭证使用。

| REST URL | WebSocket URL |
| --- | --- |
| `https://api.dataengine.chain.link` | `wss://ws.dataengine.chain.link` |

30 秒和 60 秒表示回看窗口，而不是发布频率。TWAP 由 Chainlink 计算并签名。请定义新鲜度阈值与报告缺口的降级方案，不要尝试从传入更新推断计算过程。Chainlink 当前未公开该自定义 Feed 的采样边界、权重、舍入或缺失输入处理方式，因此在没有 Chainlink 规范的情况下，不应自行复现该值。
