预测市场 API 使用标准 HTTP 状态码表示请求处理结果。以下错误可能出现在需要认证的接口中。

## `401 Unauthorized`

### API Key 无效

可能原因：

- 未携带 API Key；
- API Key 已失效；
- API Key 不正确。

请检查认证参数，并确认使用的是当前有效凭证。

### 签名无效

如果认证 Header 格式错误、时间戳不符合要求或签名内容与实际请求不一致，也会返回 `401`。

排查时重点确认：

- 请求时间戳；
- 签名原文；
- Query 与 Body 是否和签名时完全一致；
- API Secret 是否正确。

## `429 Too Many Requests`

表示请求频率超过当前限频规则。

建议客户端使用指数退避后重试，并避免短时间内重复请求同一资源。

## `503 Service Unavailable`

表示交易服务或依赖的上游服务暂时不可用。此时新的交易请求可能无法正常处理。

对于只读查询，可以在短暂等待后重试；交易类请求应先确认上一笔请求的最终状态，避免重复提交。

## 通用错误处理建议

客户端应优先根据 HTTP 状态码和响应中的结构化错误字段进行处理，不要依赖完整的错误文本。

建议记录以下信息用于排查：

- Request Method；
- Request Path；
- Query；
- 请求时间戳；
- `trace_id`；
- HTTP 状态码；
- 服务端返回的错误码与错误信息。

<Warning>
排查日志时不要记录或对外暴露 API Secret、完整签名密钥或其他敏感认证信息。
</Warning>
