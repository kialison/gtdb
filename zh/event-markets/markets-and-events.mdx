了解预测市场的基础组成。

每份合约都围绕两个核心概念构建：**市场（Market）与事件（Event）**。理解二者的关系，是基于本平台进行开发的基础。

![图片](/images/image-1.png "图片")

## 市场

市场是预测市场中最基本的可交易单元。每个市场代表一个只有 Yes/No 两种结果的二元问题。

每个市场都包含：

| 标识符 | 说明 |
| --- | --- |
| Condition ID | CTF 合约中市场条件的唯一标识 |
| Question ID | 用于结算的市场问题哈希 |
| Token ID | 在 CLOB 上交易使用的 ERC1155 代币 ID，Yes 与 No 各一个 |

### 市场示例

一个简单的市场可能是：

> _“比特币会在 2026 年 12 月前达到 100,000 美元吗？”_

它会创建两种结果代币：

- **Yes 代币**——如果比特币达到 100,000 美元，可兑付 1 美元
- **No 代币**——如果比特币未达到 100,000 美元，可兑付 1 美元

## 事件

事件是将一个或多个相关市场组合在一起的容器。事件提供组织结构，并支持多结果预测市场。

### 单市场事件

当事件只包含一个市场时，会形成一组简单的二元结果。此时事件和市场基本等价。

```text
事件：比特币会在 2024 年 12 月前达到 100,000 美元吗？
   └── 市场：比特币会在 2024 年 12 月前达到 100,000 美元吗？（Yes/No）
```

### 多市场事件

当事件包含两个或更多市场时，会把相关的二元问题归入同一事件。部分多市场事件代表互斥结果。

预测市场会将这些互斥市场关联为一个**负风险组（Negative-risk Group）**。组内恰好有一个市场结算为 Yes，其余市场全部结算为 No。

```text
事件：谁将赢得 2024 年美国总统大选？
   ├── 市场：Donald Trump？（Yes/No）
   ├── 市场：Joe Biden？（Yes/No）
   ├── 市场：Kamala Harris？（Yes/No）
   └── 市场：其他？（Yes/No）
```

## 识别市场

每个市场和事件都有唯一的 slug，它会出现在预测市场 URL 中：

```text
https://polymarket.com/event/fed-decision-in-october
                            └── slug: fed-decision-in-october
```

你可以使用 slug 从 API 获取指定市场或事件：

```bash
# 通过 slug 获取事件
curl "https://gamma-api.polymarket.com/events?slug=fed-decision-in-october"
```

## 体育市场

对于体育市场，比赛开始后，尚未成交的限价单会自动取消，并在官方开赛时间清空订单簿。但实际开赛时间可能发生变化；如果比赛提前开始，订单可能无法及时清除。请在开赛前后密切关注订单状态。
