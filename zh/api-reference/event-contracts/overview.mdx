基础 URL 为 `https://api.dexbuilder.com`，API 前缀为 `/api/v4/event_contracts`。公开接口覆盖事件、市场、标签和市场数据；私有接口覆盖订单、仓位、资产、余额、费用、用户成交与结算。

列表响应使用 `{"items":[],"next_cursor":"opaque-cursor"}`。将 `next_cursor` 原样作为下一次请求的 `cursor`，为空时停止。请勿解码、修改、跨筛选条件复用或改用 offset。

事件和市场日期字段使用 Unix 秒；请求范围、价格历史、K 线以及账户/订单生命周期时间戳使用 Unix 毫秒。价格、数量、交易量、余额、费用和金额均为字符串，应使用十进制运算。

部分文本字段以稀疏语言对象返回，客户端应优先读取请求语言，缺失时回退至英语。常见错误：400 请求无效、401 认证无效、404 资源未知或不可见、503 上游市场数据依赖不可用。
