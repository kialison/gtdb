客户端操作使用 `op`，服务器主动推送的数据使用 `type`。请求信封通常包含毫秒时间戳 `t`、客户端请求 `id`、操作 `op`、频道 `ch`、`payload`，私有请求还包含 `auth`。

```json
{"t":1787026512123,"id":1001,"op":"subscribe","ch":"em.trades","payload":{"items":[{"condition_id":"gate_0xcondition"}]}}
```

确认响应会回显 `id`、`op` 与 `ch`，成功结果位于 `result`，错误位于 `err`。推送消息包含频道、类型、时间和结果对象。

`subscribe` 与 `unsubscribe` 支持 `payload.items`；私有频道还支持 `payload.all=true`。单次请求最多 100 个筛选项，每条连接最多 10,000 个活跃订阅。

WebSocket 不提供历史重放。应用应在连接前通过 REST 建立快照，并在重连后再次通过 REST 恢复。
