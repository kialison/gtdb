事件合约是一个允许用户交易现实世界事件结果的平台。你并非与平台对赌，而是在开放的点对点市场中与其他用户交易份额。价格反映市场对事件发生概率的集体判断。

## 价格就是概率

事件合约中的每份份额价格介于 0.00 至 1.00 美元。价格代表市场认为该结果发生的概率。例如，某事件的 Yes 份额价格为 0.65 美元，意味着市场认为该事件约有 65% 的概率发生。

## 抵押品与代币

事件合约使用 USD 作为抵押品。每组 Yes/No 份额都有足额抵押：

- 1 USDT 可创建一份 Yes 和一份 No
- 获胜份额可兑付 1.00 美元
- 失败份额价值为 0.00 美元

份额使用 [Gnosis Conditional Token Framework](https://docs.gnosis.io/conditionaltokens/) 的 ERC1155 标准表示，从而支持顺畅的链上交易与结算。

## 交易

事件合约通过点对点中央限价订单簿（CLOB）交易。你直接与其他用户交易，而不是与平台对赌。

- 当你认为市场低估概率时买入份额
- 当你认为市场高估概率时卖出份额
- 可在结算前随时卖出仓位，以锁定利润或控制损失

| 操作 | 适用情形 | 盈利条件 |
| --- | --- | --- |
| 买入 Yes | 你认为概率过低 | 事件发生 |
| 买入 No | 你认为概率过高 | 事件未发生 |
| 卖出 | 锁定收益或限制亏损 | 价格向有利方向变化 |

## 结算

事件结束后，市场通过 UMA Optimistic Oracle 结算：

1. 提议者提交结果并缴纳保证金
2. 进入任何人都可提出争议的挑战期
3. 如发生争议，由 UMA 代币持有人投票决定结果
4. 获胜代币可兑换 1 USDT

该社区驱动流程确保市场结算公平、准确。
