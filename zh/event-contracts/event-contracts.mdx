事件合约允许用户围绕现实世界事件的结果进行交易。用户不是与平台对赌，而是在开放的点对点市场中与其他用户买卖结果份额。价格反映了市场参与者对某个结果发生概率的集体判断。

## 价格即概率

事件合约中的每份结果份额价格介于 `0.00` 到 `1.00` 之间。价格可以理解为市场对该结果发生概率的估计。

例如，如果某个事件的「Yes」份额交易价格为 `$0.65`，可以理解为市场当前认为该事件发生的概率约为 65%。

## 抵押资产与结果代币

事件合约使用 USDT 作为抵押资产。每一组 Yes / No 结果都具有完整抵押：

- `1 USDT` 可对应生成 1 份 Yes 和 1 份 No；
- 获胜结果份额可按 `$1.00` 赎回；
- 失败结果份额价值归零。

结果份额基于 [Gnosis Conditional Token Framework](https://docs.gnosis.io/conditionaltokens/)（ERC-1155）表示，从而支持链上交易与结算。

## 交易

事件合约采用点对点中央限价订单簿（CLOB）。用户直接与其他用户成交，而不是与平台作为对手方交易。

- 当你认为市场低估某一结果概率时，可以买入对应份额；
- 当你认为市场高估某一结果概率时，可以卖出对应份额；
- 在市场最终结算之前，可以随时卖出持仓锁定收益或控制损失。

| 操作 | 适用场景 | 盈利场景 |
| --- | --- | --- |
| 买入 Yes | 认为当前概率偏低 | 事件发生 |
| 买入 No | 认为当前概率偏高 | 事件未发生 |
| 卖出 | 锁定收益或限制损失 | 价格朝有利方向变化 |

## 结算

事件结束后，市场通过 UMA Optimistic Oracle 完成结果确认：

1. 提议者提交结果并缴纳保证金；
2. 进入挑战期，其他参与者可以对结果提出异议；
3. 若发生争议，可进一步进入 UMA 投票流程；
4. 最终获胜结果代币可兑换为 `1 USDT`。

该机制用于在无需单一中心化裁定方的情况下完成市场结果确认。
