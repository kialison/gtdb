事件合约 API 使用标准 HTTP 状态码表示请求处理结果。以下错误可能出现在需要认证的接口中。

## `401 Unauthorized`

可能原因包括：未携带或使用无效 API Key、签名不正确、时间戳不符合要求，或签名内容与实际请求不一致。

排查时重点确认：

- 请求时间戳；
- 签名原文；
- Query 与 Body 是否和签名时完全一致；
- API Secret 是否正确。

## `429 Too Many Requests`

表示请求频率超过当前限频规则。建议客户端使用指数退避后重试，并避免短时间内重复请求同一资源。

## `503 Service Unavailable`

表示交易服务或依赖的上游服务暂时不可用。只读查询可在短暂等待后重试；交易类请求应先确认上一笔请求的最终状态，避免重复提交。

## 通用错误处理建议

建议记录 Request Method、Request Path、Query、请求时间戳、`trace_id`、HTTP 状态码以及服务端结构化错误码与错误信息。

<Warning>
排查日志时不要记录或对外暴露 API Secret、完整签名密钥或其他敏感认证信息。
</Warning>
