## 开发者快速入门

几分钟内发起第一次 API 请求。了解事件合约平台基础，获取市场数据、提交订单并赎回获胜仓位。

```bash API
curl -G "https://api.dexbuilder.com/api/v4/event_contracts/markets" \
  --data-urlencode "active=true" \
  --data-urlencode "closed=false" \
  --data-urlencode "limit=5"
```
