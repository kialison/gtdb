当使用的运行环境没有现成 SDK，或业务需要对请求、签名、分页和实时订阅进行更细粒度控制时，可以直接使用 API 接入。

REST API 返回原始 JSON 数据，并按业务提供独立接口。私有接口的认证和签名需要由接入方实现；不同接口的分页规则以具体页面说明为准。对于实时数据，需要连接相应的 WebSocket 服务并订阅所需频道。
