本页接口属于私有接口，需要认证。

## 查询持仓列表

```text
GET /api/v4/event_contracts/positions
```

支持 `event_id`、`condition_id`、`settlement_status`、`limit` 和 `cursor`。

持仓字段通常包含 `position_id`、`event_id`、`token_id`、`outcome`、`size`、`available_size`、`locked_size`、`avg_open_price`、`position_value`、`claimable_amount`、`settlement_status`、`won` 和 `updated_at`。

## 查询已结算持仓

```text
GET /api/v4/event_contracts/positions/settled
```

查询已结算的事件合约持仓。

## 查询个人成交

```text
GET /api/v4/event_contracts/usertrades
```

支持 `condition_id`、`from`、`to`、`sort_type`、`order_id`、`token_id`、`limit` 和 `cursor`。
