## 标签

```text
GET /api/v4/event_markets/tags
```

公开接口，支持 `limit` 和 `cursor`。

## K 线

```text
GET /api/v4/event_markets/tokens/{currency}/candlesticks
```

参数包括 `currency`、`interval`、可选的 `from` / `to` 和 `limit`。每根 K 线包含 `t`、`o`、`h`、`l`、`c`、`v`。

## 服务器时间

```text
GET /api/v4/event_markets/time
```

返回 `server_time`，单位为 Unix 毫秒。
