本页接口均为私有接口，需要认证。

## 账户资产

```text
GET /api/v4/event_contracts/assets
```

常见字段包括 `fund_total`、`prediction_market_asset`、`prediction_position_value`、`spot_usdt_balance` 和 `unclaimed_amount`。

## 资金流水

```text
GET /api/v4/event_contracts/account_book
```

支持 `limit` 与 `cursor`。

## 手续费

```text
GET /api/v4/event_contracts/fee/current
```

查询当前事件合约交易费率。

## 账户余额

```text
GET /api/v4/event_contracts/balance
```

## 资金流水

```text
GET /api/v4/event_contracts/fund_flows
```

## 资产划转

```text
POST /api/v4/event_contracts/transfer
```
