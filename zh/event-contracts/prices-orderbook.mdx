事件合约使用中央限价订单簿（CLOB）交易。价格并非由平台设定，而是由用户交易形成的供需决定。

## 价格就是概率

每份份额价格介于 0.00 至 1.00 美元，直接代表市场认为该结果发生的概率。页面通常显示最佳买卖价的中间价；如果价差大于 0.10 美元，则显示最近成交价。

| 价格 | 隐含概率 |
| --- | --- |
| 0.25 美元 | 25% |
| 0.50 美元 | 50% |
| 0.75 美元 | 75% |

## 订单簿

| 方向 | 说明 |
| --- | --- |
| 买盘 | 买单，即交易者愿意支付的最高价格 |
| 卖盘 | 卖单，即交易者愿意接受的最低价格 |

最高买价与最低卖价之差称为价差。价差越小，通常流动性越高。

## 订单类型

市价单按当前最佳可用价格立即成交；买入支付最低卖价，卖出获得最高买价。限价单只在指定价格或更优价格成交，可部分成交，未成交部分可随时取消。

## 交易如何执行

1. **链下撮合**——运营方撮合兼容订单
2. **链上结算**——已撮合交易通过智能合约结算

该设计兼具中心化撮合速度与链上结算安全性，资金始终由用户自行托管。
