事件合约按每笔交易收取费用，采用与份额价格和市场分类有关的对称公式。欢迎 Broker 与我们协商并定制费率结构，我们建议使用动态费率模型。下表为默认费率，除此之外不收取其他费用。

## 费用结构

```text
fee = C × feeRate × p × (1 - p)
```

其中，`C` 为交易份额数量，`p` 为份额价格。市场费率参数请参阅[市场详情](/zh/event-contracts/market-details)。

| 分类 | Maker/Taker 费率 |
| --- | --- |
| 加密货币 | 0.07 |
| 体育 | 0.05 |
| 金融 | 0.04 |
| 政治 | 0.04 |
| 经济 | 0.05 |
| 文化 | 0.05 |
| 天气 | 0.05 |
| 其他/综合 | 0.05 |
| 提及类 | 0.04 |
| 科技 | 0.04 |
| 地缘政治 | 0 |

费用以 USDT 计算，并随份额价格变化。USDT 费用金额围绕 50% 概率对称：以 30¢ 成交与以 70¢ 成交产生相同金额的费用。

<Info>
  由于费用曲线遵循 `p × (1 - p)`，费用在 `p = 0.5` 时最高，并在价格接近 0 或 1 时趋近于零。
</Info>

## 费用精度

费用四舍五入至小数点后 5 位，最小收费为 `0.00001` USDT。更小的金额会舍入为零，因此在价格接近两端时，极小额交易可能不产生费用。
