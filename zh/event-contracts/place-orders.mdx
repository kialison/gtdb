确认市场正在接受订单后，可针对结果代币下单。市场数据为公开信息；下单属于私有操作，需要认证。

生产环境 API 基础 URL 为 `https://api.dexbuilder.com`。认证机制尚未最终确定。请勿在客户端请求中复制内部网关身份请求头。

## 1. 读取市场限制

获取市场并从 `outcomes[].token_id` 中选择代币：

```bash cURL
curl "https://api.dexbuilder.com/api/v4/event_contracts/markets/<market_id>"
```

读取公开订单簿：

```bash cURL
curl "https://api.dexbuilder.com/api/v4/event_contracts/tokens/<token_id>/order_book?depth=20"
```

提交前，使用响应中的 `min_order_size` 与 `tick_size` 校验订单。

## 2. 提交订单

创建认证请求：

```bash cURL
curl -X POST "https://api.dexbuilder.com/api/v4/event_contracts/orders" \
  -H "Content-Type: application/json" \
  -H "<authentication-header>: <authentication-value>" \
  --data '{
    "token_id": "<token_id>",
    "side": "BUY",
    "price": "0.52",
    "size": "10",
    "total_cost": "5.20",
    "order_type": "LIMIT",
    "order_mode": "GTC",
    "client_order_id": "client-order-001",
    "post_only": false,
    "sell_all": false,
    "expire_time": 0
  }'
```

在公共认证方案最终确定前，上述认证占位符有意保持不可用。请勿发送内部网关身份请求头或其他内部请求头。

## 请求字段

| 字段 | 说明 |
| --- | --- |
| `token_id` | 要交易的结果代币 |
| `side` | 交易方向，如 `BUY` 或 `SELL` |
| `price` | 十进制字符串格式的限价 |
| `size` | 十进制字符串格式的订单数量 |
| `total_cost` | 十进制字符串格式的订单总成本 |
| `order_type` | 交易服务定义的订单类型 |
| `order_mode` | 交易服务定义的有效期或执行模式 |
| `client_order_id` | 可选的客户端幂等/引用 ID |
| `post_only` | 是否只允许增加流动性 |
| `sell_all` | 卖单是否使用全部可用仓位 |
| `expire_time` | 适用时的 Unix 秒格式到期时间 |

## 接受响应

成功请求会返回已接受的订单引用：

```json
{"order_id":"order-123","client_order_id":"client-order-001","status":"ACCEPTED","created_at":1782753357}
```

接受响应不代表订单已全部成交。请通过[管理订单](/zh/event-contracts/manage-orders)查询状态。

## 提交前检查

- 确认市场为 `accepting_orders: true`
- 使用市场 `outcomes` 数组中的 Token ID
- 确认订单数量满足 `min_order_size`
- 按市场 `tick_size` 对价格取整
- 将十进制值保留为字符串，避免浮点舍入误差
- 公共认证方案可用后，使用已认证的私有请求
