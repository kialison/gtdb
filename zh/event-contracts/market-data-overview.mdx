了解事件合约如何组织市场数据，以及应该从哪里开始。

获取市场数据，首先要确定应用所关注的事件、市场或结果。本节页面将引导你从这一选择出发，获得应用所需的数据。

## 理解数据模型

在事件合约中，一个事件包含一个或多个市场。每个市场都是一个可交易的问题，包含 YES 和 NO 两种结果；每种结果都有独立的 Token ID。读取价格或订单簿时，请使用对应结果的 Token ID。

![图片](/images/image-6.png "图片")

<Steps>
  <Step title="发现事件">
    浏览进行中的事件、按主题搜索，或通过事件合约 URL 直接获取事件。
  </Step>
  <Step title="选择市场">
    查看事件包含的市场，并选择应用关心的具体问题。
  </Step>
  <Step title="选择结果">
    选择 YES 或 NO 并保存其 Token ID。读取价格、访问订单簿和提交订单时都将使用该 ID。
  </Step>
  <Step title="读取或订阅数据">
    使用已获取的标识符，查询或订阅应用所需的市场数据。
  </Step>
</Steps>
