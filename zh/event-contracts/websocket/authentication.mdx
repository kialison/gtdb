只有私有频道需要认证，公共行情频道可以直接订阅。

## API Key 签名

在 `auth` 中传入 API Key 和本地生成的 HMAC-SHA512 签名：

```json
{"method":"api_key","key":"YOUR_API_KEY","sign":"HEX_SIGNATURE"}
```

直接订阅私有频道时，签名原文为：

```text
channel=ec.orders&event=subscribe&time=1720000000123
```

使用 API Secret 作为 HMAC-SHA512 密钥并输出十六进制摘要。API Secret 不能发送到服务端。

## 私有订阅示例

```json
{
  "t": 1720000000123,
  "id": "private-1",
  "op": "subscribe",
  "ch": "ec.orders",
  "payload": {"all": true},
  "auth": {"method":"api_key","key":"YOUR_API_KEY","sign":"HEX_SIGNATURE"}
}
```

`ec.usertrades`、`ec.positions` 和 `ec.settlements` 使用相同的 API Key 认证方式。

## 连接级认证

也可以先使用 `server.sign` 一次性认证连接，之后订阅私有频道时不需要重复传入 `auth`：

```json
{
  "t": 1720000000123,
  "id": "auth-1",
  "op": "auth",
  "ch": "server.sign",
  "payload": {
    "method": "api_key",
    "key": "YOUR_API_KEY",
    "sign": "HEX_SIGNATURE"
  }
}
```

收到成功 ACK 后，可以在同一连接上订阅私有频道。签名在本地使用 API Secret 生成，API Secret 不会发送到服务端。
