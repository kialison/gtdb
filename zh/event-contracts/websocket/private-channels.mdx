私有频道仅返回当前认证用户的数据。可以在首次私有订阅时携带认证信息，也可以先使用 `server.sign` 预认证。

私有频道支持按 `condition_id` 过滤，或使用：

```json
{"all":true}
```

订阅当前账户全部相关更新。

## 订单 `ec.orders`

订单更新包含：

- `order_id`
- `client_order_id`
- `event_id`
- `condition_id`
- `token_id`
- `side`
- `order_mode`
- `order_type`
- `px`
- `qty`
- `filled_qty`
- `left_qty`
- `status`
- `created_ts`
- `updated_ts`

订单状态包括 `PROCESSING`、`OPEN`、`CANCELLING`、`MATCHED`、`CANCELED` 和 `FAILED`。

## 用户成交 `ec.usertrades`

返回当前用户成交，包括 `trade_id`、`order_id`、`condition_id`、`token_id`、`side`、`role`、`px`、`qty`、`fee_rate`、`status` 和 `created_ts`。

`role` 为 `MAKER` 或 `TAKER`；状态通常为 `MATCHED` 或 `CONFIRMED`。

## 持仓 `ec.positions`

持仓推送可包含：

- `position_id`
- `event_id`
- `token_id`
- `outcome`
- `qty`
- `avg_px`
- `settle_status`
- `locked_qty`
- `available_qty`
- `claimable_amount`
- `updated_ts`

## 结算 `ec.settlements`

结算更新包含 `position_id`、`event_id`、`condition_id`、`winning_outcome`、`is_winner`、`claimable_amount` 和 `created_ts`。

<Note>
私有频道不会在订阅后自动返回完整账户快照。需要完整当前状态时，应先调用对应 REST 接口，再用 WebSocket 接收后续增量变化。
</Note>
