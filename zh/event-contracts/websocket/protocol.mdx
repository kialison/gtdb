事件合约 WebSocket 使用 v2 JSON 消息结构。客户端操作使用 `op`，服务端主动推送使用 `type`。

## 客户端请求

```json
{
  "t": 1787026512123,
  "id": 1001,
  "op": "subscribe",
  "ch": "ec.trades",
  "payload": {
    "items": [{"condition_id":"gate_0xcondition"}]
  }
}
```

| 字段 | 说明 |
| --- | --- |
| `t` | 客户端 Unix 毫秒时间戳 |
| `id` | 客户端请求 ID，用于关联响应 |
| `op` | `subscribe`、`unsubscribe`、`auth` 或 `ping` |
| `ch` | 频道名称 |
| `payload` | 操作参数 |
| `auth` | 首次私有操作时携带的认证信息 |

## 成功 ACK

```json
{
  "t": 1787026512150,
  "id": 1001,
  "trace_id": "7906cdf3f7dd1ef35f8ef5808cf58da8",
  "op": "subscribe",
  "ch": "ec.trades",
  "err": null,
  "result": {"status":"success"}
}
```

## 错误 ACK

```json
{
  "id": 1001,
  "op": "subscribe",
  "ch": "ec.depth",
  "err": {"code":2,"msg":"invalid depth level"},
  "result": {"status":"fail"}
}
```

客户端应优先根据 `err.code` 处理错误，不要依赖完整错误文本。

## 服务端推送

```json
{
  "t": 1787026512150,
  "type": "update",
  "ch": "ec.trades",
  "err": null,
  "result": {
    "condition_id":"gate_0xcondition",
    "token_id":"gate_token_id",
    "side":"BUY",
    "px":"0.45",
    "qty":"10",
    "ts":1787026512027
  }
}
```

`type` 常见值为 `snapshot` 或 `update`。

## 订阅参数

支持：

```json
{"items":[{"token_id":"gate_token_id"}]}
```

私有频道也可使用：

```json
{"all":true}
```

规则：

- `items` 与 `all` 不能同时出现；
- 单次最多提交 100 个订阅项；
- 单连接最多支持 10,000 个有效订阅；
- 公共频道不支持 `all=true`；
- 取消订阅使用与订阅相同的 item 结构。
