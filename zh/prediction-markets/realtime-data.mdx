预测市场提供多种实时数据流，用于在 Market 状态、价格或关联数据发生变化时及时更新应用。私有订单与成交更新请查看「实时订单更新」。

## Market Stream

Market Stream 用于同步订单簿和交易状态变化。

```text API
wss://ws-subscriptions-clob.polymarket.com/ws/market
```

<Note>
  Market WebSocket 使用应用层心跳。每 10 秒发送文本帧 `PING`，服务端返回 `PONG`。
</Note>

连接后发送 `market` 订阅消息：

```json
{
  "assets_ids": ["<token_id>"],
  "type": "market"
}
```

### 标准 Market 事件

主要事件包括：

| `event_type` | 说明 |
| --- | --- |
| `book` | 完整订单簿快照 |
| `price_change` | 价格与最佳买卖价变化 |
| `last_trade_price` | 最近成交价 |
| `tick_size_change` | 最小价格变动单位变化 |

订单簿示例：

```json
{
  "event_type": "book",
  "market": "0x747dc809...",
  "asset_id": "1075058827...",
  "timestamp": "1782753357257",
  "hash": "0xabc123…",
  "bids": [
    { "price": "0.08", "size": "33343.4" }
  ],
  "asks": [
    { "price": "0.09", "size": "163939.58" }
  ]
}
```

启用 `custom_feature_enabled` 后，可以额外接收最佳买卖价、新 Market 与 Market 结算等事件：

```json
{
  "assets_ids": ["<token_id>"],
  "type": "market",
  "custom_feature_enabled": true
}
```

可在不重建连接的情况下动态增加或移除 Token：

<Tabs>
  <Tab title="订阅">
    ```json
    {
      "assets_ids": ["<new_token_id>"],
      "operation": "subscribe"
    }
    ```
  </Tab>
  <Tab title="取消订阅">
    ```json
    {
      "assets_ids": ["<token_id>"],
      "operation": "unsubscribe"
    }
    ```
  </Tab>
</Tabs>

## Sports Stream

体育实时流用于同步比赛状态、比分、节次和是否结束等信息。

```text API
wss://sports-api.polymarket.com/ws
```

<Note>
  服务端每 5 秒发送文本 `ping`，客户端应在 10 秒内返回 `pong`。
</Note>

连接成功后无需发送订阅消息，服务端会直接推送比赛更新。

```json
{
  "gameId": "5127839",
  "leagueAbbreviation": "NBA",
  "homeTeam": "Los Angeles Lakers",
  "awayTeam": "Boston Celtics",
  "status": "InProgress",
  "live": true,
  "ended": false,
  "score": "98-94",
  "period": "Q4",
  "elapsed": "05:12"
}
```

<Warning>
  体育数据仅用于信息展示，可能存在延迟、缺失或错误，不应单独作为交易决策依据。
</Warning>

### 常见比赛阶段

| 值 | 含义 |
| --- | --- |
| `1H`, `2H` | 上半场 / 下半场 |
| `1Q`–`4Q` | 第 1–4 节 |
| `HT` | 半场结束 |
| `FT` | 常规时间结束 |
| `FT OT` | 加时结束 |
| `FT NR` | 无结果结束 |

不同体育项目的 `status` 取值不同，应按服务端返回值处理，例如 `Scheduled`、`InProgress`、`Final`、`Postponed`、`Canceled` 等。

## RTDS 实时数据服务

RTDS（Real-Time Data Service）通过统一实时连接提供参考价格等数据。

```text API
wss://ws-live-data.polymarket.com
```

RTDS 使用应用层心跳，每 5 秒发送一次 `PING` 以保持连接。

### 加密资产价格

不同数据源使用不同 symbol 格式：

| Source | 示例 |
| --- | --- |
| Binance | `btcusdt`, `ethusdt`, `solusdt`, `xrpusdt` |
| Chainlink | `btc/usd`, `eth/usd`, `sol/usd`, `xrp/usd` |

订阅示例：

```json
{
  "action": "subscribe",
  "subscriptions": [
    {
      "topic": "crypto_prices",
      "type": "update",
      "filters": "btcusdt,ethusdt"
    },
    {
      "topic": "crypto_prices_chainlink",
      "type": "*",
      "filters": "[{\"symbol\":\"eth/usd\"}]"
    }
  ]
}
```

返回示例：

```json
{
  "topic": "crypto_prices",
  "type": "update",
  "timestamp": 1782753357257,
  "payload": {
    "symbol": "btcusdt",
    "timestamp": 1782753357213,
    "value": 67334.5
  }
}
```

### 股票及其他资产价格

`equity_prices` 可提供基于 Pyth Network 的股票、ETF、外汇、贵金属及商品参考价格。

```json
{
  "action": "subscribe",
  "subscriptions": [
    {
      "topic": "equity_prices",
      "type": "*",
      "filters": "[{\"symbol\":\"AAPL\"}]"
    }
  ]
}
```

价格事件可能同时提供 `value` 与 `full_accuracy_value`。存在 `full_accuracy_value` 时，应优先使用该字符串以避免精度损失。

```json
{
  "topic": "equity_prices",
  "type": "update",
  "timestamp": 1782753357257,
  "payload": {
    "symbol": "aapl",
    "timestamp": 1782753357213,
    "value": 189.42,
    "full_accuracy_value": "189.4217",
    "received_at": 1782753357220,
    "is_earliest_forward": false
  }
}
```

订阅某个 symbol 后，服务可能先发送一段历史 Snapshot，再持续推送实时更新，接入方可以用 Snapshot 初始化本地状态。

## 连接恢复建议

实时连接断开后应：

1. 使用退避策略重新连接；
2. 恢复全部订阅；
3. 对需要完整状态的业务重新通过 REST API 获取快照；
4. 使用业务 ID 与时间戳对重放或重复消息去重。
