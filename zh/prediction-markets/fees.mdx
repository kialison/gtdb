预测市场手续费按每笔成交计算，具体费率可根据市场分类和业务配置确定。

## 手续费计算

动态费率模式下，手续费可按以下公式计算：

```text
fee = C × feeRate × p × (1 - p)
```

其中：

- `C`：成交份额数量；
- `feeRate`：对应市场分类的费率参数；
- `p`：结果份额成交价格。

因为公式中包含 `p × (1 - p)`，手续费在价格接近 `0.5` 时较高，在价格接近 `0` 或 `1` 时逐渐降低。

## 默认分类费率

| 市场分类 | Maker / Taker Fee Rate |
| --- | --: |
| Crypto | `0.07` |
| Sports | `0.05` |
| Finance | `0.04` |
| Politics | `0.04` |
| Economics | `0.05` |
| Culture | `0.05` |
| Weather | `0.05` |
| Other / General | `0.05` |
| Mentions | `0.04` |
| Tech | `0.04` |
| Geopolitics | `0` |

实际生效费率以对应市场接口或账户费率接口返回值为准。

## 对称性

动态费率关于 50% 概率对称。例如在其他条件相同的情况下，价格为 `0.30` 和 `0.70` 的成交，其手续费金额相同。

## 精度

手续费金额保留到 5 位小数，最小计费精度为：

```text
0.00001 USDT
```

小于最小精度的费用可能四舍五入为 `0`。

<Note>
  Builder 或 Broker 的实际费率结构可能根据业务合作方案进行配置，对外展示时应以当前市场和账户实际返回的数据为准。
</Note>
