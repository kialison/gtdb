价格如何形成，以及订单簿如何实现点对点交易。

事件市场采用中央限价订单簿（CLOB）进行交易。价格并非由平台设定，而是由用户的供需关系在彼此交易中自然形成。

## 价格即概率

Polymarket 上每份份额的价格介于 $$0.00 到 $$1.00 之间。价格直接反映了市场对该结果发生概率的判断。

显示的价格是买卖价差（bid-ask spread）的中点。如果价差超过 \$0.10，则显示最新成交价。

| 价格 | 隐含概率 |
| --- | --- |
| \$0.25 | 25% 概率 |
| \$0.50 | 50% 概率 |
| \$0.75 | 75% 概率 |

### 示例

如果 "Yes" 的最高买价为 $$0.34，最低卖价为 $$0.40：

```text
显示价格 = ($0.34 + $0.40) / 2 = $0.37（37% 概率）
```

显示的价格是买卖价差的中点。如果价差超过 \$0.10，则显示最新成交价。

## 订单簿

订单簿是某个市场中所有未成交买卖订单的列表。它分为两个方向：

| 方向 | 说明 |
| --- | --- |
| 买方出价（Bids） | 买入订单，即交易者愿意支付的最高价格 |
| 卖方报价（Asks） | 卖出订单，即交易者愿意接受的最低价格 |

价差是最高买价与最低卖价之间的差距。价差越小，说明市场流动性越好。

## 订单类型

### 市价单

以当前最优可用价格立即成交。适用于希望即时成交且愿意承担价差的场景。

- **买入：** 你支付最低卖价
- **卖出：** 你收到最高买价

### 限价单

仅在你指定的价格或更优价格成交。适用于希望控制价格且愿意等待的场景。

- 你的订单会留在订单簿中，直到有人与你成交
- 随着不同交易者匹配你的订单，订单可以部分成交
- 你可以随时取消未成交的订单

## 交易如何运作

事件市场的 CLOB 是混合去中心化的：

1. **链下撮合** — 由操作员匹配兼容的订单
2. **链上结算** — 匹配成功的交易通过智能合约进行结算
