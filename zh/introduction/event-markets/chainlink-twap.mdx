直接使用或通过事件市场 RTDS 使用 Chainlink 计算的 TWAP 价格。

时间加权平均价格（TWAP）表示资产在一个回顾窗口内的价格。本页面涵盖 Chainlink 计算的 30 秒和 60 秒 TWAP。

## 使用事件市场 RTDS

RTDS 是推荐的生产集成方式。它无需身份认证即可转发 Chainlink 计算的主网 TWAP 更新。使用小写、斜杠分隔的符号，例如 `btc/usd`。省略符号筛选器以接收每个可用的交易对。

```text API
wss://ws-live-data.polymarket.com
```

<Note>
  RTDS 使用应用层心跳。每 5 秒发送一次文本帧 `PING` 以保持连接。
</Note>

当您需要更低级别的控制时，直接连接到 RTDS。发送订阅帧以获取您需要的回顾窗口：

```json
{
  "action": "subscribe",
  "subscriptions": [
    {
      "topic": "crypto_prices_twap_thirty",
      "type": "update",
      "filters": "{\"symbol\":\"btc/usd\"}"
    },
    {
      "topic": "crypto_prices_twap_sixty",
      "type": "update",
      "filters": "{\"symbol\":\"btc/usd\"}"
    }
  ]
}
```

| 回顾窗口 | RTDS 话题 |
| --- | --- |
| 30 秒 | `crypto_prices_twap_thirty` |
| 60 秒 | `crypto_prices_twap_sixty` |

`filters` 必须使用上面所示的精确紧凑 JSON 格式，包含一个小写符号且没有空格，例如 `{"symbol":"btc/usd"}`。省略它以接收每个可用的符号。如果您需要一个窗口的多个符号，请省略 `filters` 并在应用中通过 `payload.symbol` 筛选更新。

<Accordion title="示例输出">
  ```json
  {
    "topic": "crypto_prices_twap_thirty",
    "type": "update",
    "timestamp": 1785178800123,
    "payload": {
      "symbol": "btc/usd",
      "value": 65000.5,
      "full_accuracy_value": "65000500000000000000000",
      "timestamp": 1785178800009,
      "window_s": 30
    }
  }
  ```
</Accordion>

`full_accuracy_value` 是精确的带符号 E18 定点值。使用整数或十进制运算将其除以 10^18。数字 `value` 仅为了方便显示而提供。

使用 `payload.timestamp` 作为 Chainlink 观测时间。外部 `timestamp` 是发布者将更新提交给 RTDS 的时间。直接客户端必须在断开连接后重新连接并重新订阅。

### 选择窗口

为每个订阅选择 30 或 60 秒。如果需要两者，请订阅两次。

### 流行为

订阅从下一次更新开始。断开连接后没有快照、历史数据或重放。

## 使用 Chainlink Data Streams

如需直接访问主网、获取流式传输前的最新报告或获取原始签名报告，请使用 Chainlink Data Streams。在 [Chainlink Data Streams 目录](https://docs.chain.link/data-streams/crypto-streams)中找到资产的 TWAP: 30s 或 TWAP: 60s 代码，然后复制其数据源 ID。仅在受信任的后端运行此操作。切勿将 Chainlink 凭据暴露给浏览器或移动应用。

<Steps>
  <Step title="安装并连接">
    使用 Node.js 20\+ 和 TypeScript 5.3\+。安装 Chainlink SDK：

    ```bash
    npm install --save-exact @chainlink/data-streams-sdk@1.2.1
    ```

    创建主网客户端：

    ```typescript
    import {
      createClient,
      decodeReport,
      type Report,
    } from "@chainlink/data-streams-sdk";
    
    type TwapFeed = {
      symbol: string;
      windowSeconds: 30 | 60;
    };
    
    function requireEnv(name: string): string {
      const value = process.env[name];
    
      if (!value) {
        throw new Error(`Missing required environment variable: ${name}`);
      }
    
      return value;
    }
    
    const client = createClient({
      apiKey: requireEnv("CHAINLINK_CLIENT_ID"),
      userSecret: requireEnv("CHAINLINK_CLIENT_SECRET"),
      endpoint: "https://api.dataengine.chain.link",
      wsEndpoint: "wss://ws.dataengine.chain.link",
      haMode: false,
    });
    ```

    SDK 对每个请求进行签名。保持服务器时钟与 Chainlink 服务器时间在五秒以内。
  </Step>
  <Step title="映射并解码报告">
    将目录中的数据源 ID 存储在服务器端环境变量中，然后将每个 ID 映射到其资产和窗口。保留签名的 E18 值，而不是将其转换为 JavaScript `number`：

    ```typescript
    const feeds = new Map<string, TwapFeed>([
      [
        requireEnv("CHAINLINK_TWAP_30S_FEED_ID").toLowerCase(),
        { symbol: "btc/usd", windowSeconds: 30 },
      ],
      [
        requireEnv("CHAINLINK_TWAP_60S_FEED_ID").toLowerCase(),
        { symbol: "btc/usd", windowSeconds: 60 },
      ],
    ]);
    
    const E18 = 10n ** 18n;
    
    function formatE18(value: bigint): string {
      const sign = value < 0n ? "-" : "";
      const absolute = value < 0n ? -value : value;
      const whole = absolute / E18;
      const fraction = (absolute % E18)
        .toString()
        .padStart(18, "0")
        .replace(/0+$/, "");
    
      return `${sign}${whole}${fraction ? "." + fraction : ""}`;
    }
    
    function readTwap(report: Report) {
      const feed = feeds.get(report.feedID.toLowerCase());
    
      if (!feed) {
        throw new Error(`Unexpected Chainlink feed ID: ${report.feedID}`);
      }
    
      const decoded = decodeReport(report.fullReport, report.feedID);
    
      if (decoded.version !== "v2") {
        throw new Error(`Expected a V2 report, received ${decoded.version}`);
      }
    
      return {
        feedID: report.feedID,
        symbol: feed.symbol,
        windowSeconds: feed.windowSeconds,
        value: formatE18(decoded.price),
        observedAt: new Date(report.observationsTimestamp * 1_000).toISOString(),
      };
    }
    ```
  </Step>
  <Step title="获取最新 TWAP">
    在流式传输之前获取每个数据源的最新报告：

    ```typescript
    const latestReports = await Promise.all(
      [...feeds.keys()].map((feedID) => client.getLatestReport(feedID)),
    );
    
    for (const report of latestReports) {
      console.log(readTwap(report));
    }
    ```

    <Accordion title="输出: Chainlink TWAP">
      ```json
      {
        "feedID": "0x<mainnet-feed-id>",
        "symbol": "btc/usd",
        "windowSeconds": 30,
        "value": "65000.5",
        "observedAt": "2026-07-27T19:00:00.000Z"
      }
      ```
    </Accordion>
  </Step>
  <Step title="流式传输更新">
    订阅选定的数据源 ID：

    ```typescript
    const stream = client.createStream([...feeds.keys()]);
    
    stream.on("report", (report) => {
      try {
        console.log(readTwap(report));
      } catch (error) {
        console.error("Failed to decode Chainlink report:", error);
      }
    });
    
    stream.on("disconnected", () => {
      console.warn("Chainlink stream disconnected");
    });
    
    stream.on("reconnecting", ({ attempt, delayMs }) => {
      console.warn(`Reconnecting: attempt ${attempt} in ${delayMs}ms`);
    });
    
    stream.on("error", (error) => {
      console.error("Chainlink stream error:", error);
    });
    
    await stream.connect();
    
    process.once("SIGINT", async () => {
      await stream.close();
      process.exit(0);
    });
    ```

    SDK 自动进行身份验证和重新连接。监控 `error`、`disconnected` 和 `reconnecting`。如果重试次数耗尽，请重新启动流。
  </Step>
</Steps>

### 读取 Chainlink 报告

TWAP 数据源使用 Chainlink 报告格式 V2。`decodeReport()` 将编码的 `benchmarkPrice` 公开为 `decoded.price`。

| 值 | 使用方法 |
| --- | --- |
| `report.feedID` | 将报告映射到其资产和 30 秒或 60 秒窗口 |
| `decoded.price` | 将精确的带符号 E18 值保留为 `bigint` 或十进制字符串 |
| `report.validFromTimestamp` | 以 Unix 秒读取最早的有效时间 |
| `report.observationsTimestamp` | 以 Unix 秒读取 Chainlink 观测时间 |
| `decoded.expiresAt` | 以 Unix 秒读取报告过期时间 |
| `report.fullReport` | 访问原始签名的 Chainlink 报告 |

报告不包含符号或窗口标签。自行维护该映射，切勿从更新频率推断窗口，并使用 `observationsTimestamp` 进行新鲜度检查。

`decodeReport()` 解析报告字段，但不验证 DON 签名。在将报告用于结算或其他信任敏感操作之前，请遵循 Chainlink 的验证要求。

### 查找数据源 ID

打开 [Chainlink Data Streams 目录](https://docs.chain.link/data-streams/crypto-streams) 并搜索您需要的资产和窗口，例如 BTC / USD - TWAP: 30s 或 BTC / USD - TWAP: 60s。从产品页面复制数据源 ID，并将其与您现有的标准或赞助 Data Streams 凭据一起使用。

| REST URL | WebSocket URL |
| --- | --- |
| `https://api.dataengine.chain.link` | `wss://ws.dataengine.chain.link` |

30 秒和 60 秒值是回顾窗口，而不是发布频率。Chainlink 计算并签署 TWAP。定义新鲜度阈值和报告间隔的备用方案，而不是试图从传入的更新中推断计算。Chainlink 目前不发布自定义数据源的采样边界、权重、舍入或缺失输入行为，因此在没有 Chainlink 规范的情况下不要独立复制该值。
