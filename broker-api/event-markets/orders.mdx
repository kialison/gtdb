Order endpoints are private and require gateway authentication. Do not send internal account-identity headers.

```http
POST /api/v4/event_markets/orders
GET /api/v4/event_markets/orders
GET /api/v4/event_markets/orders/{order_id}
DELETE /api/v4/event_markets/orders/{order_id}
DELETE /api/v4/event_markets/orders
```

The public order request includes `client_order_id`, `token_id`, `side`, `price`, `size`, `order_type`, `order_mode`, `expire_time`, `total_cost`, `sell_all`, and `post_only`.

An accepted order is not necessarily filled. Query the order and user-trade endpoints for current state.
