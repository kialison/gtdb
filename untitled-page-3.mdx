---
title: "核心能力"
description: "在 DexBuilder 上构建产品可使用的交易、资产、运营与开发者能力。"
---

DexBuilder 旨在减少项目团队需要分别搭建和维护的独立系统数量。平台将去中心化交易产品的核心能力组织为四个相互连接的部分。

## 交易体验

- 订单簿行情与实时市场数据流；
- 专业订单类型与批量订单管理；
- 单向持仓与双向持仓模式；
- 全仓与逐仓保证金模式；
- 标记价格、资金费率、强平、保险基金与 ADL 信息；
- 账户、成交、平仓与交易费率历史。

## 账户、资产与结算

- 基于钱包的用户授权；
- 账户注册与账户状态查询；
- 充值、提现与内部划转；
- 账户流水与对账流程；
- 盈亏与 Builder 收入结算。

## Builder 运营

- 项目注册与 Builder 信息；
- 用户注册与已授权用户数据；
- 手续费设置与订单归因；
- 活动与推荐计划；
- 限定在项目范围内的管理数据访问。

## 开发者平台

- 公开及认证 REST 操作；
- WebSocket 接入指南；
- HMAC-SHA512 请求签名与凭证权限；
- 幂等操作模式；
- 完整中英文文档；
- 用于客户端生成和校验的 OpenAPI 定义；
- 故障排查与生产上线指南。

## 接入边界

每个 API 页面会明确相应操作的方法、路径、参数位置、请求体、响应结构与认证要求。应用不应只根据请求已提交就推断状态变化；应通过相应查询接口确认订单、余额、仓位、账本记录与结算状态。
