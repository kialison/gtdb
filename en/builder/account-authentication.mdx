DexBuilder provides the user-account and authentication capabilities required for sign-in, account creation, account identification, and trading authorization.

## Account flow

```text
User opens the DEX
      ↓
Sign in / Connect wallet
      ↓
Create or identify account
      ↓
Complete required authentication
      ↓
Use assets and trading
```

## Supported capabilities

- User sign-in and account identification
- Wallet connection and authorization
- Trading-account creation
- Account-status queries
- Authentication-state management
- Cross-device account-state synchronization
- Error and authentication prompts

## API authentication

REST API and WebSocket integrations must follow the authentication and signing rules for the corresponding product.
