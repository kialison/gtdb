## Broker capabilities

When a Builder is created, DexBuilder assigns project-level identifiers that associate the project with its users, trading activity, fee configuration, and operational data.

- **Project and user attribution**
- **Fee and revenue configuration**
- **Project-level data and operations**
- **API and WebSocket integration**

## Supported products

| Product | Description |
| --- | --- |
| PerpDEX | Perpetual markets, orders, positions, accounts, and related trading capabilities |
| Prediction Markets | Outcome markets, order books, trading, positions, and settlement |
| Event Contracts | Event-based contract markets, trading, real-time data, and settlement |
| Multi-product DEX | Enable multiple products in one DEX |

## How to use DexBuilder

DexBuilder provides the complete DEX product and management experience. After creating a Builder, configure products, branding, markets, accounts, fees, and operations before launch.

For integrations with other systems, use the REST API and WebSocket documentation under **API Reference**.
