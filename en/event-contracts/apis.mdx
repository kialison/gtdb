## REST API

Use REST API for:

- events and markets;
- token prices, ticker, order book, price history, and candlesticks;
- order placement and management;
- positions and personal trades;
- account assets and account book;
- fees and claims.

## WebSocket

Use WebSocket for real-time public market data and authenticated user updates.

## Authentication

Private APIs require the credentials and signing method documented for the corresponding endpoint.
