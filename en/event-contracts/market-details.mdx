After selecting a Market through Discover Markets, use the Market Detail endpoint to read its full properties. This is public market data and does not require authentication.

Production Base URL:

```text
https://api.dexbuilder.com
```

## Query a Market

By Market ID:

```bash cURL
curl "https://api.dexbuilder.com/api/v4/event_contracts/markets/<market_id>"
```

By slug:

```bash cURL
curl "https://api.dexbuilder.com/api/v4/event_contracts/markets/slug/<market_slug>"
```

## Field Reference

| Field | Description |
| --- | --- |
| `market_id` | Unique Market identifier |
| `event_id` | Parent Event ID |
| `slug` | Market slug |
| `question` | Multilingual question object |
| `condition_id` | Settlement Condition ID |
| `outcomes` | Outcome array; each item contains `token_id` and `outcome` |
| `status` | Current Market status |
| `closed` | Whether the Market is closed |
| `accepting_orders` | Whether the Market currently accepts orders |
| `enable_order_book` | Whether the order book is enabled |
| `best_bid`, `best_ask` | Current best bid and ask |
| `last_trade_price` | Latest trade price |
| `min_order_size` | Minimum order size |
| `tick_size` | Minimum price increment |
| `neg_risk` | Whether Negative Risk settlement is used |
| `start_date`, `end_date` | Market time fields, Unix seconds |
| `resolved_at` | Resolution time after settlement |
| `winning_outcome`, `winning_token_id` | Winning outcome and corresponding Token ID |
| `tags` | Tags associated with the Market |

## Using Outcome Tokens

After obtaining a Token ID from `outcomes[].token_id`, you can call the price, Ticker, and order-book endpoints:

```bash cURL
TOKEN_ID="<token_id>"

curl "https://api.dexbuilder.com/api/v4/event_contracts/tokens/$TOKEN_ID/order_book?depth=20"
curl "https://api.dexbuilder.com/api/v4/event_contracts/tokens/$TOKEN_ID/price"
curl "https://api.dexbuilder.com/api/v4/event_contracts/tokens/$TOKEN_ID/ticker"
```

The API returns Token IDs directly in the `outcomes` array, so no additional parsing of JSON-string Token lists is required.

## Query the Parent Event

Use the returned `event_id` to query the parent Event:

```bash cURL
curl "https://api.dexbuilder.com/api/v4/event_contracts/events/<event_id>"
```

Public Market data does not require authentication. Private order, position, and account endpoints do require authentication.
