This page explains how to observe trading activity, capital distribution, and position data in Event Contracts. Before starting, use Discover Markets to obtain the Market's `condition_id` and `event_id`.

```bash
CONDITION_ID="<condition_id>"
EVENT_ID="<event_id>"
```

## Recent Trades

Use this endpoint to inspect recently matched trades, including side, price, quantity, outcome, wallet, and timestamp.

```bash API
curl "https://data-api.polymarket.com/trades?market=$CONDITION_ID&limit=1"
```

## Open Interest

Use this endpoint to inspect the current value of open positions for one or more Markets.

```bash API
curl "https://data-api.polymarket.com/oi?market=$CONDITION_ID"
```

<Accordion title="Example Response">
  ```json
  [
    {
      "market": "0x747dc809fb79e1b05be09c42d6179459a58de2ef3e40f02484a4e1260f741f7",
      "value": 7484304.679057
    }
  ]
  ```
</Accordion>

## Market Holders

View the main public holders of different Outcome Tokens.

```bash API
curl "https://data-api.polymarket.com/holders?market=$CONDITION_ID&limit=1"
```

<Accordion title="Example Response">
  ```json
  [
    {
      "token": "107505882767731489358349912513945399560393482969656700824895970500",
      "holders": [
        {
          "proxyWallet": "0xaf23273e03A924A257e0D6bEae7133CF9D32377f",
          "amount": 894254.445452,
          "outcomeIndex": 0,
          "name": "5Cssss"
        }
      ]
    }
  ]
  ```
</Accordion>

## Real-Time Event Volume

Aggregate trading volume by Event and inspect the breakdown by Market.

```bash API
curl "https://data-api.polymarket.com/live-volume?id=$EVENT_ID"
```

<Accordion title="Example Response">
  ```json
  [
    {
      "total": 60773073.437817,
      "markets": [
        {
          "market": "0x747dc809fb79e1b05be09c42d6179459a58de2ef3e40f02484a4e1260f7",
          "value": 34909514.911729
        }
      ]
    }
  ]
  ```
</Accordion>

<Note>
Some analytics endpoints come from external data services. In production integrations, distinguish the DexBuilder Event Contracts API from external data sources and do not treat external endpoints as part of the DexBuilder API contract.
</Note>
