DexBuilder Event Contracts provides an order-book trading experience for event-driven outcome markets.

This documentation explains how markets are structured, how users trade outcome tokens, how positions and settlement work, and how applications can integrate through REST API and WebSocket.

## What you can build

- Discover active events and markets
- Display market rules, outcomes, prices, liquidity, and trading status
- Place and manage orders
- Track positions, trades, and account activity
- Follow market resolution and settlement
- Subscribe to real-time updates
