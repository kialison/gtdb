---

Event Contracts API provides REST API for market discovery, market data, orders, positions, account data, and claims, plus WebSocket for real-time updates.

## Base URL

```text
https://api.dexbuilder.com
```

REST endpoints use the `/api/v4/event_contracts` prefix.

Public market data does not require account authentication. Private order, position, account, and claim operations require the documented authentication flow.
