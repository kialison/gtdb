title: "Public Channels"
description: "Public Event Contracts API WebSocket channels."
---

Public channels do not require authentication.

**Endpoint**

```text
wss://broker.dexbuilder.com/ws/dex-builder/event-contracts
```

## Subscribe

```json
{
  "t": 1720000000123,
  "id": "sub-1",
  "op": "subscribe",
  "ch": "ec.trades",
  "payload": {
    "items": [
      {
        "condition_id": "ge_condition-1"
      }
    ]
  }
}
```

The server returns an acknowledgement first. Channels with cached state may send a `snapshot`; `trades` is delivered as `update` events. Subsequent messages use `type: "update"`.

## `ec.trades`

Subscribe with `condition_id`.

**Response example**

```json
{
  "t": 1720000000124,
  "trace_id": "trace-1",
  "type": "update",
  "ch": "ec.trades",
  "err": null,
  "result": {
    "condition_id": "ge_condition-1",
    "token_id": "ge_token-yes",
    "outcome": "Yes",
    "side": "BUY",
    "px": "0.45",
    "qty": "10",
    "ts": 1720000000123
  }
}
```

## `ec.depth`

Subscribe with `token_id` and `level`. Supported levels are 5, 10, 20, and 50. The response is a full book, not a delta.

**Response example**

```json
{
  "t": 1720000000124,
  "trace_id": "trace-1",
  "type": "snapshot",
  "ch": "ec.depth",
  "err": null,
  "result": {
    "token_id": "ge_token-yes",
    "level": 20,
    "full": true,
    "bids": [
      ["0.44", "100"]
    ],
    "asks": [
      ["0.46", "80"]
    ],
    "hash": "book-hash",
    "ts": 1720000000123
  }
}
```

Subscribe with `symbol` and `interval`.

```json

  "t": 1720000000124,
  "trace_id": "trace-1",
  "type": "update",
  "ch": "ec.candlestick",
  "err": null,
  "result": {
    "symbol": "btcusdt",
    "interval": "1m",
    "t": 1720000000,
    "o": "100000.00",
    "h": "100010.00",
    "l": "99990.00",
    "c": "100005.00",
    "v": "0",
    "closed": false
  }
}
```

A cached candlestick snapshot contains `symbol`, `interval`, and `history`.

## `ec.oc_price`

Subscribe with `slug` or `market_id`. Configured crypto windows can also use `symbol` and `interval`.

**Response example**

```json
{
  "t": 1720000000124,
  "trace_id": "trace-1",
  "type": "update",
  "ch": "ec.oc_price",
  "err": null,
  "result": {
    "slug": "bitcoin-up-or-down",
    "price_to_beat": "100000.00",
    "final_price": "100120.00"
  }
}
```

Unless a field is explicitly documented as seconds, timestamps are Unix timestamps in milliseconds.
