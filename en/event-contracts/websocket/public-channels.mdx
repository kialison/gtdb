---
title: "Public Channels"
description: "Public Event Contracts API WebSocket channels."
---

Public channels do not require user authentication and are intended for market-facing data.

Use the `ec.*` channel prefix:

| Channel | Purpose |
| --- | --- |
| `ec.trades` | Public trades |
| `ec.depth` | Order-book depth |
| `ec.bbo` | Best bid and offer |
| `ec.cpi` | CPI price updates |
| `ec.candlestick` | Candlestick updates |
| `ec.oc_price` | Open/close reference price |
| `ec.status` | Market lifecycle and trading status |
