---
title: "WebSocket Authentication"
description: "Authenticate private Event Contracts API WebSocket subscriptions."
---

Only private channels require authentication. Public market-data channels can be subscribed to without credentials.

## API Key signature

Include the API Key and a locally generated HMAC-SHA512 signature in the `auth` object:

```json
{
  "method": "api_key",
  "key": "YOUR_API_KEY",
  "sign": "HEX_SIGNATURE"
}
```

The signature input for a direct private subscription is:

```text
channel=ec.orders&event=subscribe&time=1720000000123
```

Compute the hexadecimal HMAC-SHA512 digest with the API Secret as the key. Never send the API Secret.

## Private subscription

```json
{
  "t": 1720000000123,
  "id": "private-1",
  "op": "subscribe",
  "ch": "ec.orders",
  "payload": {
    "all": true
  },
  "auth": {
    "method": "api_key",
    "key": "YOUR_API_KEY",
    "sign": "HEX_SIGNATURE"
  }
}
```

The same API Key authentication is used for `ec.usertrades`, `ec.positions`, and `ec.settlements`.
