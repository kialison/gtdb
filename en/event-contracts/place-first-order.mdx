This page shows how to place your first order using an existing Event Contracts account. We recommend having at least 10 USDT of available balance.

<Steps>
  <Step title="Complete Authentication">
    Prepare your API Key and signature information according to the private API authentication requirements.
  </Step>
  <Step title="Select an Outcome">
    Query the Market and choose the Outcome you want to trade from `outcomes[]`. Orders identify the specific outcome using `token_id`.
  </Step>
  <Step title="Place the Order">
    Set the price and quantity based on order-book liquidity, then submit the trading request to the order endpoint.
  </Step>
  <Step title="Wait for Settlement">
    After an order is matched, the resulting trade may still require asynchronous on-chain settlement. Confirm settlement completion before reading the final asset state.
  </Step>
  <Step title="Check the Position">
    Query the position for the corresponding Market and confirm the purchased Outcome Token amount, available quantity, and settlement status.
  </Step>
</Steps>
