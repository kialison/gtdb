Use the WebSocket API for real-time market, account, order, position, balance, and trading updates.

## Endpoint

```text
wss://api.dexbuilder.com/v1/ws/dex
```

Public channels include ticker, trades, order book, candlesticks, liquidation data, and contract statistics. Private channels include orders, user trades, positions, balances, liquidation, ADL, and automatic orders.
