These endpoints are private and require gateway authentication. Do not send internal identity headers.

- GET https://broker.dexbuilder.com/api/v4/event_contract/orders
- GET https://broker.dexbuilder.com/api/v4/event_contract/usertrades
- GET https://broker.dexbuilder.com/api/v4/event_contract/positions
- GET https://broker.dexbuilder.com/api/v4/event_contract/positions/settled
- GET https://broker.dexbuilder.com/api/v4/event_contract/balance
- GET https://broker.dexbuilder.com/api/v4/event_contract/fund_flows

Private list endpoints use limit and opaque cursor pagination.
