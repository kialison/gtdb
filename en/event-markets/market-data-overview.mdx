Prediction Markets data integration usually begins by identifying the Event, Market, or Outcome your application is interested in. This section explains how to discover markets, read market details, retrieve prices and order books, inspect analytics, and subscribe to real-time data.

## Data Model

In Prediction Markets, an Event can contain one or more Markets. Each Market is a tradable question with outcomes such as YES / NO. Every Outcome has a corresponding Token ID.

When an application needs to read the price or order book for an outcome, or place an order, it uses that Outcome's `token_id`.

![Image](/images/image-6.png "Image")

<Steps>
  <Step title="Discover an Event">
    Browse current Events, filter by category, or query a specific Event directly by slug / ID.
  </Step>
  <Step title="Select a Market">
    View the Markets under the Event and choose the specific question your application needs to handle.
  </Step>
  <Step title="Select an Outcome">
    Choose YES, NO, or another outcome and save its corresponding Token ID.
  </Step>
  <Step title="Read or Subscribe to Data">
    Use the identifiers you obtained to query the REST API or subscribe to real-time updates through WebSocket.
  </Step>
</Steps>
