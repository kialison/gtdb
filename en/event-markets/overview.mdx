## Developer Quickstart

Make your first API request in just a few minutes. Learn the core capabilities of Prediction Markets, retrieve market data, place orders, and redeem winning positions after market settlement.

<CodeGroup>

```bash API
curl -G "https://api.dexbuilder.com/api/v4/prediction/markets" \
  --data-urlencode "active=true" \
  --data-urlencode "closed=false" \
  --data-urlencode "limit=5"
```

</CodeGroup>
