---
title: "WebSocket Authentication"
description: "Authenticate private Prediction Markets API WebSocket subscriptions."
---

Only private channels require authentication. Public market-data channels can be subscribed to without credentials.

## API Key signature

Include the API Key and a locally generated HMAC-SHA512 signature in the `auth` object:

```json
{
  "method": "api_key",
  "key": "YOUR_API_KEY",
  "sign": "HEX_SIGNATURE"
}
```

The signature input for a direct private subscription is:

```text
channel=pred.orders&event=subscribe&time=1720000000123
```

Compute the hexadecimal HMAC-SHA512 digest with the API Secret as the key. Never send the API Secret.

## Private subscription

```json
{
  "t": 1720000000123,
  "id": "private-1",
  "op": "subscribe",
  "ch": "pred.orders",
  "payload": {"all": true},
  "auth": {"method":"api_key","key":"YOUR_API_KEY","sign":"HEX_SIGNATURE"}
}
```

The same API Key authentication is used for `pred.usertrades`, `pred.positions`, and `pred.settlements`.
