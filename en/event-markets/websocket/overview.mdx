The Prediction Markets WebSocket API provides public market data and authenticated account updates.

## Connection

```text
wss://broker.dexbuilder.com/ws/dex-builder/prediction
```

Use one connection for the channels of the selected product. Prediction Markets uses `pred.*`; Event Contracts uses `pred.*`.

## Channel groups

- Public channels: `pred.trades`, `pred.depth`, `pred.bbo`, `pred.status`, `pred.cpi`, `pred.candlestick`, and `pred.oc_price`
- Private channels: `pred.orders`, `pred.usertrades`, `pred.positions`, and `pred.settlements`

Public channels do not require authentication. Private channels require an API Key signature. See [WebSocket Protocol](./protocol), [Public Channels](./public-channels), and [Private Channels](./private-channels).
