---
title: "Public Channels"
description: "Public Prediction Markets API WebSocket channels."
---

Public channels do not require authentication. Connect to:

```text
wss://broker.dexbuilder.com/ws/dex-builder/prediction
```

Subscribe with the channel prefix `pred`. Each subscription item identifies one event, market, token, or price series.

## Subscription

```json
{
  "t": 1720000000123,
  "id": "sub-1",
  "op": "subscribe",
  "ch": "pred.trades",
  "payload": {
    "items": [{ "condition_id": "gate_condition-1" }]
  }
}
```

The server first returns an acknowledgement. When cached data is available, it can send a `snapshot`; subsequent messages are `update` events.

## Channels

### `pred.trades`

Public trades for a condition.

```json
{
  "type": "update",
  "ch": "pred.trades",
  "err": null,
  "result": {
    "condition_id": "gate_condition-1",
    "token_id": "gate_token-yes",
    "outcome": "Yes",
    "side": "BUY",
    "px": "0.45",
    "qty": "10",
    "ts": 1720000000123
  }
}
```

Subscribe with `condition_id`.

### `pred.depth`

Full order-book snapshot for a token at a requested level. Supported levels are 5, 10, 20, and 50.

```json
{
  "type": "snapshot",
  "ch": "pred.depth",
  "err": null,
  "result": {
    "token_id": "gate_token-yes",
    "level": 20,
    "full": true,
    "bids": [["0.44", "100"]],
    "asks": [["0.46", "80"]],
    "hash": "book-hash",
    "ts": 1720000000123
  }
}
```

Subscribe with `token_id` and `level`. The payload represents the complete book at that level, not a delta.

### `pred.bbo`

Best bid and offer for a token.

```json
{
  "type": "update",
  "ch": "pred.bbo",
  "err": null,
  "result": {
    "condition_id": "gate_condition-1",
    "token_id": "gate_token-yes",
    "bid_px": "0.44",
    "ask_px": "0.46",
    "last_px": "0.45",
    "ts": 1720000000123
  }
}
```

Subscribe with `token_id`.

### `pred.status`

Market lifecycle and outcome status.

```json
{
  "type": "update",
  "ch": "pred.status",
  "err": null,
  "result": {
    "market_id": "gate_market-1",
    "condition_id": "gate_condition-1",
    "slug": "example-market",
    "status": "ACTIVE",
    "closed": false,
    "accepting_orders": true,
    "outcomes": [
      {"name": "Yes", "token_id": "gate_token-yes", "px": "0.45"},
      {"name": "No", "token_id": "gate_token-no", "px": "0.55"}
    ],
    "ts": 1720000000123
  }
}
```

Subscribe with `market_id`.

### `pred.cpi`

Crypto price index updates for a symbol and interval.

```json
{
  "type": "update",
  "ch": "pred.cpi",
  "err": null,
  "result": {
    "symbol": "btcusdt",
    "interval": "1m",
    "price": "100000.10",
    "price_timestamp": "1720000000123",
    "ts": 1720000000123
  }
}
```

Subscribe with `symbol` and `interval`, for example `btcusdt` and `1m`.

### `pred.candlestick`

OHLC updates built from the configured price source.

```json
{
  "type": "update",
  "ch": "pred.candlestick",
  "err": null,
  "result": {
    "symbol": "btcusdt",
    "interval": "1m",
    "t": 1720000000,
    "o": "100000.00",
    "h": "100010.00",
    "l": "99990.00",
    "c": "100005.00",
    "v": "0",
    "closed": false
  }
}
```

Subscribe with `symbol` and `interval`. A snapshot, when available, contains `symbol`, `interval`, and a `history` array.

### `pred.oc_price`

Opening/closing reference prices for an event window. Subscribe using `slug` or `market_id`. For configured crypto windows, `symbol` and `interval` can also be used.

```json
{
  "type": "update",
  "ch": "pred.oc_price",
  "err": null,
  "result": {
    "slug": "bitcoin-up-or-down",
    "price_to_beat": "100000.00",
    "final_price": "100120.00"
  }
}
```

All timestamps are Unix timestamps in milliseconds unless a field is explicitly documented as seconds.
