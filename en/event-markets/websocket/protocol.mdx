---
title: "WebSocket Protocol"
description: "Prediction Markets API WebSocket message format and subscription flow."
---

WebSocket messages use JSON. A subscription identifies the channel, operation, and subscription payload.

For Prediction Markets, public and private channels use the `pred.*` prefix. For example:

```json
{
  "t": 1787026512123,
  "id": "depth-1",
  "op": "subscribe",
  "ch": "pred.depth",
  "payload": {
    "items": [{"token_id": "gate_token_id", "level": 20}]
  }
}
```

Clients should:

1. establish the connection;
2. authenticate when required;
3. subscribe to channels;
4. process update messages;
5. reconnect and resubscribe after a disconnect.

Do not rely on locally cached state after a reconnect without confirming current server state.
