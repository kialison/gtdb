---
title: "Private Channels"
description: "Authenticated Prediction Markets API WebSocket channels."
---

Private channels deliver user-specific updates such as orders, trades, positions, and account activity.

Authentication is required. Use the `pred.*` channel prefix:

| Channel | Purpose |
| --- | --- |
| `pred.orders` | Order status updates |
| `pred.usertrades` | User trade updates |
| `pred.positions` | Position updates |
| `pred.settlements` | Settlement updates |

Keep private subscriptions separate from public market-data subscriptions and handle credential errors explicitly.
