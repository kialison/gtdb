All channels on this page are public and do not require authentication.

## Trades

Channel: `ec.trades`

Subscribe by condition ID:

```json
{
  "op": "subscribe",
  "ch": "ec.trades",
  "payload": {
    "items": [
      { "condition_id": "gate_0xcondition" }
    ]
  }
}
```

Each update contains a newly observed public trade:

```json
{
  "condition_id": "gate_0xcondition",
  "token_id": "gate_token_id",
  "outcome": "Yes",
  "side": "BUY",
  "px": "0.45",
  "qty": "10",
  "ts": 1787026512027
}
```

`px` and `qty` are decimal strings. The public trade event does not include a trade ID.

## Full order-book depth

Channel: `ec.depth`

Subscribe by token ID and level. Supported levels are `5`, `10`, `20`, and `50`.

```json
{
  "op": "subscribe",
  "ch": "ec.depth",
  "payload": {
    "items": [
      { "token_id": "gate_token_id", "level": 20 }
    ]
  }
}
```

The broker sends complete snapshots, not deltas:

```json
{
  "token_id": "gate_token_id",
  "level": 20,
  "full": true,
  "bids": [
    ["0.45", "100"],
    ["0.44", "80"]
  ],
  "asks": [
    ["0.46", "90"],
    ["0.47", "120"]
  ],
  "hash": "0xabc123",
  "ts": 1787026512027
}
```

Every depth message represents the complete subscribed depth. Clients do not need to apply sequence-based patches.

## Best bid and offer

Channel: `ec.bbo`

Subscribe by token ID:

```json
{
  "op": "subscribe",
  "ch": "ec.bbo",
  "payload": {
    "items": [
      { "token_id": "gate_token_id" }
    ]
  }
}
```

```json
{
  "condition_id": "gate_0xcondition",
  "token_id": "gate_token_id",
  "bid_px": "0.45",
  "ask_px": "0.46",
  "last_px": "0.455",
  "ts": 1787026512027
}
```

Unavailable optional prices are omitted.

## CPI price updates

Channel: `ec.cpi`

CPI (Crypto Price Index) provides public price updates for a normalized symbol at a configured interval. It does not require authentication.

Subscribe by symbol and interval:

```json
{
  "t": 1787026512123,
  "id": "cpi-1",
  "op": "subscribe",
  "ch": "ec.cpi",
  "payload": {
    "items": [
      {
        "symbol": "btcusdt",
        "interval": "1m"
      }
    ]
  }
}
```

The broker normalizes symbols by lowercasing them and removing `/`, `-`, and `_`. For example, `BTC/USDT`, `BTC-USDT`, and `BTCUSDT` resolve to the same subscription key.

Each update has the following result:

```json
{
  "symbol": "btcusdt",
  "interval": "1m",
  "price": "100000.10",
  "price_timestamp": "1787026512000",
  "ts": 1787026512027
}
```

| Field | Type | Description |
| --- | --- | --- |
| `symbol` | string | Normalized symbol. |
| `interval` | string | Configured CPI interval, such as `1m`, `5m`, `15m`, `1h`, or `1d`. |
| `price` | string | CPI price as a decimal string. |
| `price_timestamp` | string | Source price timestamp, when supplied by the source. |
| `ts` | integer | Broker event timestamp in Unix milliseconds. |

CPI is a public channel, so `payload.all=true` is not supported. Use `unsubscribe` with the same `symbol` and `interval` item to stop receiving updates.

## Candlesticks

Channel: `ec.candlestick`

Candlestick updates are public and do not require authentication. Subscribe by normalized symbol and interval:

```json
{
  "t": 1787026512123,
  "id": "candle-1",
  "op": "subscribe",
  "ch": "ec.candlestick",
  "payload": {
    "items": [
      {
        "symbol": "btcusdt",
        "interval": "1m"
      }
    ]
  }
}
```

The broker builds OHLC candles from the incoming price stream. Supported intervals are configured by the deployment and may include `1m`, `5m`, `15m`, `1h`, `4h`, `1d`, `1w`, and `1mon`.

Live candle update:

```json
{
  "symbol": "btcusdt",
  "interval": "1m",
  "t": 1787026500,
  "o": "100000.10",
  "h": "100050.00",
  "l": "99980.00",
  "c": "100020.20",
  "v": "0",
  "closed": false
}
```

| Field | Type | Description |
| --- | --- | --- |
| `symbol` | string | Normalized symbol. |
| `interval` | string | Candle interval. |
| `t` | integer | Candle open time in Unix seconds. |
| `o` | string | Open price. |
| `h` | string | High price. |
| `l` | string | Low price. |
| `c` | string | Close price. |
| `v` | string | Volume field; currently `"0"`. |
| `closed` | boolean | Whether the candle is closed; live updates are `false`. |

When a cached history is available, a snapshot uses the following result shape:

```json
{
  "symbol": "btcusdt",
  "interval": "1m",
  "history": [
    {
      "t": 1787026440,
      "o": "99950.00",
      "h": "100010.00",
      "l": "99920.00",
      "c": "100000.10",
      "v": "0"
    }
  ]
}
```

\\n## Open/close price

Channel: `ec.oc_price`

Open/close price updates are public and do not require authentication. Subscribe by market slug, market ID, or by symbol and interval:

```json
{
  "t": 1787026512123,
  "id": "oc-1",
  "op": "subscribe",
  "ch": "ec.oc_price",
  "payload": {
    "items": [
      {
        "slug": "btc-updown-5m-1782178800"
      },
      {
        "symbol": "btcusdt",
        "interval": "5m"
      }
    ]
  }
}
```

A `market_id` item is treated as an alias for `slug`. The broker also derives common symbol and interval keys from supported slug formats.

Update result:

```json
{
  "slug": "btc-updown-5m-1782178800",
  "price_to_beat": "63995.66",
  "final_price": "63984.86"
}
```

| Field | Type | Description |
| --- | --- | --- |
| `slug` | string | Market slug associated with the open/close price event. |
| `price_to_beat` | string | Reference price at the start of the market window. |
| `final_price` | string | Final reference price when available. |

Use `unsubscribe` with the same item shape to stop receiving updates. If no matching source event has been observed, subscription activation returns no snapshot. \\

## Market status

Channel: `ec.status`

Subscribe by complete market ID:

```json
{
  "op": "subscribe",
  "ch": "ec.status",
  "payload": {
    "items": [
      { "market_id": "gate_632804_3653439" }
    ]
  }
}
```

```json
{
  "market_id": "gate_632804_3653439",
  "condition_id": "gate_0xcondition",
  "slug": "gate_example-market",
  "status": "ACTIVE",
  "closed": false,
  "accepting_orders": true,
  "outcomes": [
    {
      "name": "Yes",
      "token_id": "gate_token_yes",
      "px": "0.45"
    },
    {
      "name": "No",
      "token_id": "gate_token_no",
      "px": "0.55"
    }
  ],
  "ts": 1787026512027
}
```

Status values are `ACTIVE`, `CLOSED`, and `RESOLVED`. Resolution fields may be included when available.
