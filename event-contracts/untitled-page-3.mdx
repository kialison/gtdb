title: "APIs"
---

API is best suited for unsupported runtimes and use cases that require low-level control. It returns raw JSON data and provides service-specific APIs rather than a unified client interface. Authentication and signing must be implemented directly, while pagination behavior may vary across APIs. For realtime data, users need to connect to each WebSocket surface individually.
