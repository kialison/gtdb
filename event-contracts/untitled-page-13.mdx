Each market outcome is represented by a token. Start with [Discover Event Contracts](/event-contracts/untitled-page-11) or [Market Details](/event-contracts/untitled-page-12), then use `outcomes[].token_id`.

All endpoints on this page are public market-data endpoints and do not require authentication. The production API base URL is `https://api.dexbuilder.com`.

## Order book

### Fetch an order book

```bash cURL
curl "https://api.dexbuilder.com/api/v4/event_contracts/tokens/<token_id>/order_book?depth=20"
```

`depth` is optional and defaults to 20. It accepts values from 1 to 100.

```json Example
{
  "token_id": "token-yes",
  "condition_id": "0xabc...",
  "timestamp": 1782753357257,
  "hash": "a1b2c3d4",
  "bids": [
    { "price": "0.48", "size": "100.00" }
  ],
  "asks": [
    { "price": "0.52", "size": "80.00" }
  ],
  "last_trade_price": "0.50",
  "min_order_size": "5",
  "tick_size": "0.01",
  "neg_risk": false
}
```

| Field | Description |
| --- | --- |
| `token_id` | Outcome token identifier. |
| `condition_id` | Settlement condition identifier. |
| `bids`, `asks` | Price-level arrays; each level has decimal-string `price` and `size`. |
| `timestamp` | Snapshot timestamp in Unix milliseconds. |
| `hash` | Order-book snapshot hash. |
| `last_trade_price` | Last matched price, when available. |
| `min_order_size`, `tick_size`, `neg_risk` | Trading constraints. |

There is currently no batch order-book endpoint in this API. Request each token separately when multiple books are needed.

## Latest token price

Fetch the latest trade price and side:

```bash cURL
curl "https://api.dexbuilder.com/api/v4/event_contracts/tokens/<token_id>/price"
```

```json
{
  "token_id": "token-yes",
  "price": "0.50",
  "side": "BUY",
  "timestamp": 1782753357257
}
```

When no trade is available, `price` may be an empty string.

## Token ticker

Fetch the latest price together with the best bid and ask:

```bash cURL
curl "https://api.dexbuilder.com/api/v4/event_contracts/tokens/<token_id>/ticker"
```

```json
{
  "token_id": "token-yes",
  "last_price": "0.50",
  "best_bid": "0.48",
  "best_ask": "0.52",
  "timestamp": 1782753357257
}
```

Fields without reliable data may be `null`.

## Batch token prices

Pass comma-separated token IDs. A request can contain at most 100 distinct token IDs:

```bash cURL
curl "https://api.dexbuilder.com/api/v4/event_contracts/tokens/prices?token_ids=token-yes,token-no"
```

```json
{
  "items": [
    { "token_id": "token-yes", "price": "0.50", "timestamp": 1782753357257 },
    { "token_id": "token-no", "price": "0.50", "timestamp": 1782753357257 }
  ]
}
```

Unknown or invisible tokens are omitted, and returned items preserve request order.

## Price history

Fetch historical prices for a token:

```bash cURL
curl "https://api.dexbuilder.com/api/v4/event_contracts/tokens/<token_id>/price_history?interval=1h&from=1782666000000&to=1782752400000"
```

Required parameters:

| Parameter | Description |
| --- | --- |
| `interval` | One of `5m`, `15m`, `1h`, `4h`, `1d`. |
| `from` | Start time as Unix milliseconds. |
| `to` | End time as Unix milliseconds. |
|  | The requested range is limited to 14 days. |

Response:

```json
{
  "history": [
    { "t": 1782666000, "p": 0.485 },
    { "t": 1782669600, "p": 0.500 }
  ]
}
```

## Unsupported CLOB-specific endpoints

The Prediction API does not currently expose Polymarket CLOB endpoints such as `/books`, `/prices` POST, `/midpoint`, `/midpoints`, `/spread`, `/spreads`, or `/last-trades-prices`. Use the order-book, price, ticker, batch-price, and price-history endpoints above instead.
