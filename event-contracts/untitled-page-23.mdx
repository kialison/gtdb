The Prediction API exposes account activity for the authenticated user. It does not expose a public wallet-address lookup API equivalent to Polymarket's Data API.

The production API base URL is `https://api.dexbuilder.com`. Positions and user trades are private endpoints and require authentication. The authentication mechanism is not finalized yet; internal identity headers are not documented here.

## Positions

List the authenticated user's positions:

```bash cURL
curl -G "https://api.dexbuilder.com/api/v4/event_contracts/positions" \
  -H "<authentication-header>: <authentication-value>" \
  --data-urlencode "event_id=<event_id>" \
  --data-urlencode "condition_id=<condition_id>" \
  --data-urlencode "settlement_status=OPEN" \
  --data-urlencode "limit=20"
```

The response uses cursor pagination:

```json
{
  "items": [
    {
      "position_id": "position-123",
      "event_id": "event-123",
      "token_id": "token-yes",
      "outcome": "Yes",
      "size": "10",
      "available_size": "10",
      "locked_size": "0",
      "avg_open_price": "0.48",
      "mark_price": "0.52",
      "position_value": "5.20",
      "settlement_status": "OPEN",
      "won": false,
      "updated_at": 1782753357
    }
  ],
  "next_cursor": "eyJvZmZzZXQiOjIwfQ"
}
```

Get one position:

```bash cURL
curl "https://api.dexbuilder.com/api/v4/event_contracts/positions/<position_id>" \
  -H "<authentication-header>: <authentication-value>"
```

## User trades

List the authenticated user's trades:

```bash cURL
curl -G "https://api.dexbuilder.com/api/v4/event_contracts/usertrades" \
  -H "<authentication-header>: <authentication-value>" \
  --data-urlencode "market_id=<market_id>" \
  --data-urlencode "token_id=<token_id>" \
  --data-urlencode "limit=20"
```

Use the returned `next_cursor` as `cursor` for the next page. Event Contracts trade response fields are documented in [API Reference](/event-contracts/api/positions).

## Important scope

The following Polymarket Data API concepts are not part of the current Prediction API contract:

- Querying positions by an arbitrary public wallet address.
- Public closed-position and portfolio-value endpoints.
- A generic wallet activity timeline.

Use the authenticated positions, user trades, orders, and account endpoints instead.
