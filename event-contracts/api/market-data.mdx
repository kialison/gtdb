## Base URL

`https://broker.dexbuilder.com`

All endpoints use `/api/v4/event_contract`. Decimal values such as prices, sizes, and volumes are returned as strings.

## Authentication

Market data is public. Orders, positions, account data, fees, and user trades are private and require an authenticated gateway request. The gateway authentication scheme is not finalized; do not send or document internal gateway identity headers.

## Endpoints

| Operation | Path |
| --- | --- |
| Token market | `GET /api/v4/event_contract/tokens/{token_id}/market` |
| Latest price | `GET /api/v4/event_contract/tokens/{token_id}/price` |
| Ticker | `GET /api/v4/event_contract/tokens/{token_id}/ticker` |
| Order book | `GET /api/v4/event_contract/tokens/{token_id}/order_book` |
| Price history | `GET /api/v4/event_contract/tokens/{token_id}/price_history` |
| Batch prices | `GET /api/v4/event_contract/tokens/prices` |

Order-book `depth` defaults to 20 and accepts 1–100. Price history requires `interval` (`5m`, `15m`, `1h`, `4h`, or `1d`), `from`, and `to`; the range is at most 14 days. Batch `token_ids` accepts at most 100 comma-separated IDs.

```json
{"token_id":"token-yes","bids":[{"price":"0.4200","size":"120.00"}],"asks":[{"price":"0.4300","size":"80.00"}],"timestamp":1760000000000,"last_trade_price":"0.4250","tick_size":"0.001"}
```

Price history returns `{"history":[{"p":"0.4250","t":1760000000000}]}`. Unknown or invisible tokens return `404`.
