## List markets

`GET https://broker.dexbuilder.com/api/v4/event_contracts/markets`

Public endpoint. No authentication is required.

### Query parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `limit` | integer | No | Page size, minimum 1 and maximum 100. |
| `cursor` | string | No | Opaque cursor from the previous `next_cursor`. |
| `market_id` | string | No | Gate composite market ID. |
| `event_id` | string | No | Parent event ID. |
| `slug` | string | No | Market slug. |
| `condition_id` | string | No | Condition ID. |
| `tag_slug` | string | No | Parent-event tag slug. |
| `active` | boolean | No | Active-state filter. |
| `closed` | boolean | No | Closed-state filter. |

### Response envelope

| Field | Type | Description |
| --- | --- | --- |
| `items` | array | Market summary objects. |
| `next_cursor` | string | Cursor for the next page; empty at the end. |

### Market summary fields

| Field | Type | Description |
| --- | --- | --- |
| `market_id` | string | Market identifier. |
| `event_id` | string | Parent event identifier. |
| `slug` | string | URL-friendly market identifier. |
| `question` | object | Sparse multilingual market question. |
| `condition_id` | string | Condition identifier used by trading and account APIs. |
| `status` | string | Market lifecycle status. |
| `closed` | boolean | Whether the market is closed. |
| `start_date` / `end_date` | integer | Market dates in Unix seconds. |
| `outcomes` | array | Outcome references with `token_id` and multilingual `outcome`. |
| `best_bid` / `best_ask` | string | Current best bid and ask as decimal strings. |
| `last_trade_price` | string | Latest trade price. |
| `volume` / `volume_24hr` | string | Aggregate and 24-hour volume. |
| `category` | string | Market category. |
| `tags` | array | Market tag summaries. |

```bash
curl --get 'https://broker.dexbuilder.com/api/v4/event_contracts/markets' \
  --data-urlencode 'limit=20' \
  --data-urlencode 'event_id=event-123' \
  --data-urlencode 'active=true'
```

## Get market details

- `GET /api/v4/event_contracts/markets/{market_id}`
- `GET /api/v4/event_contracts/markets/slug/{slug}`

The detail response includes all market-summary fields plus:

| Field | Type | Description |
| --- | --- | --- |
| `accepting_orders` | boolean | Whether the matching engine currently accepts orders. |
| `enable_order_book` | boolean | Whether order-book trading is enabled. |
| `min_order_size` | string | Minimum order size. |
| `tick_size` | string | Minimum price increment. |
| `neg_risk` | boolean | Whether the market uses negative-risk settlement. |
| `resolution_source` | string | Resolution source description or URL. |
| `resolved_at` | integer | Resolution timestamp. |
| `winning_outcome` | string | Winning outcome after resolution. |
| `winning_token_id` | string | Winning outcome token after resolution. |

## Market trades

`GET /api/v4/event_contracts/markets/{market_id}/trades`

Query parameters are `limit` and `cursor`. The response contains `items` and `next_cursor`.

| Field | Type | Description |
| --- | --- | --- |
| `trade_id` | string | Trade identifier. |
| `market_id` | string | Market identifier. |
| `condition_id` | string | Market condition identifier. |
| `token_id` | string | Outcome token identifier. |
| `price` / `size` | string | Execution price and size. |
| `side` | string | Trade direction. |
| `timestamp` | integer | Trade timestamp. |
