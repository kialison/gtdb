## Base URL

`https://broker.dexbuilder.com`

All endpoints use `/api/v4/event_contract`. Decimal values such as prices, sizes, and volumes are returned as strings.

## Authentication

Market data is public. Orders, positions, account data, fees, and user trades are private and require an authenticated gateway request. The gateway authentication scheme is not finalized; do not send or document internal gateway identity headers.

## List markets

`GET /api/v4/event_contract/markets`

Parameters: `limit` (1–100), `cursor`, `market_id`, `event_id`, `slug`, `condition_id`, `tag_slug`, `active`, and `closed`.

Response is `items` plus `next_cursor`. Items include market identity, multilingual question, outcome token references, status, dates, best bid/ask, last trade price, and volumes.

## Market detail

- `GET /api/v4/event_contract/markets/{market_id}`
- `GET /api/v4/event_contract/markets/slug/{slug}`

Detail adds `accepting_orders`, `enable_order_book`, `min_order_size`, `tick_size`, `neg_risk`, `resolution_source`, `resolved_at`, `winning_outcome`, and `winning_token_id`.

## Market trades

`GET /api/v4/event_contract/markets/{market_id}/trades` accepts `limit` and `cursor`. Each trade contains `trade_id`, `market_id`, `condition_id`, `token_id`, `price`, `size`, `side`, and `timestamp`; the response is `items` plus `next_cursor`.
