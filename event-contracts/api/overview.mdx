## Base URL

`https://broker.dexbuilder.com`

All endpoints use `/api/v4/event_contract`. Decimal values such as prices, sizes, and volumes are returned as strings.

## Authentication

Market data is public. Orders, positions, account data, fees, and user trades are private and require an authenticated gateway request. The gateway authentication scheme is not finalized; do not send or document internal gateway identity headers.

## Public data boundary

Public event, market, trade, and token-price endpoints expose only visible records in the configured scope. A valid identifier can return `404` when the resource is not visible.

## Cursor pagination

List responses use `items` and `next_cursor`. For the next request, pass the returned value as `cursor`; stop when it is empty. Public list endpoints accept at most 100 items per page. Offset pagination is not supported.

## Time units

Request filters `from`, `to`, `start_date_min`, `start_date_max`, `end_date_min`, and `end_date_max` use Unix milliseconds. Event and market date fields use Unix seconds. Price-history and candlestick timestamps use Unix milliseconds.

Event Contracts uses the same response and market-data conventions as Event Markets, with the namespace prefix `event_contract`.
