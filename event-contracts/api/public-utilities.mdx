## Base URL

`https://broker.dexbuilder.com`

## Tags

`GET /api/v4/event_contract/tags`

Returns visible tags with cursor pagination. Query parameters are `limit` (1–100) and `cursor`; response is `items` plus `next_cursor`.

## Cryptocurrency candlesticks

`GET /api/v4/event_contract/tokens/{currency}/candlesticks`

Required query parameters are `interval`; optional parameters are `from`, `to`, and `limit`. `currency` is a path parameter such as `BTC` or `ETH`. Each candle contains `t`, `o`, `h`, `l`, `c`, and `v`.

## Server time

`GET /api/v4/event_contract/time`

Returns `server_time` as a Unix-millisecond timestamp. A `503` from candlestick or other upstream market-data endpoints should be retried with backoff.
