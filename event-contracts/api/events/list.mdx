## Access

Market-data endpoints are public. Private endpoints require gateway authentication. Internal gateway identity headers are not part of this public contract.

## Errors

`400` invalid request; `401` missing or invalid authentication; `404` unknown or invisible resource; `503` upstream market-data unavailable.

## GET `/api/v4/event_contract/events`

Parameters: `limit` (1–100), `cursor`, `sort` (`start_date`, `start_time`, `end_date`, `closed_time`), `ascending`, `event_id`, `slug`, `tag_slug`, `active`, `closed`, and Unix-millisecond date bounds. Response `items[]` contains event identity, multilingual title, state, Unix-second dates, volume, images, and tags; `next_cursor` is empty at the end.
