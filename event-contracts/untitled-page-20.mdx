Order queries and cancellations are private operations and require authentication. The authentication mechanism is not finalized yet; this page intentionally does not document internal gateway identity headers.

The production API base URL is `https://api.dexbuilder.com`.

## List orders

Query the current user's orders with optional filters:

```bash cURL
curl -G "https://api.dexbuilder.com/api/v4/event_contracts/orders" \
  -H "<authentication-header>: <authentication-value>" \
  --data-urlencode "status=OPEN" \
  --data-urlencode "condition_id=<condition_id>" \
  --data-urlencode "limit=20"
```

Supported filters include `status`, `condition_id`, `event_id`, `order_id`, `client_order_id`, `from`, `to`, `sort_type`, `limit`, and `cursor`. `from` and `to` are Unix milliseconds. Use `created_at` or `updated_at` for `sort_type`.

Response shape:

```json
{
  "items": [
    {
      "order_id": "order-123",
      "client_order_id": "client-order-001",
      "event_id": "event-123",
      "condition_id": "0xabc...",
      "token_id": "token-yes",
      "outcome": "Yes",
      "side": "BUY",
      "price": "0.52",
      "size": "10",
      "size_matched": "4",
      "size_left": "6",
      "order_type": "LIMIT",
      "order_mode": "GTC",
      "status": "OPEN",
      "created_at": 1782753357,
      "updated_at": 1782753357
    }
  ],
  "next_cursor": "eyJvZmZzZXQiOjIwfQ"
}
```

Pass `next_cursor` as `cursor` to request the next page.

## Get an order

```bash cURL
curl "https://api.dexbuilder.com/api/v4/event_contracts/orders/<order_id>" \
  -H "<authentication-header>: <authentication-value>"
```

The detail response contains the same order identity and execution fields as a list item, plus any `error_code` returned by the order service.

## Cancel one order

```bash cURL
curl -X DELETE "https://api.dexbuilder.com/api/v4/event_contracts/orders/<order_id>" \
  -H "<authentication-header>: <authentication-value>"
```

Example accepted response:

```json
{
  "order_id": "order-123",
  "status": "ACCEPTED",
  "cancel_status": "PENDING"
}
```

## Cancel orders for a condition

Cancel the current user's orders for a market condition:

```bash cURL
curl -X DELETE "https://api.dexbuilder.com/api/v4/event_contracts/orders?condition_id=<condition_id>" \
  -H "<authentication-header>: <authentication-value>"
```

Example batch response:

```json
{
  "batch_id": "batch-123",
  "status": "ACCEPTED",
  "total_orders": 3
}
```

## Authentication note

The examples use a placeholder authentication header because the public authentication contract is still being finalized. Gateway-injected identity fields and other internal headers must not be used by external clients.
