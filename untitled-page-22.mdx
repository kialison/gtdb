---
title: "开始构建"
description: "通过 DexBuilder 配置并创建属于您的 DEX。"
---

**DexBuilder** 提供完整的 DEX 创建与管理能力。<br />连接钱包后，可根据业务需求选择 **PerpDEX、预测市场、事件合约** 等产品，并完成品牌、界面、市场及服务配置，快速创建并上线独立 DEX。

## 创建 DEX

<Steps>
  <Step title="配置 DEX 基本信息">
    填写 DEX 名称等基础信息，并选择需要支持的产品类型。

    可选择：

    - PerpDEX
    - 预测市场
    - 事件合约
    - 多种产品组合
  </Step>
  <Step title="配置品牌与界面">
    设置 Logo、品牌名称、主题样式、社交链接等品牌信息，并根据需要自定义 DEX 前端界面。
  </Step>
  <Step title="配置交易与市场">
    根据所选产品配置支持的区块链网络、交易市场、交易标的及相关市场参数。
  </Step>
  <Step title="配置语言与服务规则">
    设置 DEX 支持的语言、服务地区、风险限制及服务免责声明等内容。
  </Step>
  <Step title="创建并部署 DEX">
    完成必要配置后即可创建 DEX。DexBuilder 将自动生成并部署对应的交易前端及相关服务。
  </Step>
</Steps>

## 支持的产品

| 产品 | 说明 |
| --- | --- |
| PerpDEX | 提供永续合约交易能力，支持行情、下单、持仓、订单及账户等完整交易流程 |
| 预测市场 | 创建并运营预测市场，为用户提供事件结果交易能力 |
| 事件合约 | 基于指定事件或结果创建事件合约交易市场 |
| 多产品 DEX | 可根据业务需要同时启用 PerpDEX、预测市场及事件合约 |

## DEX 管理

DEX 创建后，可通过 **My DEX** 持续管理和更新您的 DEX，包括：

| 管理能力 | 用途 |
| --- | --- |
| DEX 配置 | 修改品牌形象、主题样式、社交链接、钱包及相关功能配置 |
| 手续费设置 | 配置 DEX 交易手续费及 Builder 收入分成 |
| 产品与市场管理 | 管理 PerpDEX、预测市场、事件合约及对应市场 |
| 更新与部署 | 配置修改后重新生成并部署 DEX |
| 部署状态 | 查看 DEX 创建、更新及部署任务的运行状态 |
