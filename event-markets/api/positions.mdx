## Base URL

`https://broker.dexbuilder.com`

All endpoints use `/api/v4/event_markets`. Decimal values such as prices, sizes, and volumes are returned as strings.

## Authentication

Market data is public. Orders, positions, account data, fees, and user trades are private and require an authenticated gateway request. The gateway authentication scheme is not finalized; do not send or document internal gateway identity headers.

## Positions

`GET /api/v4/event_markets/positions` accepts `event_id`, `condition_id`, `settlement_status`, `limit`, and `cursor`, and returns `items` plus `next_cursor`. Position items include `position_id`, `event_id`, `token_id`, `outcome`, `size`, `available_size`, `locked_size`, `avg_open_price`, `mark_price`, `position_value`, `claimable_amount`, `settlement_status`, `won`, and `updated_at`.

- `GET /api/v4/event_markets/positions/{position_id}` returns one position.
- `POST /api/v4/event_markets/positions/{position_id}/close` requests position closure.

## User trades

`GET /api/v4/event_markets/usertrades` supports `condition_id`, `from`, `to`, `sort_type` (`created_at` or `updated_at`), `order_id`, `token_id`, `limit`, and `cursor`. It returns the authenticated user's executions.

## Fees and time

- `GET /api/v4/event_markets/fee` is private; `fee_type` is `fixed` or `dynamic`.
- `GET /api/v4/event_markets/time` is public and returns `server_time` in Unix milliseconds.

## Errors

| Status | Meaning |
| --- | --- |
| 400 | Invalid query, path, or body |
| 401 | Missing or invalid authentication |
| 404 | Unknown or invisible resource |
| 503 | Upstream market-data service unavailable |

Retry read-only `503` responses with backoff. Check order state before retrying a write.
