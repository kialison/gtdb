## Access

Market-data endpoints are public. Private endpoints require gateway authentication. Internal gateway identity headers are not part of this public contract.

## Errors

`400` invalid request; `401` missing or invalid authentication; `404` unknown or invisible resource; `503` upstream market-data unavailable.

## GET `/api/v4/event_markets/events`

### Query parameters

| Name | Type | Description |
|---|---|---|
| `limit` | integer | 1–100. |
| `cursor` | string | Previous `next_cursor`. |
| `sort` | string | `start_date`, `start_time`, `end_date`, or `closed_time`. |
| `ascending` | boolean | Sort direction. |
| `event_id`, `slug`, `tag_slug` | string | Exact filters. |
| `active`, `closed` | boolean | State filters. |
| `start_date_min/max`, `end_date_min/max` | integer | Unix milliseconds. |

### Response fields

`items[]` contains `event_id`, `slug`, multilingual `title`, `category`, `active`, `closed`, `start_date`, `start_time`, `end_date`, `closed_time`, `volume`, `image`, `icon`, and `tags`. Event dates use Unix seconds; decimal values are strings. `next_cursor` is opaque and empty on the final page.

```json
{"items":[{"event_id":"event-123","slug":"example-event","title":{"en":"Example event"},"active":true,"closed":false,"start_date":1760000000,"volume":"125000.00","tags":[]}],"next_cursor":"opaque-cursor"}
```
