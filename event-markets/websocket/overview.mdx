The Event Markets WebSocket API provides real-time market and account events. Use it together with the REST API:

- Use public WebSocket channels for live market updates.
- Use private WebSocket channels for authenticated order, trade, position, and settlement events.
- Use the REST API for historical queries, pagination, order management, and state recovery after a disconnect.

## Connection

Production WebSocket endpoint:

```text
wss://broker.dexbuilder.com/v4/ws/event_markets
```

The protocol uses JSON messages and the current public protocol version is **v2**.

## Channels

Public channels:

| Channel | Purpose | Authentication |
| --- | --- | --- |
| `em.trades` | Public market trades. | Not required |
| `em.depth` | Full order-book depth for a token. | Not required |
| `em.bbo` | Best bid, best ask, and last price. | Not required |
| `em.status` | Market lifecycle and tradability status. | Not required |

Private channels:

| Channel | Purpose | Authentication |
| --- | --- | --- |
| `em.orders` | Order lifecycle updates. | Required |
| `em.usertrades` | Authenticated user's fills. | Required |
| `em.positions` | Position updates. | Required |
| `em.settlements` | Settlement updates. | Required |

## First public subscription

```json
{
  "t": 1787026512123,
  "id": "depth-1",
  "op": "subscribe",
  "ch": "em.depth",
  "payload": {
    "items": [
      {
        "token_id": "gate_token_id",
        "level": 20
      }
    ]
  }
}
```

The server returns an acknowledgement with the same `id`. If cached data is available, a depth snapshot follows the acknowledgement.

## Important conventions

- `t` is a Unix timestamp in milliseconds.
- IDs are JSON strings and must be treated as opaque values.
- Prices, quantities, amounts, and rates are decimal strings.
- Public channels do not require authentication.
- Private subscriptions require authentication on the first private operation.
- A reconnect creates a new connection identity; authenticate and resubscribe again.
- WebSocket messages are real-time only. Query REST endpoints to recover missed data.
