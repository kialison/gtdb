## Developer Quickstart

Make your first API request in minutes. Learn the basics of the event markets platform, fetch market data, place orders, and redeem winning positions.

<CodeGroup>

```bash API
curl -G "https://api.dexbuilder.com/api/v4/event_markets/markets" \
  --data-urlencode "active=true" \
  --data-urlencode "closed=false" \
  --data-urlencode "limit=5"
```

</CodeGroup>
