Learn how to find and filter public events and markets. Discovery and market-data endpoints do not require authentication.

The production API base URL is `https://api.dexbuilder.com`. All timestamps in event and market responses are Unix seconds unless noted otherwise. Localized text fields such as `title`, `question`, `outcome`, and tag `label` are returned as sparse language objects.

## Events

An event groups one or more markets under a shared question set.

### Fetch an Event

Fetch an event by its ID:

```bash cURL
curl "https://api.dexbuilder.com/api/v4/event_markets/events/<event_id>"
```

Fetch an event by slug:

```bash cURL
curl "https://api.dexbuilder.com/api/v4/event_markets/events/slug/<event_slug>"
```

The response is an event detail object. Important fields include:

| Field | Description |
| --- | --- |
| `event_id` | Event identifier. |
| `slug` | URL-friendly event identifier. |
| `title` | Localized event title object. |
| `description` | Localized event description object. |
| `markets` | Embedded market summaries. |
| `markets_has_more` | Whether the embedded market list is truncated. |
| `active`, `closed` | Event lifecycle flags. |
| `start_date`, `start_time`, `end_date`, `closed_time` | Event times as Unix seconds. |
| `volume` | Event volume as a decimal string. |
| `tags` | Event tag summaries. |

```json Example
{
  "event_id": "event-123",
  "slug": "example-event",
  "title": { "en": "Example event" },
  "active": true,
  "closed": false,
  "markets": [],
  "markets_has_more": false
}
```

### List Events

List visible events with optional filters. This is a public endpoint.

```bash cURL
curl "https://api.dexbuilder.com/api/v4/event_markets/events?limit=20&active=true&closed=false&sort=start_date&ascending=true"
```

Supported query parameters:

| Parameter | Description |
| --- | --- |
| `limit` | Number of results, from 1 to 100. |
| `cursor` | Cursor returned by the previous response. |
| `sort` | One of `start_date`, `start_time`, `end_date`, `closed_time`. |
| `ascending` | Sort direction. |
| `event_id` | Filter by event ID. |
| `slug` | Filter by event slug. |
| `tag_slug` | Filter by tag slug. |
| `active`, `closed` | Filter by lifecycle state. |
| `start_date_min`, `start_date_max` | Start-date bounds in Unix milliseconds. |
| `end_date_min`, `end_date_max` | End-date bounds in Unix milliseconds. |

The response contains event summaries under `items`:

```json Example
{
  "items": [
    {
      "event_id": "event-123",
      "slug": "example-event",
      "title": { "en": "Example event" },
      "active": true,
      "closed": false,
      "volume": "12500.50",
      "tags": [
        { "tag_id": "sports", "slug": "sports", "label": { "en": "Sports" } }
      ]
    }
  ],
  "next_cursor": "eyJvZmZzZXQiOjIwfQ"
}
```

When `next_cursor` is non-empty, pass it as `cursor` in the next request:

```bash cURL
curl "https://api.dexbuilder.com/api/v4/event_markets/events?limit=20&cursor=<next_cursor>"
```

## Markets

A market is a tradable question with one or more outcome tokens.

### Fetch a Market

Fetch a market by its composite market ID:

```bash cURL
curl "https://api.dexbuilder.com/api/v4/event_markets/markets/<market_id>"
```

Fetch a market by slug:

```bash cURL
curl "https://api.dexbuilder.com/api/v4/event_markets/markets/slug/<market_slug>"
```

The response is a market detail object. The `outcomes` array directly contains the token IDs used by order-book and pricing endpoints; no JSON-string parsing is required.

| Field | Description |
| --- | --- |
| `market_id` | Composite market identifier. |
| `event_id` | Parent event identifier. |
| `slug` | URL-friendly market identifier. |
| `question` | Localized market question object. |
| `condition_id` | Condition identifier. |
| `outcomes` | Outcome references with `token_id` and localized `outcome`. |
| `status`, `closed` | Market lifecycle state. |
| `accepting_orders` | Whether the market currently accepts orders. |
| `enable_order_book` | Whether the order book is enabled. |
| `best_bid`, `best_ask`, `last_trade_price` | Current market-data summary fields. |
| `min_order_size`, `tick_size`, `neg_risk` | Trading constraints and risk mode. |
| `start_date`, `end_date`, `resolved_at` | Lifecycle times as Unix seconds. |
| `winning_outcome`, `winning_token_id` | Resolution fields, when resolved. |

```json Example
{
  "market_id": "market-123",
  "event_id": "event-123",
  "slug": "example-market",
  "question": { "en": "Will the outcome occur?" },
  "condition_id": "0xabc...",
  "status": "active",
  "closed": false,
  "accepting_orders": true,
  "enable_order_book": true,
  "outcomes": [
    { "token_id": "token-yes", "outcome": { "en": "Yes" } },
    { "token_id": "token-no", "outcome": { "en": "No" } }
  ]
}
```

### List Markets

List visible markets with filters:

```bash cURL
curl "https://api.dexbuilder.com/api/v4/event_markets/markets?limit=20&active=true&closed=false&tag_slug=sports"
```

Supported query parameters:

| Parameter | Description |
| --- | --- |
| `limit` | Number of results, from 1 to 100. |
| `cursor` | Cursor returned by the previous response. |
| `market_id` | Filter by composite market ID. |
| `event_id` | Filter by parent event ID. |
| `slug` | Filter by market slug. |
| `condition_id` | Filter by condition ID. |
| `tag_slug` | Filter by parent-event tag slug. |
| `active`, `closed` | Filter by lifecycle state. |

The response contains market summaries under `items` and the next-page cursor under `next_cursor`:

```json Example
{
  "items": [
    {
      "market_id": "market-123",
      "event_id": "event-123",
      "slug": "example-market",
      "question": { "en": "Will the outcome occur?" },
      "condition_id": "0xabc...",
      "outcomes": [
        { "token_id": "token-yes", "outcome": { "en": "Yes" } },
        { "token_id": "token-no", "outcome": { "en": "No" } }
      ],
      "best_bid": "0.48",
      "best_ask": "0.52",
      "last_trade_price": "0.50",
      "volume": "12500.50",
      "volume_24hr": "850.25"
    }
  ],
  "next_cursor": "eyJvZmZzZXQiOjIwfQ"
}
```

Continue pagination by passing `next_cursor` as `cursor`:

```bash cURL
curl "https://api.dexbuilder.com/api/v4/event_markets/markets?limit=20&cursor=<next_cursor>"
```

## Tags

Use tags to build category filters. The tags endpoint is the supported metadata endpoint for discovery:

```bash cURL
curl "https://api.dexbuilder.com/api/v4/event_markets/tags?limit=20&cursor=<cursor>"
```

The response uses the same cursor pagination shape:

```json
{
  "items": [
    { "tag_id": "sports", "slug": "sports", "label": { "en": "Sports" } }
  ],
  "next_cursor": "eyJvZmZzZXQiOjIwfQ"
}
```

## Current API scope

The Prediction API currently exposes events, markets, tags, public market trades, and token market data. The separate Polymarket Gamma endpoints for series, sports metadata, global search, and tag relationships are not part of this API contract and should not be used in integrations.
