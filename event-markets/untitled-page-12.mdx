Use the market detail endpoint after selecting a market from [Discover Event Markets](/event-markets/untitled-page-11). Market data is public and does not require authentication.

The production API base URL is `https://api.dexbuilder.com`.

## Fetch a market

By composite market ID:

```bash cURL
curl "https://api.dexbuilder.com/api/v4/event_markets/markets/<market_id>"
```

By slug:

```bash cURL
curl "https://api.dexbuilder.com/api/v4/event_markets/markets/slug/<market_slug>"
```

## Response

The response is a single market detail object:

```json Example
{
  "market_id": "market-123",
  "event_id": "event-123",
  "slug": "example-market",
  "question": { "en": "Will the outcome occur?" },
  "condition_id": "0xabc...",
  "status": "active",
  "closed": false,
  "accepting_orders": true,
  "enable_order_book": true,
  "outcomes": [
    { "token_id": "token-yes", "outcome": { "en": "Yes", "cn": "是", "tw": "是" } },
    { "token_id": "token-no", "outcome": { "en": "No", "cn": "否", "tw": "否" } }
  ],
  "best_bid": "0.48",
  "best_ask": "0.52",
  "last_trade_price": "0.50",
  "min_order_size": "5",
  "tick_size": "0.01",
  "neg_risk": false,
  "volume": "12500.50",
  "volume_24hr": "850.25",
  "resolution_source": "https://example.com/source"
}
```

## Field reference

| Field | Description |
| --- | --- |
| `market_id` | Composite ID used by market-specific endpoints. |
| `event_id` | Parent event ID. |
| `slug` | Stable URL-friendly market identifier. |
| `question` | Sparse localized object. The available language keys depend on the source data. |
| `condition_id` | Settlement condition identifier. |
| `outcomes` | Array of outcome objects. Each item contains a `token_id` and localized `outcome`. |
| `status` | Current market status. |
| `closed` | Whether trading or market activity is closed. |
| `accepting_orders` | Whether orders are currently accepted. |
| `enable_order_book` | Whether order-book data is available. |
| `best_bid`, `best_ask` | Current best bid and ask, when available. |
| `last_trade_price` | Latest matched price, when available. |
| `min_order_size` | Minimum order size represented as a decimal string. |
| `tick_size` | Price increment represented as a decimal string. |
| `neg_risk` | Whether the market uses negative-risk settlement. |
| `start_date`, `end_date` | Market times as Unix seconds. |
| `resolved_at` | Resolution time as Unix seconds, when resolved. |
| `winning_outcome`, `winning_token_id` | Resolution result, when available. |
| `tags` | Tag summaries associated with the market. |

## Use an outcome token

Use `outcomes[].token_id` with the public pricing endpoints:

```bash cURL
TOKEN_ID="<token_id>"

curl "https://api.dexbuilder.com/api/v4/event_markets/tokens/$TOKEN_ID/order_book?depth=20"
curl "https://api.dexbuilder.com/api/v4/event_markets/tokens/$TOKEN_ID/price"
curl "https://api.dexbuilder.com/api/v4/event_markets/tokens/$TOKEN_ID/ticker"
```

The API returns token IDs directly in the `outcomes` array. Do not read or parse a `clobTokenIds` JSON-encoded string; that is not part of the Prediction API response.

## Related event

Use `event_id` from the market response to fetch the parent event:

```bash cURL
curl "https://api.dexbuilder.com/api/v4/event_markets/events/<event_id>"
```

Market data is public. Order placement, positions, account data, and other private endpoints require authentication; the authentication mechanism is documented separately and may change.
