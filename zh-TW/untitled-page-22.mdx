**DexBuilder** 提供完整的 DEX 創建與管理能力。<br />連接錢包後，可根據業務需求選擇 **PerpDEX、預測市場、事件合約** 等產品，並完成品牌、界面、市場及服務配置，快速創建並上線獨立 DEX。

## 創建 DEX

<Steps>
  <Step title="配置 DEX 基本信息">
    填寫 DEX 名稱等基礎信息，並選擇需要支持的產品類型。

    可選擇：

    - PerpDEX
    - 預測市場
    - 事件合約
    - 多種產品組合
  </Step>
  <Step title="配置品牌與界面">
    設置 Logo、品牌名稱、主題樣式、社交鏈接等品牌信息，並配置 DexBuilder 提供的 DEX 頁面樣式與展示內容。
  </Step>
  <Step title="配置交易與市場">
    根據所選產品配置支持的區塊鏈網絡、交易市場、交易標的及相關市場參數。
  </Step>
  <Step title="配置語言與服務規則">
    設置 DEX 支持的語言、服務地區、風險限制及服務免責聲明等內容。
  </Step>
  <Step title="創建並部署 DEX">
    完成必要配置後即可創建 DEX。DexBuilder 將自動生成並部署對應的交易前端及相關服務。
  </Step>
</Steps>

## 支持的產品

| 產品 | 說明 |
| --- | --- |
| PerpDEX | 提供永續合約交易能力，支持行情、下單、持倉、訂單及賬戶等完整交易流程 |
| 預測市場 | 創建並運營預測市場，為用戶提供事件結果交易能力 |
| 事件合約 | 基於指定事件或結果創建事件合約交易市場 |
| 多產品 DEX | 可根據業務需要同時啓用 PerpDEX、預測市場及事件合約 |

## DEX 管理

DEX 創建後，可通過 **My DEX** 持續管理和更新您的 DEX，包括：

| 管理能力 | 用途 |
| --- | --- |
| DEX 配置 | 修改品牌形象、主題樣式、社交鏈接、錢包及相關功能配置 |
| 手續費設置 | 配置 DEX 交易手續費及 Builder 收入分成 |
| 產品與市場管理 | 管理 PerpDEX、預測市場、事件合約及對應市場 |
| 更新與部署 | 配置修改後重新生成並部署 DEX |
| 部署狀態 | 查看 DEX 創建、更新及部署任務的運行狀態 |
