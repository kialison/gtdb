title: "開始構建"
description: "透過 DexBuilder 設定並建立屬於您的 DEX。"

**DexBuilder** 提供完整的 DEX 建立與管理能力。<br />連接錢包後，可根據業務需求選擇 **PerpDEX、預測市場、事件合約** 等產品，並完成品牌、界面、市場及服務設定，快速建立並上線獨立 DEX。

## 建立 DEX

<Steps>
  <Step title="設定 DEX 基本資訊">
    填寫 DEX 名稱等基礎資訊，並選擇需要支援的產品類型。

    可選擇：

    - PerpDEX
    - 預測市場
    - 事件合約
    - 多種產品組合
  </Step>
  <Step title="設定品牌與界面">
    設定 Logo、品牌名稱、主題樣式、社交連結等品牌資訊，並設定 DexBuilder 提供的 DEX 頁面樣式與展示內容。
  </Step>
  <Step title="設定交易與市場">
    根據所選產品設定支援的區塊鏈網路、交易市場、交易標的及相關市場參數。
  </Step>
  <Step title="設定語言與服務規則">
    設定 DEX 支援的語言、服務地區、風險限制及服務免責聲明等內容。
  </Step>
  <Step title="建立並部署 DEX">
    完成必要設定後即可建立 DEX。DexBuilder 將自動生成並部署對應的交易前端及相關服務。
  </Step>
</Steps>

## 支援的產品

| 產品 | 說明 |
| --- | --- |
| PerpDEX | 提供永續合約交易能力，支援行情、下單、持倉、訂單及帳戶等完整交易流程 |
| 預測市場 | 建立並營運預測市場，為使用者提供事件結果交易能力 |
| 事件合約 | 基於指定事件或結果建立事件合約交易市場 |
| 多產品 DEX | 可根據業務需要同時啓用 PerpDEX、預測市場及事件合約 |

## DEX 管理

DEX 建立後，可透過 **My DEX** 持續管理和更新您的 DEX，包括：

| 管理能力 | 用途 |
| --- | --- |
| DEX 設定 | 修改品牌形象、主題樣式、社交連結、錢包及相關功能設定 |
| 手續費設定 | 設定 DEX 交易手續費及 Builder 收入分成 |
| 產品與市場管理 | 管理 PerpDEX、預測市場、事件合約及對應市場 |
| 更新與部署 | 設定修改後重新生成並部署 DEX |
| 部署狀態 | 檢視 DEX 建立、更新及部署任務的運行狀態 |
