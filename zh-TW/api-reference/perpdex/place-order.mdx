該接口用於創建一筆永續合約訂單。

<Warning>
該接口需要 API Key、時間戳和請求籤名認證。
</Warning>

`size` 表示合約張數，不是幣的數量。每張合約對應的標的資產數量可通過合約信息中的 `quanto_multiplier` 獲取。

當 `price` 為 `0` 且 `tif` 為 `ioc` 時，可用於提交市價單。
