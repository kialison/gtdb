接收當前賬戶的平倉結果與盈虧更新。

**頻道：** `futures.position_closes`

**認證：** 需要 API Key

## 訂閱

```json
{
  "time": 1700000000,
  "channel": "futures.position_closes",
  "event": "subscribe",
  "payload": ["<user_id>", "BTC_USDT"],
  "auth": {
    "method": "api_key",
    "KEY": "<API_KEY>",
    "SIGN": "<SIGN>"
  }
}
```

如需訂閱全部合約，可在支持的頻道中使用 `!all`。簽名方式請參見「認證與簽名」。

## 取消訂閱

將 `event` 改為 `unsubscribe`，並保持認證信息與訂閱參數一致。
