訂閱永續合約即時 Ticker 行情。

**頻道：** `futures.tickers`

**認證：** 不需要

## 訂閱

```json
{
  "time": 1700000000,
  "channel": "futures.tickers",
  "event": "subscribe",
  "payload": ["BTC_USDT"]
}
```

服務端確認訂閱後，會透過同一 `channel` 持續推送 `event: "update"` 消息。

## 取消訂閱

將 `event` 改為 `unsubscribe`，並保持 `payload` 與訂閱時一致。
