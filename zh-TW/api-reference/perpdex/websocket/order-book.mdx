訂閱訂單簿全量或增量深度更新。

**頻道：** `futures.order_book`

**認證：** 不需要

## 訂閱

```json
{
  "time": 1700000000,
  "channel": "futures.order_book",
  "event": "subscribe",
  "payload": ["BTC_USDT", "20", "0"]
}
```

服務端確認訂閱後，會通過同一 `channel` 持續推送 `event: "update"` 消息。

## 取消訂閱

將 `event` 改為 `unsubscribe`，並保持 `payload` 與訂閱時一致。

標準深度相關頻道包括 `futures.order_book` 與 `futures.order_book_update`。客戶端應按頻道定義維護本地訂單簿。
