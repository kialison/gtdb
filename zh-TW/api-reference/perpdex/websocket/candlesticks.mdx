訂閱指定合約與週期的即時 K 線。

**頻道：** `futures.candlesticks`

**認證：** 不需要

## 訂閱

```json
{
  "time": 1700000000,
  "channel": "futures.candlesticks",
  "event": "subscribe",
  "payload": ["1m", "BTC_USDT"]
}
```

服務端確認訂閱後，會透過同一 `channel` 持續推送 `event: "update"` 消息。

## 取消訂閱

將 `event` 改為 `unsubscribe`，並保持 `payload` 與訂閱時一致。
