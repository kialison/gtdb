實時接收當前賬戶餘額變化。

**頻道：** `futures.balances`

**認證：** 需要 API Key

## 訂閱

```json
{
  "time": 1700000000,
  "channel": "futures.balances",
  "event": "subscribe",
  "payload": ["<user_id>"],
  "auth": {
    "method": "api_key",
    "KEY": "<API_KEY>",
    "SIGN": "<SIGN>"
  }
}
```

如需訂閱全部合約，可在支持的頻道中使用 `!all`。簽名方式請參見「認證與簽名」。

## 取消訂閱

將 `event` 改為 `unsubscribe`，並保持認證信息與訂閱參數一致。
