即時接收目前帳戶倉位變化。

**頻道：** `futures.positions`

**認證：** 需要 API Key

## 訂閱

```json
{
  "time": 1700000000,
  "channel": "futures.positions",
  "event": "subscribe",
  "payload": ["<user_id>", "BTC_USDT"],
  "auth": {
    "method": "api_key",
    "KEY": "<API_KEY>",
    "SIGN": "<SIGN>"
  }
}
```

如需訂閱全部合約，可在支援的頻道中使用 `!all`。簽名方式請參見「認證與簽名」。

## 取消訂閱

將 `event` 改為 `unsubscribe`，並保持認證資訊與訂閱參數一致。
