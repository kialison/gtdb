# BatchAmendOrderReq

批量修改訂單請求模型，對應 OpenAPI Schema：`BatchAmendOrderReq`。

| 字段 | 類型 | 必填 | 說明 |
| --- | --- | --- | --- |
| `order_id` | integer(int64) | 是 | 訂單 ID |
| `amend_text` | string | 否 | 改單自定義信息 |
| `size` | string | 否 | 新的訂單數量 |
| `price` | string | 否 | 新的訂單價格 |
