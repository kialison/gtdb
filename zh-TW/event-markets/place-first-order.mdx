本頁演示如何使用已有預測市場賬戶提交第一筆訂單。建議賬戶至少準備 10 USDT 可用資金。

<Steps>
  <Step title="完成認證">
    首先按照私有接口認證要求準備 API Key 與簽名信息。
  </Step>
  <Step title="選擇 Outcome">
    查詢 Market，並從 `outcomes[]` 中選擇要交易的 Outcome。訂單通過 `token_id` 標識具體結果。
  </Step>
  <Step title="提交訂單">
    根據訂單簿流動性設置價格與數量，然後向訂單接口提交交易請求。
  </Step>
  <Step title="等待結算">
    訂單撮合後，相關成交仍可能需要異步完成鏈上結算。確認結算完成後再讀取最終資產狀態。
  </Step>
  <Step title="檢查持倉">
    查詢對應 Market 的持倉，確認買入的 Outcome Token 數量、可用數量與結算狀態。
  </Step>
</Steps>
