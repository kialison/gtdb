私有頻道僅返回當前認證用戶的數據。可以在首次私有訂閱時攜帶認證信息，也可以先使用 `server.sign` 預認證。

私有頻道支持按 `condition_id` 過濾，或使用：

```json
{"all":true}
```

訂閱當前賬戶全部相關更新。

## 訂單 `em.orders`

訂單更新包含：

- `order_id`
- `client_order_id`
- `event_id`
- `condition_id`
- `token_id`
- `side`
- `order_mode`
- `order_type`
- `px`
- `qty`
- `filled_qty`
- `left_qty`
- `status`
- `created_ts`
- `updated_ts`

訂單狀態包括 `PROCESSING`、`OPEN`、`CANCELLING`、`MATCHED`、`CANCELED` 和 `FAILED`。

## 用戶成交 `em.usertrades`

返回當前用戶成交，包括 `trade_id`、`order_id`、`condition_id`、`token_id`、`side`、`role`、`px`、`qty`、`fee_rate`、`status` 和 `created_ts`。

`role` 為 `MAKER` 或 `TAKER`；狀態通常為 `MATCHED` 或 `CONFIRMED`。

## 持倉 `em.positions`

持倉推送可包含：

- `position_id`
- `event_id`
- `token_id`
- `outcome`
- `qty`
- `avg_px`
- `settle_status`
- `locked_qty`
- `available_qty`
- `claimable_amount`
- `updated_ts`

## 結算 `em.settlements`

結算更新包含 `position_id`、`event_id`、`condition_id`、`winning_outcome`、`is_winner`、`claimable_amount` 和 `created_ts`。

<Note>
私有頻道不會在訂閱後自動返回完整賬戶快照。需要完整當前狀態時，應先調用對應 REST 接口，再用 WebSocket 接收後續增量變化。
</Note>
