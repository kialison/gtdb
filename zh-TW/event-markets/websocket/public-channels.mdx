本頁頻道均為公開頻道，無需認證。

## 公開成交 `em.trades`

按 `condition_id` 訂閱：

```json
{
  "op":"subscribe",
  "ch":"em.trades",
  "payload":{"items":[{"condition_id":"gate_0xcondition"}]}
}
```

每條更新包含 `condition_id`、`token_id`、`outcome`、`side`、`px`、`qty` 和 `ts`。

## 訂單簿深度 `em.depth`

按 `token_id` 和深度等級訂閱。支援 `5`、`10`、`20`、`50` 檔。

```json
{
  "op":"subscribe",
  "ch":"em.depth",
  "payload":{"items":[{"token_id":"gate_token_id","level":20}]}
}
```

服務端推送的是完整快照，不是增量 Delta。

## 最優買賣價 `em.bbo`

回傳 `bid_px`、`ask_px`、`last_px` 和時間戳。

## CPI 價格 `em.cpi`

按 `symbol` 和 `interval` 訂閱，例如：

```json
{
  "op":"subscribe",
  "ch":"em.cpi",
  "payload":{"items":[{"symbol":"btcusdt","interval":"1m"}]}
}
```

回傳標準化後的 Symbol、週期、價格和價格時間。

## K 線 `em.candlestick`

按 Symbol 和週期訂閱。推送欄位包括：

- `t`：K 線開始時間；
- `o`：開盤價；
- `h`：最高價；
- `l`：最低價；
- `c`：收盤價；
- `v`：成交量；
- `closed`：K 線是否已結束。

## 開收盤參考價 `em.oc_price`

可按市場 `slug`、`market_id`，或 Symbol + Interval 訂閱。回傳 `price_to_beat` 與 `final_price`。

## 市場狀態 `em.status`

按 `market_id` 訂閱市場狀態。常見狀態：

- `ACTIVE`
- `CLOSED`
- `RESOLVED`

推送還可包含 `closed`、`accepting_orders`、各結果 Token 及目前價格。
