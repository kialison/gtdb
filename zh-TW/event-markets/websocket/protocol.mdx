預測市場 WebSocket 使用 v2 JSON 消息結構。客戶端操作使用 `op`，服務端主動推送使用 `type`。

## 客戶端請求

```json
{
  "t": 1787026512123,
  "id": 1001,
  "op": "subscribe",
  "ch": "em.trades",
  "payload": {
    "items": [{"condition_id":"gate_0xcondition"}]
  }
}
```

| 欄位 | 說明 |
| --- | --- |
| `t` | 客戶端 Unix 毫秒時間戳 |
| `id` | 客戶端請求 ID，用於關聯響應 |
| `op` | `subscribe`、`unsubscribe`、`auth` 或 `ping` |
| `ch` | 頻道名稱 |
| `payload` | 操作參數 |
| `auth` | 首次私有操作時攜帶的認證資訊 |

## 成功 ACK

```json
{
  "t": 1787026512150,
  "id": 1001,
  "trace_id": "7906cdf3f7dd1ef35f8ef5808cf58da8",
  "op": "subscribe",
  "ch": "em.trades",
  "err": null,
  "result": {"status":"success"}
}
```

## 錯誤 ACK

```json
{
  "id": 1001,
  "op": "subscribe",
  "ch": "em.depth",
  "err": {"code":2,"msg":"invalid depth level"},
  "result": {"status":"fail"}
}
```

客戶端應優先根據 `err.code` 處理錯誤，不要依賴完整錯誤文本。

## 服務端推送

```json
{
  "t": 1787026512150,
  "type": "update",
  "ch": "em.trades",
  "err": null,
  "result": {
    "condition_id":"gate_0xcondition",
    "token_id":"gate_token_id",
    "side":"BUY",
    "px":"0.45",
    "qty":"10",
    "ts":1787026512027
  }
}
```

`type` 常見值為 `snapshot` 或 `update`。

## 訂閱參數

支援：

```json
{"items":[{"token_id":"gate_token_id"}]}
```

私有頻道也可使用：

```json
{"all":true}
```

規則：

- `items` 與 `all` 不能同時出現；
- 單次最多提交 100 個訂閱項；
- 單連接最多支援 10,000 個有效訂閱；
- 公共頻道不支援 `all=true`；
- 取消訂閱使用與訂閱相同的 item 結構。
