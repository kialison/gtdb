預測市場手續費按每筆成交計算，具體費率可根據市場分類和業務配置確定。

## 手續費計算

動態費率模式下，手續費可按以下公式計算：

```text
fee = C × feeRate × p × (1 - p)
```

其中：

- `C`：成交份額數量；
- `feeRate`：對應市場分類的費率參數；
- `p`：結果份額成交價格。

因為公式中包含 `p × (1 - p)`，手續費在價格接近 `0.5` 時較高，在價格接近 `0` 或 `1` 時逐漸降低。

## 默認分類費率

| 市場分類 | Maker / Taker Fee Rate |
| --- | ---: |
| Crypto | `0.07` |
| Sports | `0.05` |
| Finance | `0.04` |
| Politics | `0.04` |
| Economics | `0.05` |
| Culture | `0.05` |
| Weather | `0.05` |
| Other / General | `0.05` |
| Mentions | `0.04` |
| Tech | `0.04` |
| Geopolitics | `0` |

實際生效費率以對應市場接口或賬戶費率接口返回值為準。

## 對稱性

動態費率關於 50% 概率對稱。例如在其他條件相同的情況下，價格為 `0.30` 和 `0.70` 的成交，其手續費金額相同。

## 精度

手續費金額保留到 5 位小數，最小計費精度為：

```text
0.00001 USDT
```

小於最小精度的費用可能四捨五入為 `0`。

<Note>
Builder 或 Broker 的實際費率結構可能根據業務合作方案進行配置，對外展示時應以當前市場和賬戶實際返回的數據為準。
</Note>
