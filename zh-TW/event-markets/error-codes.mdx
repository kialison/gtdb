預測市場 API 使用標準 HTTP 狀態碼表示請求處理結果。以下錯誤可能出現在需要認證的接口中。

## `401 Unauthorized`

### API Key 無效

可能原因：

- 未攜帶 API Key；
- API Key 已失效；
- API Key 不正確。

請檢查認證參數，並確認使用的是當前有效憑證。

### 簽名無效

如果認證 Header 格式錯誤、時間戳不符合要求或簽名內容與實際請求不一致，也會返回 `401`。

排查時重點確認：

- 請求時間戳；
- 簽名原文；
- Query 與 Body 是否和簽名時完全一致；
- API Secret 是否正確。

## `429 Too Many Requests`

表示請求頻率超過當前限頻規則。

建議客戶端使用指數退避後重試，並避免短時間內重復請求同一資源。

## `503 Service Unavailable`

表示交易服務或依賴的上游服務暫時不可用。此時新的交易請求可能無法正常處理。

對於只讀查詢，可以在短暫等待後重試；交易類請求應先確認上一筆請求的最終狀態，避免重復提交。

## 通用錯誤處理建議

客戶端應優先根據 HTTP 狀態碼和響應中的結構化錯誤字段進行處理，不要依賴完整的錯誤文本。

建議記錄以下信息用於排查：

- Request Method；
- Request Path；
- Query；
- 請求時間戳；
- `trace_id`；
- HTTP 狀態碼；
- 服務端返回的錯誤碼與錯誤信息。

<Warning>
排查日誌時不要記錄或對外暴露 API Secret、完整簽名密鑰或其他敏感認證信息。
</Warning>
