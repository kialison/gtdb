---
title: "探索市場"
description: "查詢 Event、Market 與 Token。"
---

### 查詢 Event

```bash
curl "https://broker.dexbuilder.com/api/v4/event_markets/events?limit=20"
```

支援依 ID、slug、標籤與狀態查詢。列表結果使用 `items` 與 `next_cursor`；當 `next_cursor` 為空時表示沒有下一頁。結果僅包含父級 Event 建立時間在最近 30 天內的資料。

### 查詢 Market

```bash
curl "https://broker.dexbuilder.com/api/v4/event_markets/markets?limit=20"
```

取得 Market 後讀取其中的 outcome token ID，再呼叫價格或訂單簿介面。
