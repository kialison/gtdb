---
title: "運維與技術支持"
description: "瞭解 DEX 上線後的運行監控、問題定位與技術支持能力。"
---

DEX 上線後，DexBuilder 持續提供交易服務、API、WebSocket、賬戶、資產及核心基礎設施的運行支持，並通過 Builder 管理後台提供項目級運營與問題排查能力。

## 運行監控

可重點關注：

- DEX 頁面與核心功能可用性
- API 與 WebSocket 狀態
- 行情、訂單、倉位和資產狀態
- 充值與提現狀態
- 交易失敗與異常情況
- 項目運營數據
- 後台管理員及權限變化

## 問題定位

出現交易或資產問題時，可結合以下信息進行查詢和定位：

1. 用戶及賬戶標識
2. 發生時間
3. 交易市場或資產
4. Order ID / Transaction Hash 等業務標識
5. 請求結果與錯誤碼
6. Trace ID 或相關日誌
7. 當前業務狀態

Builder 管理後台和 API 返回信息可用於輔助定位具體問題。

## 平台支持

DexBuilder 提供：

- DEX 產品與交易服務運行支持
- API 與 WebSocket 問題定位
- 賬戶、資產、交易及結算問題排查
- 平台異常與服務狀態同步
- 項目配置與上線階段技術支持

## 重大異常

涉及交易中斷、資產異常或大面積用戶影響的問題，應優先確認影響範圍並及時升級處理。

</Info>
