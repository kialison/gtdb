DexBuilder 提供完整的資產與充提能力，並在 DEX 中統一提供資產展示、充值、提現和資金狀態查詢。

## 資產能力

<CardGroup cols={2}>
  <Card title="資產展示" icon="wallet">
    展示賬戶總資產、可用資產、凍結資產及相關資金狀態。
  </Card>
  <Card title="充值" icon="arrow-down">
    提供充值網絡、地址、資產選擇及到賬狀態展示。
  </Card>
  <Card title="提現" icon="arrow-up">
    提供提現網絡、地址、數量、手續費及提現狀態展示。
  </Card>
  <Card title="資金流水" icon="list">
    查詢充值、提現、交易及其他資金變化記錄。
  </Card>
</CardGroup>

## 資金狀態

充值與提現流程會根據實際處理進度持續更新狀態。DexBuilder 會在對應頁面展示當前狀態，並提供相關記錄用於查詢和排查。

## 配置項

不同 DEX 可根據實際業務配置：

- 支持的資產與網絡
- 最小充值 / 提現數量
- 提現費用
- 充值與提現狀態
- 正式環境相關資金配置

<Note>
具體支持的資產、網絡、費用及狀態定義，以當前項目配置和對應 API 文檔為準。
</Note>
