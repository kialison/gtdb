DexBuilder 提供從 **DEX 創建、品牌配置、用戶賬戶、資產、行情、交易、結算到運營管理** 的完整能力。項目可以直接基於 DexBuilder 創建並運營自己的 DEX，無需分別建設交易前端和底層交易系統。

## Broker 能力

創建 Builder 後，DexBuilder 會為項目建立項目級標識，用於關聯該項目的用戶、交易和運營數據。

<CardGroup cols={2}>
  <Card title="項目與用戶歸屬" icon="users">
    識別不同項目來源，並關聯項目下用戶、訂單與交易數據。
  </Card>
  <Card title="手續費與收益" icon="coins">
    支持項目級手續費配置、交易費率、收入統計及相關結算能力。
  </Card>
  <Card title="數據與運營" icon="chart-column">

## 支持的產品

| 產品 | 說明 |
| --- | --- |
| PerpDEX | 永續合約交易、行情、訂單、持倉與賬戶能力 |
| 預測市場 | 事件結果市場、訂單簿、交易、持倉與結算 |
| 事件合約 | 事件類合約市場、交易、實時數據與結算 |
| 多產品 DEX | 可根據業務需要組合啓用多個產品 |

## 使用方式

DexBuilder 默認提供完整的 DEX 產品與管理能力。完成 Builder 創建後，可繼續配置產品、品牌、市場、賬戶、手續費及運營能力並上線 DEX。

對於需要與其他系統連接的場景，可使用對應產品的 REST API 與 WebSocket。具體接口、參數與認證方式統一在 **API Reference** 中維護。
