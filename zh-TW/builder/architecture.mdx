DexBuilder 提供從 **DEX 建立、品牌設定、使用者帳戶、資產、行情、交易、結算到營運管理** 的完整能力。專案可以直接基於 DexBuilder 建立並營運自己的 DEX，無需分別建設交易前端和底層交易系統。

## Broker 能力

建立 Builder 後，DexBuilder 會為專案建立專案級標識，用於關聯該專案的使用者、交易和營運資料。

<CardGroup cols={2}>
  <Card title="專案與使用者歸屬" icon="users">
    識別不同專案來源，並關聯專案下使用者、訂單與交易資料。
  </Card>
  <Card title="手續費與收益" icon="coins">
    支援專案級手續費設定、交易費率、收入統計及相關結算能力。
  </Card>
  <Card title="資料與營運" icon="chart-column">
    透過 Builder 管理後台檢視專案級使用者、交易量、手續費及營運資料。
  </Card>
  <Card title="API 與 WebSocket" icon="code">
    對需要系統集成的場景，提供 REST API 與 WebSocket 能力。
  </Card>
</CardGroup>

## 支援的產品

| 產品 | 說明 |
| --- | --- |
| PerpDEX | 永續合約交易、行情、訂單、持倉與帳戶能力 |
| 預測市場 | 事件結果市場、訂單簿、交易、持倉與結算 |
| 事件合約 | 事件類合約市場、交易、即時資料與結算 |
| 多產品 DEX | 可根據業務需要組合啓用多個產品 |

## 使用方式

DexBuilder 預設提供完整的 DEX 產品與管理能力。完成 Builder 建立後，可繼續設定產品、品牌、市場、帳戶、手續費及營運能力並上線 DEX。

對於需要與其他系統連接的場景，可使用對應產品的 REST API 與 WebSocket。具體介面、參數與認證方式統一在 **API Reference** 中維護。
