DexBuilder 提供完整的使用者帳戶與認證能力，用於支撐 DEX 的登入、帳戶建立、帳戶識別和交易認證流程。

## 帳戶流程

```text
使用者進入 DEX
      ↓
登入 / 連接錢包
      ↓
建立或識別帳戶
      ↓
完成必要認證
      ↓
進入資產與交易
```

DexBuilder 會統一處理帳戶狀態及交易所需的認證流程，並在 DEX 中提供對應的頁面與狀態展示。

## 支援能力

- 使用者登入與帳戶識別
- 錢包連接與授權
- 交易帳戶建立
- 帳戶狀態查詢
- 認證狀態管理
- 多端帳戶狀態同步
- 異常狀態與認證提示

## API 認證

對於透過 REST API 或 WebSocket 進行系統集成的場景，需要按照對應產品的 API 認證規則完成簽名和權限校驗。
