DexBuilder 提供完整的用戶賬戶與認證能力，用於支撐 DEX 的登錄、賬戶創建、賬戶識別和交易認證流程。

## 賬戶流程

```text
用戶進入 DEX
      ↓
登錄 / 連接錢包
      ↓
創建或識別賬戶
      ↓
完成必要認證
      ↓
進入資產與交易
```

DexBuilder 會統一處理賬戶狀態及交易所需的認證流程，並在 DEX 中提供對應的頁面與狀態展示。

## 支持能力

- 用戶登錄與賬戶識別
- 錢包連接與授權
- 交易賬戶創建
- 賬戶狀態查詢
- 認證狀態管理
- 多端賬戶狀態同步
- 異常狀態與認證提示

## API 認證

對於通過 REST API 或 WebSocket 進行系統集成的場景，需要按照對應產品的 API 認證規則完成簽名和權限校驗。
