手續費與收益屬於 **Builder 項目級配置**，不應與普通用戶查詢交易手續費的接口混在一起。

## Builder 需要確認甚麼

在正式上線前，項目方需要與 DexBuilder 對齊：

- 用戶側交易手續費
- DexBuilder 基礎費用
- Builder 可獲得的收益或分成
- 特殊費率或活動費率的適用範圍
- 收益統計口徑
- 結算週期與結算方式

## 手續費關係

```text
用戶交易
   ↓
用戶實際支付手續費
   ↓
平台基礎費用 + Builder 收益
```

具體費率、分成比例和結算規則以項目最終商務及系統配置為準。

## Builder 側能力

Builder 後續可通過項目級能力查看或管理與自身業務相關的手續費信息，例如：

- Builder 當前費率配置
- 用戶或用戶組費率
- 手續費收入
- 交易量與費率統計
- 收益結算記錄

<Warning>
只有已經在 Builder 後台或 Builder API 正式開放的能力才可使用。未在 API Reference 中出現的 Builder 專屬接口，不應視為已經對外提供。
</Warning>

## 與普通交易 API 的區別

普通用戶 API 中的手續費查詢用於交易和賬戶展示；Builder 手續費與收益則屬於項目級管理能力，兩者權限和使用場景不同。
