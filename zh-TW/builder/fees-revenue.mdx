description: "專案方在上線前需要確認的 Builder 手續費、收益與結算規則。"
---

手續費與收益屬於 **Builder 專案級設定**，不應與普通使用者查詢交易手續費的介面混在一起。

## Builder 需要確認甚麼

在正式上線前，專案方需要與 DexBuilder 對齊：

- 使用者側交易手續費
- DexBuilder 基礎費用
- Builder 可獲得的收益或分成
- 特殊費率或活動費率的適用範圍
- 收益統計口徑
- 結算週期與結算方式

## 手續費關係

```text
使用者交易
   ↓
使用者實際支付手續費
   ↓
平台基礎費用 + Builder 收益
```

具體費率、分成比例和結算規則以專案最終商務及系統設定為準。

## Builder 側能力

Builder 後續可透過專案級能力檢視或管理與自身業務相關的手續費資訊，例如：

- Builder 目前費率設定
- 使用者或使用者組費率
- 手續費收入
- 交易量與費率統計
- 收益結算記錄

<Warning>
只有已經在 Builder 後台或 Builder API 正式開放的能力才可使用。未在 API Reference 中出現的 Builder 專屬介面，不應視為已經對外提供。
</Warning>

## 與普通交易 API 的區別

普通使用者 API 中的手續費查詢用於交易和帳戶展示；Builder 手續費與收益則屬於專案級管理能力，兩者權限和使用場景不同。
