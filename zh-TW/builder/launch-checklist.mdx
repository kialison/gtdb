---
title: "上線檢查"
description: "Builder 在正式上線 DEX 前需要完成的產品、技術和營運檢查。"
---

正式上線前，專案方應完成一次端到端驗收，確保帳戶、資產、交易、即時資料和營運設定均符合預期。

## 產品與品牌

- [ ] 品牌名稱、Logo、域名和頁面設定已確認
- [ ] 支援的市場與交易對範圍已確認
- [ ] 風險提示、Terms 與 Privacy 已設定
- [ ] 使用者側異常提示和空狀態已檢查

## 帳戶與資產

- [ ] 帳戶建立與認證正常
- [ ] 充值流程正常
- [ ] 提現流程正常
- [ ] 資產餘額和狀態展示正確
- [ ] 網路、資產、費用等設定與正式環境一致

## 交易

- [ ] 行情、盤口和成交資料正常
- [ ] 下單、撤單和改單正常
- [ ] 訂單狀態同步正確
- [ ] 倉位、保證金和盈虧展示正確
- [ ] 異常訂單和風險提示已覆蓋

## 即時資料

- [ ] WebSocket 連接正常
- [ ] 斷線重連正常
- [ ] 重連後能夠恢復完整狀態
- [ ] 訂單、成交和倉位不會因重復消息出現異常

## Builder 設定

- [ ] Builder 身份和正式環境設定已確認
- [ ] 手續費與收益規則已確認
- [ ] Builder 管理後台賬號和權限已設定
- [ ] 營運、客服和技術聯繫人已明確

## 上線驗收

- [ ] 測試環境驗收完成
- [ ] 正式環境設定核對完成
- [ ] API / 簽名相關安全檢查完成
- [ ] 監控和告警已設定
- [ ] 回滾與異常處理方案已確認

<Note>
不同 Builder 的產品範圍可能不同。僅需驗收實際接入的模塊，但所有資金和交易相關流程都應覆蓋正常與異常場景。
</Note>
