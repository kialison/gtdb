title: "Builder 管理後台"
description: "DEX 上線後，項目方可通過 Builder 管理後台查看業務數據並進行日常運營管理。"
---

Builder 管理後台面向 **項目方運營和管理人員**。它不是終端用戶功能，而是 DEX 上線後的項目級管理工具。

## 後台能力概覽

根據當前運營後台能力，項目方可以集中查看和管理以下內容。

<CardGroup cols={2}>
  <Card title="運營數據" icon="chart-column">
    查看交易量、交易筆數、交易地址、手續費、活躍用戶、充提金額、訪問數據等核心指標和趨勢。
  </Card>
  <Card title="用戶與增長" icon="users">
    查看用戶、交易量及邀請返傭相關數據，用於日常運營和增長分析。
  </Card>
  <Card title="公告與內容" icon="bullhorn">
    管理項目公告及公告分類，用於向用戶同步產品和運營信息。
  </Card>
  <Card title="資金與充提" icon="wallet">
    查看資金轉賬、充值記錄、提現記錄及相關業務狀態。
  </Card>
  <Card title="系統權限" icon="user-shield">
    管理後台管理員、角色權限和訪問範圍。
  </Card>
  <Card title="操作審計" icon="clipboard-list">
    查看關鍵後台操作日誌，便於問題定位和權限審計。
  </Card>
</CardGroup>

## 運營數據看板

項目方可通過數據看板觀察自己的業務運行情況，例如：

- 總交易量與交易筆數
- 交易地址數與活躍用戶
- 手續費收入
- 充值與提現金額
- 新增用戶
- 邀請返傭數據
- PV / UV 與獨立 IP
- 交易量、用戶和手續費趨勢

## 後台與 Builder API 的關係

當前後台適合項目方進行日常運營和人工管理。對於需要程序化獲取或配置的 Builder 能力，後續會根據實際開放範圍逐步提供 Builder API。

<Note>
後台具體菜單和權限會根據項目配置有所不同。此處用於說明 Builder 可獲得的項目級運營能力，不作為後台操作手冊。
</Note>
