Builder 管理後台面向 **專案方營運和管理人員**。它不是終端使用者功能，而是 DEX 上線後的專案級管理工具。

## 後台能力概覽

根據目前營運後台能力，專案方可以集中檢視和管理以下內容。

<CardGroup cols={2}>
  <Card title="營運資料" icon="chart-column">
    檢視交易量、交易筆數、交易位址、手續費、活躍使用者、充提金額、存取資料等核心指標和趨勢。
  </Card>
  <Card title="使用者與增長" icon="users">
    檢視使用者、交易量及邀請返傭相關資料，用於日常營運和增長分析。
  </Card>
  <Card title="公告與內容" icon="bullhorn">
    管理專案公告及公告分類，用於向使用者同步產品和營運資訊。
  </Card>
  <Card title="資金與充提" icon="wallet">
    檢視資金轉賬、充值記錄、提現記錄及相關業務狀態。
  </Card>
  <Card title="系統權限" icon="user-shield">
    管理後台管理員、角色權限和存取範圍。
  </Card>
  <Card title="操作審計" icon="clipboard-list">
    檢視關鍵後台操作日誌，便於問題定位和權限審計。
  </Card>
</CardGroup>

## 營運資料看板

專案方可透過資料看板觀察自己的業務運行情況，例如：

- 總交易量與交易筆數
- 交易位址數與活躍使用者
- 手續費收入
- 充值與提現金額
- 新增使用者
- 邀請返傭資料
- PV / UV 與獨立 IP
- 交易量、使用者和手續費趨勢

## 後台與 Builder API 的關係

目前後台適合專案方進行日常營運和人工管理。對於需要程式化取得或設定的 Builder 能力，後續會根據實際開放範圍逐步提供 Builder API。

<Note>
後台具體菜單和權限會根據專案設定有所不同。此處用於說明 Builder 可獲得的專案級營運能力，不作為後台操作手冊。
</Note>
