DexBuilder 提供完整的 DEX 產品能力。大多數專案可以直接透過 Builder 完成 DEX 建立、品牌設定、產品設定和上線，無需單獨建設交易前端或交易基礎設施。

## DEX 構建

透過 DexBuilder 可直接完成：

- DEX 名稱、Logo、主題和域名設定
- PerpDEX、預測市場、事件合約等產品啓用
- 帳戶、資產、充提和交易能力設定
- 市場與交易參數設定
- 手續費與收益設定
- 營運後台與管理權限設定
- DEX 建立、更新與部署

## API / WebSocket

對於需要將 DexBuilder 資料或交易能力連接到其他系統的場景，可以使用對應產品的 REST API 與 WebSocket。

常見用途包括：

- 取得市場與行情資料
- 查詢帳戶、資產、訂單和持倉
- 執行交易操作
- 訂閱訂單、成交、倉位和餘額等即時資料
- 將業務資料連接到其他系統

具體 Endpoint、參數、認證方式和回傳欄位統一以 **API Reference** 為準。

## 推薦流程

1. 建立 Builder
2. 設定 DEX 基本資訊
3. 選擇並設定產品
4. 設定帳戶、資產與交易能力
5. 設定手續費與營運後台
6. 完成測試與驗收
7. 發佈上線
