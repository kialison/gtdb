DexBuilder 提供完整的 DEX 產品能力。大多數項目可以直接通過 Builder 完成 DEX 創建、品牌配置、產品配置和上線，無需單獨建設交易前端或交易基礎設施。

## DEX 構建

通過 DexBuilder 可直接完成：

- DEX 名稱、Logo、主題和域名配置
- PerpDEX、預測市場、事件合約等產品啓用
- 賬戶、資產、充提和交易能力配置
- 市場與交易參數配置
- 手續費與收益配置
- 運營後台與管理權限配置
- DEX 創建、更新與部署

## API / WebSocket

對於需要將 DexBuilder 數據或交易能力連接到其他系統的場景，可以使用對應產品的 REST API 與 WebSocket。

常見用途包括：

- 獲取市場與行情數據
- 查詢賬戶、資產、訂單和持倉
- 執行交易操作
- 訂閱訂單、成交、倉位和餘額等實時數據
- 將業務數據連接到其他系統

具體 Endpoint、參數、認證方式和返回字段統一以 **API Reference** 為準。

## 推薦流程

1. 創建 Builder
2. 配置 DEX 基本信息
3. 選擇並配置產品
4. 配置賬戶、資產與交易能力
5. 配置手續費與運營後台
6. 完成測試與驗收
7. 發佈上線
