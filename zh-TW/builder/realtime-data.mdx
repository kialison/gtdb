---

DexBuilder 通過 WebSocket 與內部實時數據服務持續更新 DEX 中的行情和交易狀態，保證訂單、成交、倉位和資產信息及時同步。

## 實時數據類型

- Ticker 與市場行情
- 訂單簿
- 市場成交
- 用戶訂單狀態
- 用戶成交
- 倉位變化
- 賬戶餘額
- 風險與強平相關狀態

## 數據同步

DEX 頁面會在首次加載時獲取當前完整狀態，並持續接收實時更新。當連接發生變化時，系統會重新建立連接並恢復必要的數據狀態。

## API / WebSocket 集成
