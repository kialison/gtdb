DexBuilder 是面向去中心化交易產品的基礎設施。平台將市場接入、訂單執行、帳戶、資產流程、結算與 Builder 營運能力整合在統一體系中，使專案團隊無需分別搭建每一層能力，即可推出具有獨立品牌的交易產品。

同一套平台基礎既可支援完整的品牌化交易體驗，也可支援專注於 API 的接入方式，專案團隊可以根據自身產品選擇適合的營運模式。

## 一個平台，多種市場體驗

DexBuilder 支援三類產品：永續合約 DEX、預測市場與事件合約。專案方可以使用自有前端呈現產品，並透過公開文檔中的 API 與接入流程連接平台能力。

## 面向專業交易產品

DexBuilder 將熟悉的訂單簿交易體驗，與生產級交易應用所需的帳戶、資產和營運能力結合起來。

- **交易基礎設施：** 行情、訂單管理、倉位、保證金模式、資金費率、強平與成交歷史；
- **可核對的帳戶記錄：** 餘額、訂單、成交、倉位和帳戶賬本變動透過一致的帳戶介面提供；
- **靈活的產品設計：** 專案團隊掌控品牌、使用者體驗、市場呈現與接入方式；
- **Builder 營運能力：** 使用者注冊、手續費設定、活動、推薦關係、使用者資料與收入結算按照產品流程組織；
- **開發者優先：** 中英文指南、OpenAPI、請求籤名、程式碼示例、WebSocket 指南與生產檢查清單集中維護。

## 平台如何協同

<Frame caption="DexBuilder 平台架構">
  ![交易應用與錢包使用者連接到 DexBuilder 的市場、帳戶、賬本與結算服務](/images/platform-architecture-zh.svg)
</Frame>

使用者透過交易應用發起操作，並對帳戶或資產動作進行授權。應用使用公開行情介面與已認證的帳戶介面；DexBuilder 協調交易執行、倉位記賬、賬本更新與結算。Builder 營運能力則提供專案運行所需的設定與管理入口。
