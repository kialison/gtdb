DexBuilder 是面向去中心化交易產品的基礎設施。平台將市場接入、訂單執行、賬戶、資產流程、結算與 Builder 運營能力整合在統一體系中，使項目團隊無需分別搭建每一層能力，即可推出具有獨立品牌的交易產品。

同一套平台基礎既可支持完整的品牌化交易體驗，也可支持專注於 API 的接入方式，項目團隊可以根據自身產品選擇適合的運營模式。

## 一個平台，多種市場體驗

DexBuilder 支持三類產品：永續合約 DEX、預測市場與事件合約。項目方可以使用自有前端呈現產品，並通過公開文檔中的 API 與接入流程連接平台能力。

## 面向專業交易產品

DexBuilder 將熟悉的訂單簿交易體驗，與生產級交易應用所需的賬戶、資產和運營能力結合起來。

- **交易基礎設施：** 行情、訂單管理、倉位、保證金模式、資金費率、強平與成交歷史；
- **可核對的賬戶記錄：** 餘額、訂單、成交、倉位和賬戶賬本變動通過一致的賬戶接口提供；
- **靈活的產品設計：** 項目團隊掌控品牌、用戶體驗、市場呈現與接入方式；
- **Builder 運營能力：** 用戶注冊、手續費配置、活動、推薦關係、用戶數據與收入結算按照產品流程組織；
- **開發者優先：** 中英文指南、OpenAPI、請求籤名、代碼示例、WebSocket 指南與生產檢查清單集中維護。

## 平台如何協同

<Frame caption="DexBuilder 平台架構">
  ![交易應用與錢包用戶連接到 DexBuilder 的市場、賬戶、賬本與結算服務](/images/platform-architecture-zh.svg)
</Frame>

用戶通過交易應用發起操作，並對賬戶或資產動作進行授權。應用使用公開行情接口與已認證的賬戶接口；DexBuilder 協調交易執行、倉位記賬、賬本更新與結算。Builder 運營能力則提供項目運行所需的配置與管理入口。
