---

當使用的運行環境沒有現成 SDK，或業務需要對請求、簽名、分頁和即時訂閱進行更細粒度控制時，可以直接使用 API 接入。

REST API 回傳原始 JSON 資料，並按業務提供獨立介面。私有介面的認證和簽名需要由接入方實現；不同介面的分頁規則以具體頁面說明為準。對於即時資料，需要連接相應的 WebSocket 服務並訂閱所需頻道。
