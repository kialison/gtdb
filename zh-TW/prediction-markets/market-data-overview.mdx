預測市場的資料接入通常從確定應用關注的 Event、Market 或 Outcome 開始。本節將介紹如何完成市場發現、讀取市場詳情、取得價格與訂單簿、檢視統計資料，以及訂閱即時資料。

## 資料模型

在預測市場中，一個 Event 可以包含一個或多個 Market。每個 Market 是一個可交易問題，並包含 YES / NO 等結果。每個 Outcome 都有對應的 Token ID。

當應用需要讀取某個結果的價格、訂單簿或提交訂單時，需要使用該 Outcome 的 `token_id`。

![Image](/images/image-6.png "Image")

<Steps>
  <Step title="發現 Event">
    瀏覽目前 Event、按分類篩選，或根據 slug / ID 直接查詢指定 Event。
  </Step>
  <Step title="選擇 Market">
    檢視 Event 下的 Market，並選擇應用需要處理的具體問題。
  </Step>
  <Step title="選擇 Outcome">
    選擇 YES、NO 或其他結果，並保存對應的 Token ID。
  </Step>
  <Step title="讀取或訂閱資料">
    使用已取得的標識查詢 REST API，或透過 WebSocket 訂閱即時更新。
  </Step>
</Steps>
