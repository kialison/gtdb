事件合約使用中央限價訂單簿（CLOB）進行交易。價格並非由平台直接設定，而是由使用者之間的買賣供需形成。

![Image](/images/image-2.png "Image")

## 價格代表概率

每份結果份額的價格介於 `$0.00` 和 `$1.00` 之間，可以直接理解為市場對該結果發生概率的估計。

頁面展示價格通常取最佳買價與最佳賣價的中間價；當買賣價差過寬時，可使用最近成交價作為展示價格。

| 價格 | 隱含概率 |
| --- | --- |
| `$0.25` | 25% |
| `$0.50` | 50% |
| `$0.75` | 75% |

### 示例

如果 Yes 的最佳買價為 `$0.34`，最佳賣價為 `$0.40`：

```text
展示價格 = ($0.34 + $0.40) / 2 = $0.37
對應概率約為 37%
```

## 訂單簿

訂單簿包含目前 Market 所有未成交的買單與賣單：

| 方向 | 說明 |
| --- | --- |
| Bids | 買單，表示買方願意支付的價格，最高買價位於最前 |
| Asks | 賣單，表示賣方願意接受的價格，最低賣價位於最前 |

最佳買價和最佳賣價之間的差值稱為 Spread（價差）。通常價差越小，說明市場流動性越好。

## 訂單類型

### 市價交易

希望立即成交時，可以使用能夠直接吃掉目前訂單簿流動性的訂單：

- 買入：按目前可成交的最低賣價開始成交；
- 賣出：按目前可成交的最高買價開始成交。

### 限價單

只在指定價格或更優價格成交：

- 未成交部分會繼續留在訂單簿；
- 一筆訂單可以被多次部分成交；
- 未成交部分可以在允許撤單時主動取消。

## 成交與結算

事件合約 CLOB 採用混合式架構：

1. **鏈下撮合**：撮合服務匹配價格與數量滿足條件的訂單；
2. **鏈上結算**：匹配後的交易透過智能合約完成資產交割。

這種模式兼顧鏈下撮合效率與鏈上資產結算的可驗證性。
