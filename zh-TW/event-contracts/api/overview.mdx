## Base URL

```text
https://api.dexbuilder.com
```

事件合約 REST API 前綴為：

```text
/api/v4/event_contracts
```

## 介面存取模型

| 介面類型 | 是否需要認證 | 典型能力 |
| --- | --- | --- |
| 市場發現 | 否 | 事件、市場、標籤 |
| 市場資料 | 否 | 價格、Ticker、訂單簿、歷史資料、K 線 |
| 交易 | 是 | 下單、查詢訂單、撤單 |
| 帳戶 | 是 | 持倉、資產、餘額、費率、個人成交 |
| 結算 | 是 | 平倉、領取、資金處理 |

## 分頁

清單介面使用游標分頁，回傳 `items` 與 `next_cursor`。下一頁請求直接使用上一頁回傳的 `next_cursor`，不要自行解析或修改游標。

## 時間與數值約定

- 事件與市場日期欄位通常使用 Unix 秒；
- `from`、`to` 等範圍參數通常使用 Unix 毫秒；
- 價格、數量、成交額、餘額、手續費等金額類欄位通常以字串回傳，建議使用 Decimal 精度處理。

## 標準錯誤

```json
{"label":"INVALID_ARGUMENT","message":"invalid request"}
```

常見 HTTP 狀態包括 `400`、`401`、`404` 和 `503`。
