事件合約允許使用者圍繞現實世界事件的結果進行交易。使用者不是與平台對賭，而是在開放的點對點市場中與其他使用者買賣結果份額。價格反映了市場參與者對某個結果發生概率的集體判斷。

## 價格即概率

事件合約中的每份結果份額價格介於 `0.00` 到 `1.00` 之間。價格可以理解為市場對該結果發生概率的估計。

例如，如果某個事件的「Yes」份額交易價格為 `$0.65`，可以理解為市場目前認為該事件發生的概率約為 65%。

## 抵押資產與結果代幣

事件合約使用 USDT 作為抵押資產。每一組 Yes / No 結果都具有完整抵押：

- `1 USDT` 可對應生成 1 份 Yes 和 1 份 No；
- 獲勝結果份額可按 `$1.00` 贖回；
- 失敗結果份額價值歸零。

結果份額基於 [Gnosis Conditional Token Framework](https://docs.gnosis.io/conditionaltokens/)（ERC-1155）表示，從而支援鏈上交易與結算。

## 交易

事件合約採用點對點中央限價訂單簿（CLOB）。使用者直接與其他使用者成交，而不是與平台作為對手方交易。

- 當你認為市場低估某一結果概率時，可以買入對應份額；
- 當你認為市場高估某一結果概率時，可以賣出對應份額；
- 在市場最終結算之前，可以隨時賣出持倉鎖定收益或控制損失。

| 操作 | 適用場景 | 盈利場景 |
| --- | --- | --- |
| 買入 Yes | 認為目前概率偏低 | 事件發生 |
| 買入 No | 認為目前概率偏高 | 事件未發生 |
| 賣出 | 鎖定收益或限制損失 | 價格朝有利方向變化 |

## 結算

事件結束後，市場透過 UMA Optimistic Oracle 完成結果確認：

1. 提議者提交結果並繳納保證金；
2. 進入挑戰期，其他參與者可以對結果提出異議；
3. 若發生爭議，可進一步進入 UMA 投票流程；
4. 最終獲勝結果代幣可兌換為 `1 USDT`。

該機制用於在無需單一中心化裁定方的情況下完成市場結果確認。
