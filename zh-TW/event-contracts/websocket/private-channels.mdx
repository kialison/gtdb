私有頻道需要 API Key 簽名認證。API Secret 只在本地用於簽名，不能透過網路傳送。詳見 [WebSocket 認證](./authentication)。

## 訂閱

使用 `ec` 前綴。可以使用 `items` 訂閱指定條件，也可以使用 `all: true` 訂閱全部私有推送。

```json
{
  "t": 1720000000123,
  "id": "private-1",
  "op": "subscribe",
  "ch": "ec.orders",
  "payload": {"items": [{"condition_id": "ge_condition-1"}]},
  "auth": {"method": "api_key", "key": "YOUR_API_KEY", "sign": "SIGNATURE"}
}
```

取消訂閱時使用相同的 payload，並將 `op` 設定為 `unsubscribe`。文件不暴露內部使用者 Header 或 broker 標識。

## `ec.orders`

帳戶訂單狀態變化。返回欄位包括 `order_id`、`client_order_id`、`event_id`、`condition_id`、`token_id`、`outcome`、`side`、`order_mode`、`order_type`、`px`、`qty`、`filled_qty`、`left_qty`、`status`、`created_ts` 和 `updated_ts`。

```json
{"type":"update","ch":"ec.orders","err":null,"result":{"order_id":"order-1","condition_id":"ge_condition-1","token_id":"ge_token-yes","side":"BUY","px":"0.45","qty":"10","filled_qty":"4","left_qty":"6","status":"OPEN","updated_ts":1720000001123}}
```

狀態可能為 `PROCESSING`、`OPEN`、`CANCELLING`、`MATCHED`、`CANCELED` 或 `FAILED`。

## `ec.usertrades`

帳戶成交推送。返回 `trade_id`、`order_id`、`condition_id`、`token_id`、`side`、`role`、`px`、`qty`、`fee_rate`、`status` 和 `created_ts`。

```json
{"type":"update","ch":"ec.usertrades","err":null,"result":{"trade_id":"trade-1","order_id":"order-1","condition_id":"ge_condition-1","token_id":"ge_token-yes","side":"BUY","role":"MAKER","px":"0.45","qty":"4","fee_rate":"0.001","status":"CONFIRMED","created_ts":1720000000123}}
```

僅推送已確認的帳戶成交；是否推送 MATCHED 事件取決於服務設定。

## `ec.positions`

帳戶倉位變化。返回 `position_id`、`event_id`、`token_id`、`outcome`、`qty`、`avg_px`、`settle_status`、`locked_qty`、`available_qty`、`claimable_amount` 和 `updated_ts`。

```json
{"type":"update","ch":"ec.positions","err":null,"result":{"position_id":"12345","event_id":"event-1","token_id":"ge_token-yes","outcome":"Yes","qty":"10","avg_px":"0.45","settle_status":"UNSETTLED","locked_qty":"0","available_qty":"10","claimable_amount":"0","updated_ts":1720000001123}}
```

倉位文件不描述標記價格欄位。

## `ec.settlements`

結算和可領取金額變化。

```json
{"type":"update","ch":"ec.settlements","err":null,"result":{"position_id":"12345","condition_id":"ge_condition-1","event_id":"event-1","winning_outcome":"Yes","is_winner":true,"claimable_amount":"10.00","created_ts":1720000002123}}
```

私有頻道是事件驅動的。重連後應透過對應 REST 介面恢復目前狀態；訂閱私有頻道不會自動返回完整帳戶快照。
