公共頻道不需要認證。連線地址：

```text
wss://broker.dexbuilder.com/ws/dex-builder/event-contracts
```

使用前綴 `ec` 訂閱。每個訂閱項目對應一個事件、市場、Token 或價格序列。

## 訂閱範例

```json
{
  "t": 1720000000123,
  "id": "sub-1",
  "op": "subscribe",
  "ch": "ec.trades",
  "payload": {"items": [{"condition_id": "gate_condition-1"}]}
}
```

伺服器會先返回 ACK；如果已有快取，會返回 `snapshot`，之後透過 `update` 推送變化。

## 頻道與返回

### `ec.trades`

市場成交推送。訂閱欄位為 `condition_id`。

```json
{"type":"update","ch":"ec.trades","err":null,"result":{"condition_id":"gate_condition-1","token_id":"gate_token-yes","outcome":"Yes","side":"BUY","px":"0.45","qty":"10","ts":1720000000123}}
```

### `ec.depth`

Token 的完整訂單簿快照，支援 level 5、10、20、50。訂閱欄位為 `token_id` 和 `level`。

```json
{"type":"snapshot","ch":"ec.depth","err":null,"result":{"token_id":"gate_token-yes","level":20,"full":true,"bids":[["0.44","100"]],"asks":[["0.46","80"]],"hash":"book-hash","ts":1720000000123}}
```

`bids` 和 `asks` 是完整深度，不是增量變更。

### `ec.bbo`

Token 的最佳買賣價。訂閱欄位為 `token_id`。

```json
{"type":"update","ch":"ec.bbo","err":null,"result":{"condition_id":"gate_condition-1","token_id":"gate_token-yes","bid_px":"0.44","ask_px":"0.46","last_px":"0.45","ts":1720000000123}}
```

### `ec.status`

市場狀態和結果。訂閱欄位為 `market_id`。

```json
{"type":"update","ch":"ec.status","err":null,"result":{"market_id":"gate_market-1","condition_id":"gate_condition-1","slug":"example-market","status":"ACTIVE","closed":false,"accepting_orders":true,"outcomes":[{"name":"Yes","token_id":"gate_token-yes","px":"0.45"}],"ts":1720000000123}}
```

### `ec.cpi`

指數價格推送。訂閱欄位為 `symbol` 和 `interval`。

```json
{"type":"update","ch":"ec.cpi","err":null,"result":{"symbol":"btcusdt","interval":"1m","price":"100000.10","price_timestamp":"1720000000123","ts":1720000000123}}
```

### `ec.candlestick`

基於價格源生成的 OHLC 推送。訂閱欄位為 `symbol` 和 `interval`。

```json
{"type":"update","ch":"ec.candlestick","err":null,"result":{"symbol":"btcusdt","interval":"1m","t":1720000000,"o":"100000.00","h":"100010.00","l":"99990.00","c":"100005.00","v":"0","closed":false}}
```

可用快照包含 `symbol`、`interval` 和 `history`。

### `ec.oc_price`

事件視窗的開盤參考價和最終價。可以使用 `slug` 或 `market_id` 訂閱，也可以對配置好的幣價視窗使用 `symbol` 和 `interval`。

```json
{"type":"update","ch":"ec.oc_price","err":null,"result":{"slug":"bitcoin-up-or-down","price_to_beat":"100000.00","final_price":"100120.00"}}
```

除非欄位明確標註為秒級時間，否則時間戳均為 Unix 毫秒時間戳。
