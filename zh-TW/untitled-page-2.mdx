DexBuilder 為多種去中心化市場產品提供統一基礎。項目團隊可以根據用戶需求選擇產品模式，同時在賬戶、資產、數據和運營方面保持一致的接入方式。

## 永續合約 DEX

永續合約 DEX 面向無固定到期日的連續訂單簿交易，覆蓋活躍交易者與專業交易者所需的主要流程：

- 合約信息、訂單簿、市場成交、K 線、行情統計與歷史資金費率；
- 限價、市價、只減倉、只掛單、全部成交或取消、批量與檔位 BBO 下單流程；
- 單向持倉與雙向持倉模式；
- 全倉與逐倉保證金模式；
- 槓桿、倉位保證金、倉位檔位、標記價格、資金費率、強平與 ADL 記錄；
- 賬戶狀態、賬戶流水、交易費率、個人成交與平倉歷史。

## 預測市場

預測市場圍繞定義清晰的問題和一組可能結果組織交易。完整的市場體驗會向用戶展示市場規則、交易狀態、結果標的、關鍵時間與最終判定結果，使用戶能夠在交易前核對合約含義。

項目團隊可以通過 DexBuilder 將預測市場產品納入自有品牌與用戶體驗，並沿用平台統一的賬戶、資產與運營流程。

## 事件合約

事件合約是與特定事件結果關聯的結果型合約。每個合約均以明確條款、生命週期狀態、交易可用性與結算條件呈現，使用戶可以理解最終結果的判定依據。

事件合約擴展了 Builder 可提供的市場範圍，並遵循相同的產品原則：規則清晰、用戶狀態一致、賬戶記錄可核對、結算結果明確。

## 共同的產品原則

| 原則 | 用戶應獲得的體驗 |
| --- | --- |
| 清晰的市場定義 | 提交操作前可以查看產品條款、市場狀態、支持的操作與結算條件 |
| 一致的賬戶狀態 | 訂單、倉位或結果敞口、餘額、手續費與歷史記錄形成連貫的賬戶體驗 |
| 明確的授權 | 已認證操作與資產操作遵循公開的憑證和錢包授權規則 |
| 可追蹤的生命週期 | 應用可以從提交、執行、賬本更新一直跟蹤至最終結算 |
| Builder 自主控制 | 項目團隊擁有前端、品牌、用戶路徑與允許配置的產品參數 |
