---
title: "核心能力"
description: "在 DexBuilder 上構建產品可使用的交易、資產、營運與開發者能力。"
---

DexBuilder 旨在減少專案團隊需要分別搭建和維護的獨立系統數量。平台將去中心化交易產品的核心能力組織為四個相互連接的部分。

## 交易體驗

- 訂單簿行情與即時市場資料流；
- 專業訂單類型與批量訂單管理；
- 單向持倉與雙向持倉模式；
- 全倉與逐倉保證金模式；
- 標記價格、資金費率、強平、保險基金與 ADL 資訊；
- 帳戶、成交、平倉與交易費率歷史。

## 帳戶、資產與結算

- 基於錢包的使用者授權；
- 帳戶注冊與帳戶狀態查詢；
- 充值、提現與內部划轉；
- 帳戶流水與對賬流程；
- 盈虧與 Builder 收入結算。

## Builder 營運

- 專案注冊與 Builder 資訊；
- 使用者注冊與已授權使用者資料；
- 手續費設定與訂單歸因；
- 活動與推薦計劃；
- 限定在專案範圍內的管理資料存取。

## 開發者平台

- 公開及認證 REST 操作；
- WebSocket 接入指南；
- HMAC-SHA512 請求籤名與憑證權限；
- 冪等操作模式；
- 完整中英文文檔；
- 用於客戶端生成和校驗的 OpenAPI 定義；
- 故障排查與生產上線指南。

## 接入邊界

每個 API 頁面會明確相應操作的方法、路徑、參數位置、請求體、響應結構與認證要求。應用不應只根據請求已提交就推斷狀態變化；應透過相應查詢介面確認訂單、餘額、倉位、賬本記錄與結算狀態。
