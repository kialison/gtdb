Discovery endpoints are public and do not require authentication. Results are limited to the rolling 30-day parent Event window.

## Events

```http
GET /api/v4/event_markets/events
GET /api/v4/event_markets/events/{event_id}
GET /api/v4/event_markets/events/slug/{slug}
```

The list endpoint supports filters such as `active`, `closed`, `tag_slug`, date ranges, sorting, and cursor pagination.

```bash
curl "https://broker.dexbuilder.com/api/v4/event_markets/events?limit=20&active=true"
```

## Markets

```http
GET /api/v4/event_markets/markets
GET /api/v4/event_markets/markets/{market_id}
GET /api/v4/event_markets/markets/slug/{slug}
```

Use `event_id`, `active`, `closed`, `tag_slug`, and cursor parameters to narrow a market list.

```bash
curl "https://broker.dexbuilder.com/api/v4/event_markets/markets?limit=20&event_id=<event_id>"
```

Read the outcome token identifiers from the returned market before requesting prices or order-book data.
