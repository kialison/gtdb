DexBuilder 是面向去中心化交易产品的基础设施。平台将市场接入、订单执行、账户、资产流程、结算与 Builder 运营能力整合在统一体系中，使项目团队无需分别搭建每一层能力，即可推出具有独立品牌的交易产品。

同一套平台基础既可支持完整的品牌化交易体验，也可支持专注于 API 的接入方式，项目团队可以根据自身产品选择适合的运营模式。

## 一个平台，多种市场体验

DexBuilder 支持三类产品：永续合约 DEX、预测市场与事件合约。项目方可以使用自有前端呈现产品，并通过公开文档中的 API 与接入流程连接平台能力。

## 面向专业交易产品

DexBuilder 将熟悉的订单簿交易体验，与生产级交易应用所需的账户、资产和运营能力结合起来。

- **交易基础设施：** 行情、订单管理、仓位、保证金模式、资金费率、强平与成交历史；
- **可核对的账户记录：** 余额、订单、成交、仓位和账户账本变动通过一致的账户接口提供；
- **灵活的产品设计：** 项目团队掌控品牌、用户体验、市场呈现与接入方式；
- **Builder 运营能力：** 用户注册、手续费配置、活动、推荐关系、用户数据与收入结算按照产品流程组织；
- **开发者优先：** 中英文指南、OpenAPI、请求签名、代码示例、WebSocket 指南与生产检查清单集中维护。

用户通过交易应用发起操作，并对账户或资产动作进行授权。应用使用公开行情接口与已认证的账户接口；DexBuilder 协调交易执行、仓位记账、账本更新与结算。Builder 运营能力则提供项目运行所需的配置与管理入口。
